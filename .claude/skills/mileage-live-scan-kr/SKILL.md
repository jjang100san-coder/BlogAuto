# mileage-live-scan-kr — 실시간 보너스 좌석 수집 + 로그아웃 대비

프로그램 위치: `C:\Users\user\Desktop\Blog\projects\asiana-award\`
결과·기록 위치: 같은 폴더의 `data\`

공개 달력(로그인 불필요, 하루 1회 스냅샷)은 **어느 도시를 볼지 고를 때만** 쓴다.
글에 싣는 숫자는 이 스킬의 실시간 수집으로 받는다. 공개 달력과 실시간 화면은 며칠씩 어긋난다.

## 반드시 지키는 것

1. **수집기는 `launch.py` 로만 띄운다.** 직접 `python ke_live.py` 로 띄우지 않는다. `launch.py` 가 세션 가드를 먼저 확인하고 띄운다. (수집기 자체도 시작할 때 가드를 확인하지만, 2중으로 둔다.)
2. **로그인은 사람이 한다.** 비밀번호·OTP·보안문자는 입력하지 않는다. 로그인이 풀리면 멈추고 알린다.
3. **예매·결제 단계로 넘어가지 않는다.** 조회 결과 화면까지만.
4. **차단(403·Access Denied) 이면 즉시 멈춘다.** 우회하지 않는다. 같은 항공사를 탭 여러 개로 동시에 돌리지 않는다(조회량이 배가 된다). 아시아나 1개 + 대한항공 1개 병렬은 된다.
5. **작업을 걸기 전에 범위와 소요 시간을 먼저 답한다.** 사용자는 큰 틀이 정해진 뒤에 띄우길 원한다.

## 조회량 원칙 — 2026-10-02 아시아나 차단 뒤에 정한 것

10월 2일 11:11 아시아나가 `Access Denied`(아카마이)로 막혔다. 그날 나간 것: 새벽 90분 날짜별 수집 → 아침 점검 → 4분마다 세션 연장 클릭 38번 → 오전 재수집(일반석+비즈니스라 조회 두 배) + 사용자의 수동 조회. 재수집 12분째에 막혔다. 집 회선만 막혔고 회사 회선에서는 로그인·접속이 됐다.

1. **실시간 수집은 하루 한 번, 꼭 필요한 도시만.** 같은 날 전체 수집 위에 재수집을 얹지 않는다. 넓게 훑는 건 공개 달력으로 한다.
2. **재확인은 도시 한두 곳만**, 가능하면 사용자가 수동으로 본다.
3. **로그인을 붙잡아 두지 않는다.** 가드는 마지막 조회 후 10분이 지나면 스스로 끝난다. 수집 없이 연장만 계속 누르는 것(`launch.py guard`)은 측정 목적이 아니면 쓰지 않는다 — 그것도 눈에 띄는 패턴이다.
4. **차단을 피하려는 동작(사람인 척하는 클릭·대기 섞기 등)은 넣지 않는다.** 계정에 마일리지가 있다. 막히면 그날은 그 항공사를 접는다.
5. 가드는 차단 화면을 보면 `data\PAUSE_<항공사>` 파일을 만들고 그 항공사 창을 더 누르지 않는다. 다시 쓰려면 사람이 그 파일을 지운다.

## 세션 가드 (`session_guard.py`)

- 감독 + 일꾼 구조. 일꾼이 죽거나 90초 넘게 멈추면 감독이 다시 띄운다. **마지막 조회 후 10분이 지나면 스스로 끝난다.** 크롬이 15분 넘게 꺼져 있어도 끝난다. `launch.py guard [시간]` 으로 띄운 경우만 수집과 무관하게 계속 돈다.
- 로그인 유지 실측(2026-10-02): 가드의 연장 클릭만으로 08:38~11:11(2시간 33분) 두 사이트 모두 유지됐다. 그 이상은 재지 못했다(아시아나 차단으로 중단).
- 다른 프로그램이 새로 연 탭은 기존 연결에 안 보일 수 있어서, 탭 목록이 달라지면 크롬에 다시 붙는다. (옛 감시기가 수집 탭을 못 봐서 연장을 놓친 원인이었다.)
- 도는 동안 PC 절전 진입을 막는다. **노트북 덮개를 닫는 절전은 못 막는다** — 덮개를 닫으면 타이머가 멈춰 세션이 죽는다.
- 수집기가 3초 안에 처리하지 않은 알림창(alert)은 가드가 닫는다. 안 닫으면 그 탭이 멈춘다.

## 아시아나 화면의 함정

- 좌석등급을 **전체**로 조회하면 달력에 하루 표시가 하나만 뜬다. 일반석이 있으면 비즈니스가 가려진다. 비즈니스는 등급을 비즈니스만 골라 따로 조회한다(`--cabins B`, `oz_daily.py` 는 끝에 자동으로 한다).
- 예매 화면은 **좌석 없는 날과 편 없는 날을 구분해 주지 않는다.** 대한항공은 공개 달력의 편 목록으로 구분된다. 글·이미지에 이 차이를 적는다.
- `좌석없음` 날은 눌리지 않아 편별 내역이 없다.
- 국내선은 등급 선택이 없고, 결과 화면에서 안내창(`#btnDomPopup`)을 닫아야 한다.
- 조회 버튼은 대기열(NetFunnel)을 거치므로 화면 조작으로만 조회한다.

## 선제 세션 유지(keeper) — 2026-10-10 추가

- 대한항공 로그인 수명은 쿠키 `TTL`(40분)·`t_sck` 로 돌고, **API 호출로는 안 늘어난다. 전체 페이지 로드만 40분으로 되돌린다**(실측 04:10). 그래서 `session_guard.py` 의 `KEEPER` 가 1분마다 수명 쿠키를 읽어 12분 아래면 가드 전용 탭에서 `koreanair.com/` 을 다시 연다. 아시아나는 수명 쿠키가 없어 로그인·비수집 상태에서 10분마다 메인을 다시 연다.

- 연장 버튼 클릭·만료창 기록·LOGIN_NEEDED 파일은 2차 방어로 그대로. 비밀번호 입력·자동 로그인은 사용자가 요청해도 하지 않는다.
