# 부동산 데이터 도구 안내 (2026-10-10)

키는 콘텐츠 트렌드 레이더 ⚙ 설정(4~8번)과 공공데이터포털 키를 **읽기만** 한다. 도구는 `tools\`, 결과는 이 폴더 아래.

| 도구 | 하는 일 | 결과 | 자동 실행 |
|---|---|---|---|
| `tools\rates_snapshot.py` | 은행별 주담대(아파트·분할)·전세대출 금리(금감원 finlife) + 기준금리·예금은행 신규 평균금리 13개월(한국은행 ECOS) | `금리스냅샷\금리_날짜.md` · `rates_history.csv`(쌓임) · `data\` | **Blog_부동산_금리스냅샷** 매주 월 09:40 ~12/31 · 카톡 요약 |
| `tools\compare_suwon.py` | 수원 4개 구: 매매 건수·84㎡급 매매/전세 중위·같은 단지 전세가율·신규 vs 갱신 전세·갱신 인상률·해제·직거래·법인·계약→등기·인구 12개월 | `수원4개구\비교표_YYYY-MM.md` · `.csv` · `card1`·`card2` 카드(직접 만든 표, 출처 줄 포함) | **Blog_부동산_수원비교표** 매주 월 10:00 ~2027-06-30 · 카톡은 매달 첫 주만 |
| `tools\deal_track.py` | 내 거래가 실거래 자료에 뜬 날·등기일 찍힌 날 + 같은 구·같은 계약월의 등기 진행 | `내거래추적\기록.md`(날짜·구 단위만) · `tools\_track_state.json` | **Blog_부동산_내거래추적** 매일 09:30 ~2027-02-28 · 바뀐 게 있을 때만 카톡 |

- 실행 기록: `tools\_run.log` (pythonw 라 화면이 없다)
- 실거래 캐시: `tools\_cache\` — 3개월 넘은 달은 그대로 쓰고, 최근 3개월은 하루 지나면 다시 받는다(신고·등기가 계속 채워짐)
- 손으로 돌릴 때: `python tools\compare_suwon.py --end 202609` 처럼 끝 달 지정 가능

## ⚠️ 내 거래 추적기는 설정이 필요하다

`tools\my_deal.json` 을 채워야 돈다. **이 파일은 블로그에 올리지 않는다.**

| 칸 | 넣는 것 |
|---|---|
| lawd | 구 코드 — 장안 41111 · 권선 41113 · 팔달 41115 · 영통 41117 |
| umd | 법정동 이름 (비워도 됨) |
| apt_contains | 단지 이름 일부 (실거래 자료에 찍히는 이름 기준) |
| area_min · area_max | 전용면적 범위 (예: 84.0 · 85.0) |
| deal_date | 계약일 YYYY-MM-DD |
| floor · price_manwon | 층 · 거래가(만원) — 넣으면 정확해진다, 비워도 됨 |
| balance_date | 잔금일 (기록용) |

## 블로그에 쓸 때 (마스터 0-10)

- 구 단위 집계만. 단지명·동·호·지번, 내 단지가 좁혀지는 숫자 조합 금지.
- 출처 한 줄(API·기간·건수·방법·조회일)은 결과 md 머리에 이미 만들어져 있다 — 그대로 옮긴다.
- 원인·전망은 쓰지 않는다.
