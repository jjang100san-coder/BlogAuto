```
   `계양산 주차`로 들어온 사람은 주차 답만 찾는다.

2. 4종 세트를 표로 박는다
   거리 / 소요시간 / 난이도 / 코스 경유지.
   상위 노출 글이 예외 없이 갖고 있다. 2열(항목/값) 세로 표.

3. 주력 키워드는 [산 이름] + 등산코스
   대형 검색어(등산 코스 추천)는 언론사·기관이 점유. 정면 승부 금지.

4. 등산 용어에 쉬운 설명을 붙인다
   들머리·날머리·원점회귀·능선·안부. 초보는 거기서 멈춘다.

5. 비유는 여행·읽기·생활에서만 가져온다
   등산 글에서는 등산이 이미 본문이라 비유가 안 된다.

6. 카테고리는 Move > 등산 하나, 장비는 Move > 장비
   지역별로 쪼개지 않는다. 주차·교통은 들머리 기준으로 쓴다.

7. 프로그램이 뽑은 값은 공식 값이 아니다
   GPX 최고점 ≠ 산 높이. 높이는 산림청 값, 시간은 "휴식 제외 계산값"이라고 적는다.
   예상 시간을 예고했으면 다녀와서 실측과 나란히 쓴다.
```

# 1. 🎯 등산 글 독자는 「답」을 찾으러 온다

| | 여행·독후감 독자 | **등산 글 독자** |
|---|---|---|
| 상태 | 갈까 말까 / 읽을까 말까 | **이미 갈 마음을 먹음** |
| 원하는 것 | 판정·감상 | **답** (주차·시간·난이도) |
| 검색어 | `책제목 후기` | `계양산 주차` |
| 이탈 조건 | 재미없으면 | **답이 안 보이면 즉시** |

> ### 등산 글의 가시성은 "읽기 편함"이 아니라 **"답이 어디 있는지 보임"**이다.

**주 독자층은 50-60+ 여성** (마스터 §11). 감성보다 실용 정보를 본다.
소요시간·난이도·화장실·주차를 앞쪽에 배치한다.

## 답이 보이게 쓰는 4가지

### ① 답을 맨 위에

도입 2~3줄 안에 결론. 그다음 **바로 4종 세트 표.**
(분야 예외 — 마스터 16-4는 「도입부 2~4문장」. 등산 독자는 답만 찾으므로 더 짧게 둔다)

```
❌ 지난 토요일, 오랜만에 산에 다녀왔어. 날씨가 어찌나 좋던지…
⭕ 인왕산 등산코스, 경복궁역에서 왕복 5km 걸렸어. 결론부터 표로.
```

### ② 소제목은 섹션 이름이 아니라 답 문장

마스터 §1-2(고유명사 + 결론 평서문)를 등산에 적용하면 이렇게 된다.

| ❌ 섹션 이름 | ⭕ 답 문장 |
|---|---|
| 주차 정보 | 주차는 사직공원 공영주차장 |
| 등산 시작 | 사직공원에서 등산 초입까지 25분 |
| 힘든 구간 | 범바위까지 20분이 제일 힘들어 |
| 하산 후 | 하산해서 서촌 두부김치로 마무리 |

### ③ 4종 세트는 반드시 표로

**상위 노출 글이 예외 없이 갖고 있는 조합이다.** 취향이 아니라 검색 매칭 구조.

```
거리 / 소요시간 / 난이도 / 코스 경유지
```

⚠️ **표는 3열 이하(마스터 2-5·2-6).** 4종 세트는 가로로 늘어놓지 말고 **2열(항목/값) 세로 표**로.

### ④ 스크롤 테스트

> 소제목과 볼드만 이어서 읽어본다.
> **「주차 어디 / 얼마나 걸림 / 얼마나 힘듦」** 세 가지가 답해지면 합격.

마스터 §4-1의 자가 검증("내용이 잡히면 합격")보다 기준이 구체적이다.
등산 글은 답이 정해져 있으므로 그 답이 나오는지로 검사한다.

# 2. ✍️ 등산 용어에 쉬운 설명을 붙인다

**`초보 등산 코스`로 들어온 사람은 등산 용어를 모른다.**
"들머리"라고 쓰면 초보는 거기서 멈춘다.

검색어이기도 하므로 지우지 말고 **바로 옆에 쉬운 말**을 붙인다.

| 용어 | 옆에 붙일 설명 |
|---|---|
| 들머리 | 산에 들어가는 입구 |
| 날머리 | 내려와서 빠져나오는 곳 |
| 원점회귀 | 출발한 자리로 되돌아오는 코스 |
| 능선 | 산등성이. 봉우리끼리 이어진 길 |
| 안부 | 능선이 잠깐 낮아지는 잘록한 곳 |
| 깔딱고개 | 숨이 턱까지 차는 가파른 구간 |
| 조망 | 트여서 내려다보이는 경치 |
| 알바 | 길을 잘못 들어 헤매는 것 |
| 사면 | 산비탈 |
| 누적고도 | 오르내린 높이를 다 더한 값 |
| 아웃솔 / 미드솔 | 신발 바닥 / 바닥과 깔창 사이 쿠션층 |

```
⭕ 들머리(산에 들어가는 입구)는 사직공원 쪽이야.
⭕ 원점회귀 코스야. 출발한 자리로 돌아온다는 뜻.
```

**검사법** — 소리 내서 읽어본다. 중학생이 사전 없이 읽을 수 있는가.

# 3. 🔑 키워드 티어

## 🔴 Tier 1 — 대형 검색어 (단독 공략 금지)

`등산 코스 추천` `서울 근교 등산` `등산 초보` `등산 준비물`

상위가 전부 언론사·지자체·대형 정보사이트. 신규 카테고리로 정면 승부하면 안 된다.
글이 쌓인 뒤 **허브 글**로 재도전.

## 🟢 Tier 2 — 산 이름 + 등산코스 (주력)

`계양산 등산코스` `관악산 등산코스` `문학산 등산코스` `마니산 등산코스`

**개인 블로그가 실제로 상위에 올라와 있는 유일한 진입 구간.**
→ 산 하나당 글 하나. 이게 메인이다.

## 🔵 Tier 3 — 조건 결합 롱테일 (선점 가능)

`계양산 주차` `○○산 계단` `여자친구랑 등산` `부모님과 갈만한 산`
`인왕산 운동화` `등산 운동화 가능`

경쟁이 거의 없고 의도가 뾰족하다(마스터 1-5 롱테일). **Tier 2 글 안의 소제목으로 흡수**시킨다.

## 🟡 Tier 4 — 시즌

`단풍 산행` `가을 등산 코스` `○○산 단풍 시기` `억새 명소`

**시즌 글은 정점 2~3주 전**에 발행한다(마스터 14장). 검색량은 지금 값이 아니라 정점 때 값으로 본다.
끝나는 날이 있는 행사(축제)성 글만 **이벤트 2~5일 전**을 따로 본다(축제 지침 2장).
단풍 절정 시기는 최근 지연 추세이므로 **발행 직전 산림청·기상청 관측으로 재확인.**
작년 날짜 재활용 금지.

⚠️ **검색량 절대수치는 미확인(마스터 0-4).** 위 티어는 상위 노출 글의 성격·경쟁자 유형에서 역추정한 것.
수치를 본문에 쓰려면 블랙키위나 네이버 검색광고 키워드도구로 직접 조회할 것.

# 4. 💎 검색 공백 — 등산에서 이길 수 있는 곳

## ① 상위 글이 전부 「리스트업 기사」다

`BEST 10`, `TOP 4`, `추천 5곳` — 한 산을 10줄씩 훑고 지나간다.
**실제로 다녀온 사람의 한 코스 심층 글이 거의 없다.**

→ 개인 블로그의 유일하고 확실한 우위. 리스트업을 흉내내지 말 것. **한 편에 한 산.**

## ② 소요시간이 전부 추정치다

어느 글도 신뢰할 구간 기록을 제시하지 못한다.

→ **EXIF 타임스탬프 기반 구간별 실측표.** 이게 결정적 무기다.

```
들머리 15:39  →  첫 조망 15:46  (7분)
첫 조망 15:46  →  바위 구간 16:00  (14분)
바위 구간 16:00 →  정상 16:37  (37분, 휴식 15분 포함)
안내판 표기 2시간 / 실측 43분 (휴식 제외)
```

⚠️ **실측표는 사진 내용을 눈으로 판독한 뒤 만든다.**
파일명 순서와 업로드 표시 순서가 다를 수 있다. 2026.09.13에 이 가정으로
사진 5장의 캡션이 틀어진 사고가 있었다. 반드시 컨택트시트로 전량 확인.
(라벨은 마스터 §5-3대로 이미지 **위에** 얹는다)

## ③ 동반자 조건 콘텐츠가 Q&A로만 존재한다

`여자친구랑 등산` `부모님과 갈만한 산`을 검색하면 아하·커뮤니티 잡담만 나온다.
**실제 코스 추천 글이 없다.**

→ 멤버 동반 산행 기록이 그대로 이 공백을 메운다.

# 5. 🏷️ 제목 — 등산 적용판

제목 공식·질문형 후킹은 마스터 10-5, 후킹 문장 공식과 쓰는 순서는 10-6, 제목 속 숫자는 0-5(확정된 것만)를 따른다.
**유입 경로별 두 꼴은 10-7** — 등산코스·장비 글은 검색형이 기본: 앞에 「산 이름 + 등산코스 + 주차·소요시간·최단코스 같은 함께 찾는 명사 2~3개」, 구분선 뒤에 내 문장. 「등산을 왜 하는 건데」 같은 회고 글만 홈판형.
**앞 검색어·소주제 명사는 점검표를 보고 고른다 — 마스터 10-8** (`title_check.py --q "산 이름 등산코스"`, 표는 인수인계서 1절에). 「○○산」 하나는 큰 말이라 그대로 앞에 두지 않고 「○○산 등산코스 주차」처럼 표에서 지수 0.1 이상인 말로 좁힌다.
등산에서 달라지는 것만 적는다.

## 숫자는 이미 갖춰져 있다

여행은 경비를 정산해야 숫자가 나오지만, 등산은 원래부터 숫자가 있다.

| 여행 | 등산 대응 |
|---|---|
| 금액 (429만원) | **거리 (왕복 5km)** |
| 기간 (5박6일) | **소요시간 (43분)** |
| 인원 (1인/2인) | **고도 (338m, 산림청 값 — 12장)** / 인원 |
| 세부 항목 (저녁 세 끼 39만원) | **난구간 (로프 구간)** / 주차비 / 뒤풀이 비용 |

**뒤풀이·주차비가 있으면 금액도 넣는다.** 등산은 무료라 경비 검색이 약할 것 같지만,
`등산 후 맛집`·`주차비`는 실제 지출이라 여행 글의 경비 키워드와 같은 역할을 한다.

## 뒷부분도 검색어를 겸할 수 있다

정보 검색 의도가 강해서 감성 후킹보다 구체 조건이 더 클릭된다.

> **분야 예외(등산 예시)** — 아래 4가지는 마스터에 없는 등산 고유 예시다. 10-6 다섯 공식을 대신하는 게 아니라, 그 공식에 넣을 **등산 재료**를 모아 둔 것이다.

| 유형 | 예 | 손에 있어야 할 재료 |
|---|---|---|
| 비교 구도 | `산은 공짜인데 뒤풀이가 17만 5천원` | 뒤풀이 영수증 |
| 의외의 세부 | `2시간 걷고 3시간 먹었다` | 사진 EXIF 시각 |
| 결핍·미완 | `정상 못 가고 내려온 이유` | 돌아선 지점 사진·시각 |
| 판단 유보 | `안내판이랑 실제가 달랐다` | 안내판 사진 + 실측표 |

🚨 **후킹은 다녀온 뒤에 쓴다.** 가보기 전에 쓴 후킹은 추측이고, 현장이 다르면 낚시가 된다.
**재료 칸이 비면 후킹을 만들지 않는다.** 뒤집을 숫자·장면이 없으면 발견형 평서문으로 간다(마스터 10-6 「쓸 때 순서」 2).

**금지**: `등린이의 첫 산행기` 같은 일기 제목. 검색 기여 0.

# 6. 🚫 비유는 여행·읽기·생활에서만

마스터 §3(공학·직업 비유 금지)이 제시한 대체 출처는
**걷기·등산 / 여행 / 읽기 / 생활** 네 곳이다.

**그런데 등산 글에서는 등산이 이미 본문이다.**
배낭 꾸리기를 비유로 쓰면 비유가 아니라 그냥 서술이 된다.
(게로 시리즈에서 배낭 비유가 작동한 건 그게 *여행* 글이라 등산이 바깥 재료였기 때문)

→ **등산 글의 비유 재료는 여행 · 읽기 · 생활 세 곳에서만.** (분야 예외 — 마스터 3장의 「걷기·등산」을 등산 글에서는 뺀다)

→ 같은 비유를 글마다 돌려 쓰지 않는다(마스터 3-1, 10.16). 대표 비유는 한 글에 하나, 쉬는 말(문·칸·계단·뚜껑)은 비유로 한 번까지 — 등산 글의 「계단」은 실제 계단 구간이면 그대로 쓴다. 대신 쓴 말도 비유 장부(`metaphor_ledger.py`)가 센다 — 등산 글은 「단계」「지도」처럼 말 그대로 쓰는 말이 많아 ⚠가 떠도 비유가 아니면 그대로 둔다.

| 출처 | 등산 글에서 쓸 만한 재료 |
|---|---|
| **여행** | 일정 짜기, 예약하며 놓친 것, 환승, 짐 싸기 |
| **읽기** | 책에서 본 것 *(억지로 끌어오지 말 것)* |
| **생활** | 사진첩, 메모장, 미뤄둔 일, 약속 시간 |

**적용 예**

| 대신 쓰지 않을 것 | 쓸 것 |
|---|---|
| 목적지에서 역산한 설계 | 여행 일정 짤 때 저녁 먹을 데를 먼저 정하면 동선이 역산된다 |
| 협상 불가한 데드라인 | 비행기 시간 같은 거야. 늦으면 그날이 통째로 어긋나 |
| 페일세이프 | 안 쓰면 제일 좋은 짐이 있다 |
| 좋은 기능을 다 넣은 스펙 | 짐 쌀 때 「이 여행에 이게 필요한가」를 묻는 것 |

⚠️ **안내판 표기 vs 실측**은 비유가 아니라 글의 실제 내용이므로 그대로 서술한다.

# 7. 📸 촬영 체크리스트 (계획 단계에서 확정)

사진을 먼저 보고 초안을 짜므로, **못 찍은 컷은 못 쓰는 문단**이 된다.

| 컷 | 용도 | 우선순위 |
|---|---|---|
| 들머리 표지판·안내지도 | 코스명 텍스트 확보, "어디서 시작" 답변 | ★★★ |
| **갈림길 이정표 전부** | 실측표의 구간 분할점. 남들이 안 찍음 | ★★★ |
| 주차장 (입구·요금표·혼잡도) | `○○산 주차` 단독 검색어 | ★★★ |
| 난이도 증거 (계단·바윗길·로프) | "얼마나 힘든가"의 유일한 물증 | ★★ |
| 화장실·식수·매점 | 동반 산행일수록 검색됨 | ★★ |
| 정상석 | 인증 + 도착 시각 앵커 | ★★ |
| 조망 (방향 메모 필수) | 썸네일 후보 | ★★ |
| 하산 후 식당 외관·메뉴판·음식 | `등산 후 맛집` 키워드 | ★★ |
| 인물 컷 | Moments 에세이 분리용 | ★ |

**원칙: 각 이정표마다 무조건 한 장.** 예쁘지 않아도 찍는다. EXIF가 목적이다.

**그 자리에서 메모할 것** — 조망 사진의 방향, 뒤풀이 결제 금액과 인원수.
나중에 기억으로 복원하면 그게 곧 추정치다.

## 🖼️ 썸네일은 따로 의식하고 찍는다

홈판(피드) 유입이 주력이다 — 홈판 비율 59.81 → 61.93 → 63.74% (우리 블로그 3주 통계, 2026.9 기준 · 마스터 16-2).
피드에서 보이는 건 제목이 아니라 **본문 첫 사진**이다.
기준은 마스터 §5-4·16-7(대표이미지는 1:1로 잘라 지정)을 따르되, 등산에서 갈리는 지점은 이렇다.

**썸네일 세 질문(마스터 5-4, 10.15)** — 등산은 ②가 쉽다. 코스 글은 **정상석**, 장비 글은 **그 장비를 찍은 내 사진**이 ①②③을 한 번에 채운다(조회수 상위의 용마산·인왕산·수암봉·등산화 두 편). 능선·하늘만 있는 풍경은 어느 산인지 몰라 ②✕, 가는 길 사진은 ①✕.

| 후보 | 적합도 | 이유 |
|---|---|---|
| 정상석 | ★★★ | 형태 명확, 글자 커서 축소해도 읽힘 |
| 음식 (뒤풀이) | ★★★ | 단일 피사체 + 강한 색 |
| 로프·바위 구간 | ★★ | 선이 살아 있으면 강함 |
| **서울·도시 조망** | ★ | ⚠️ 디테일 과다 → 축소하면 회색 덩어리 |

💡 **산행 글이라고 정상 조망을 맨 앞에 두는 게 오히려 손해일 수 있다.**

🚫 **(2026.10.9 마스터 5-4 동기화) 장비 실측·비교 글(무게표·그래프 카드가 들어가는 글)도 첫 이미지는 카드가 아니다.** 그 장면을 찍은 내 사진(저울 위 장비, 신발 밑창)이 먼저, 없으면 5-5 조건의 AI 장면 한 장. 표·그래프 카드는 두 번째부터.
현장에서 판단하지 말고 후보를 여러 장 확보한 뒤 **갤러리 격자 보기**로 비교.

# 8. 🗂️ 카테고리 구조 — Move 아래 「등산」과 「장비」

주제 설정은 **국내여행** (마스터 13-3). 카테고리 트리와 넣는 기준은 **마스터 13장이 정본**이다. 여기엔 등산 쪽 적용만 적는다.

## 지금 구조 (2026.9 하순 확정)

```
Move
 ├ 등산   ← 산 이름이 들어가는 글 전부. 지역별로 쪼개지 않는다
 ├ 장비   ← 종목 무관. 등산화·배낭·스틱·풋살화
 └ (축구 · 농구 …)
```

- 예전의 `Hiking > 서울 / 인천 / 경기`와 `등산 준비·장비`는 **쓰지 않는다.** 「서울 산행」은 「등산」으로, 「등산 준비·장비」는 「장비」로 합쳤다
- 지역은 카테고리가 아니라 **제목·소제목·태그**로 잡는다 (`#서울등산` `#경기등산`)
- 해외 트레킹은 Travel의 해당 지역에 둔다. 기존 캐나다 로키·미국 국립공원 글은 옮기거나 복제하지 않는다 — 이미 색인돼 유입이 도는 글이다

**되돌릴 수 있는 결정이다.** 네이버는 글 주소가 글 번호 기반이라 카테고리를 옮겨도 주소가 안 바뀐다.

## 들머리 기준은 그대로 쓴다 — 카테고리가 아니라 본문에

| 산 | 애매한 이유 |
|---|---|
| 북한산 | 서울 / 경기 고양 걸침 |
| 관악산 | 서울 / 경기 안양·과천 걸침 |
| 수리산·수암봉 | 경기지만 서울 근교로 검색됨 |

**정상 위치가 아니라 실제로 올라간 입구로 쓴다.** 주차·교통·화장실이 전부 들머리 기준이고, 지역 태그도 들머리를 따른다.

## 등산 / 장비 / 정보 — 배치 판정

> **"이 글 제목에 특정 산 이름이 꼭 들어가야 하나?"**
> 들어가야 하면 → **등산**
> 물건(신발·배낭·스틱) 이야기면 → **장비**
> 산을 고르는 방법·도구·시기처럼 찾아보면 답이 있는 것이면 → **Travel > 정보**

| 등산 | 장비 | 정보 |
|---|---|---|
| 특정 산의 코스·주차·소요시간 | 등산화·배낭·스틱 후기와 사이즈 | 산 찾기 시리즈 (조건으로 산 고르기) |
| 특정 산의 단풍·억새 시기 | 오래 쓴 장비 상태 | 단풍 절정 시기처럼 전국 단위 정보 |
| 산행 후기 | 풋살화 (종목 무관) | |

⚠️ **조사한 내용을 빼내지 말 것.** 계양산 갈 때 조사한 주차 정보는 계양산 글 안에 있어야 `계양산 주차`로 걸린다.

💡 **장비 칸이 체험단 진입로다.** 아웃도어 캠페인 심사자가 보는 건 코스 글이 아니라 장비 후기가 쌓여 있는지다.

⚠️ `등산 초보 준비물`은 Tier 1이다. 쓰더라도 개인 경험으로 각도를 좁힐 것.

## ❌ 하지 말 것

- **지역 카테고리 다시 만들기** — 글이 흩어져 칸마다 한두 편이 된다
- **100대 명산을 카테고리로 만들기** — 완주 압박 + 지방 원정 중심이라 수도권 집중 전략과 충돌. **제목·해시태그의 시리즈 이름으로만** 쓴다 (`#100대명산`)
- **기존 Travel의 해외 산행 글 이동·복제** — 복제는 유사문서 위험

# 9. 📊 등산이 유입 구조에서 갖는 위치

**등산 코스 글은 "검색으로 오래 걸리는 실무 정보" 타입이다.**
`○○산 등산코스`·`주차`·`소요시간`은 계절마다 되살아나는 검색어라,
여행 글의 `경비`·`일정`·`숙소`와 같은 역할을 한다.

→ 등산 카테고리 신설은 유입 다변화가 아니라 **검색 자산 축적**으로 봐야 한다.

운영 방향은 **마스터 14장**(지금은 확장이 먼저)을 따른다.
등산은 여행을 대체하는 게 아니라 검색 기반을 넓히는 축이다(마스터 10-1·16-2·16-3).
인왕산·서촌처럼 도심 산행은 서울 나들이 콘텐츠와도 겹쳐 시너지가 난다.

## 핫토픽 관찰 (2026.09)

네이버 블로그홈 핫토픽에 **`등산 일기`** 가 걸린 것 확인. 홈판 기회가 열린 시기.

⚠️ **단, 핫토픽에 뜬 글들은 감성 일기 + 동영상 형식이다.** 코스 정보 글과는 다른 게임.

| | 코스 정보 글 | 일기·감성 글 |
|---|---|---|
| 유입 경로 | 검색 | 피드·홈판 |
| 지속성 | 오래 감 (자산) | 휘발성 |

→ **주력은 코스 정보. 가끔 일기형을 섞어 홈판을 노린다.**
일기형은 Moments 또는 Move > 등산(마스터 13-1)에 배치.

**사진과 글은 번갈아.** 글자만 꽉 찬 구간이 한 화면을 넘기지 않게.
분량은 **마스터 2-10**(본문 2,000자 이상)을 따른다. 4종 세트·길찾기·실측표가 들어가면 저절로 넘는다. 인포그래픽 카드(캡션 「직접 만든 그림·도해」)가 3장 이상이면 2,000자 조건은 만족한 것으로 본다(마스터 2-10 인포그래픽 예외, 10.12).
구분선·문단은 마스터 4-2, 해시태그는 2-7.
⚠️ **채우려고 늘리지 말 것.** 밀도가 떨어지면 찾던 답이 파묻힌다.

# 11. ✅ 등산 고유 체크 (마스터 9장·15장 체크리스트에 덧붙임)

- [ ] 글감을 정하기 전 **블로그 전체 글 목록**과 대조했는가 — 같은 산·같은 코스면 새 글이 아니라 후속·수정 (마스터 9장)
- [ ] 4종 세트 표가 스크롤 1회 안에 보이는가
- [ ] 표가 **2열(항목/값) 세로**인가 — 모바일 잘림 방지
- [ ] **소제목이 섹션 이름이 아니라 답 문장**인가
- [ ] 소제목에 산 이름·지명·랜드마크가 들어갔는가
- [ ] **스크롤 테스트** — 소제목+볼드만 읽어 「주차/시간/난이도」가 답해지는가
- [ ] 등산 용어에 쉬운 설명을 붙였는가 (들머리·능선·원점회귀·아웃솔)
- [ ] 실측표가 있고, **사진 내용을 눈으로 판독한 뒤** 만들었는가 ⭐
- [ ] 비유가 여행·읽기·생활에서 왔는가 (등산 재료 금지)
- [ ] 안내판 표기와 실측을 구분해 썼는가
- [ ] 첫 사진(썸네일)이 도시 조망이 아닌가 — 축소 시 뭉개짐
- [ ] 대표이미지를 **1:1로 잘라** 지정했는가, 글 끝에 관련 글 **1~2개**를 붙였는가 — 미발행 글은 링크 안 함 (마스터 16-7 · 2-4)
- [ ] AI 이미지를 썼다면 마스터 **5-5** 그대로인가 — 캡션 `(AI 생성 이미지)`, 글자·로고·얼굴 없음. 5-6 삽화 규칙은 Travel 전용이라 등산엔 적용 안 함
- [ ] 카테고리 주제가 **국내여행**인가
- [ ] 카테고리가 **Move > 등산** 또는 **Move > 장비**인가 (옛 Hiking > 서울 ❌)
- [ ] 높이를 **산림청 값**으로 썼는가 — 프로그램·GPS 최고점을 산 높이처럼 쓰지 않았는가
- [ ] 예상 시간에 "휴식 제외 계산값"을 붙였는가, 예고한 예상치를 실측과 나란히 썼는가
- [ ] 산 찾기 프로그램은 **"직접 만든 조회 프로그램" 한 줄**로만 — 어떻게 만들었는지는 본문에 쓰지 않았는가 (마스터 0-9)
- [ ] 발행 속도 **하루 3편 기본, 최대 5편** (마스터 15장, 2026.10.07 변경)

# 12. 📐 프로그램 값·실측 — 2026.9 하순에 생긴 규칙

마스터 0-9(실험·실측 글)를 등산에 적용한 것이다. 산 찾기 프로그램과 GPS 기록을 쓰기 시작하면서 생겼다.

| 값 | 어떻게 쓰나 |
|---|---|
| 산 높이 | **산림청 산정보 값.** GPX 최고점은 그 기록이 오른 높이일 뿐이다 (인왕산 공식 338m, 기록 361m) |
| 거리 | **들머리에서 정상까지 한 경로**의 값만. 등산로 망을 이어 붙인 값은 쓰지 않는다 (수암봉이 21km로 나온 적이 있다 — 실제 2.3km) |
| 예상 시간 | "휴식 제외 계산값"이라고 매번 붙인다 |
| 정상에 안 가는 기록 | 표에 경고가 붙은 짧은 코스는 정상까지 안 간다. 짧다고 고르지 않는다 |
| 역까지 거리 | 직선거리다. 실제 도보는 지도로 다시 본다 |
| 조명·야간 개방·통제 구간 | 자료에 없다. 「프로그램이 모르는 것」으로 솔직하게 쓴다 |

**예고했으면 대조한다.** 산 찾기 글에서 "예상 57분"을 적었으면 산행 글에서 실측과 나란히 쓴다.
(용마산: 예상 57분 → 실측 54분. 수암봉: 주차장에서 정상 38분.)

**시리즈 흐름** (마스터 12장 연결 자산)
- 산 찾기: 조건으로 고르기 → 그 산을 실제로 감 → 산행 글. 각 글은 앞 글을 링크한다
- 장비: 고르는 법 → 사이즈 → 첫 산행. 새 장비의 첫 산행은 장비 글과 산행 글 두 편이 된다

**시즌 창** — 억새(10월)·단풍·눈꽃처럼 철이 있는 산은 날짜를 확정하지 않고 창만 적어 둔다(마스터 15장). 겨울 장비 글은 정점(12월 말~1월 초) 2~3주 전에 올린다.
