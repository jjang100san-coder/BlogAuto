# 초안 작성·발행 추가 지침

> `초안작성_프롬프트.md`에 **덧붙이는** 문서.
> 발행 형식과 자동화 검증에 관한 내용만 다룬다. 콘텐츠 소재·시리즈별 내용은 여기 없다.
> 충돌하면 **이 문서가 우선**한다.
>
> 작성: 2026.9.7
>
> 📄 **새 채팅방에는 `초안작성_규격요약.md` 한 장만 올린다.**
> 이 문서는 왜 그렇게 정했는지까지 담고 있어 길다. 규칙을 바꾸면 두 파일을 같이 고친다.

## 📋 새 채팅방에 붙여넣을 요약

```
[초안 작성 추가 지침]

1. 링크는 [[LINK:URL | 표시할 텍스트]] 마커로 쓴다.
   마크다운 링크 [텍스트](URL)는 여전히 금지.
   URL이 아직 없으면 파이프 앞을 비워두고 본문에 넣어둔다.

2. 마커 인자 순서는 전부 "대상 | 사람이 읽을 말".
   [[IMG:파일명 | 캡션]] / [[LINK:URL | 텍스트]]

3. 발행 직전 검증에 걸리면 발행을 멈춘다.
   - 이미지 파일이 폴더에 없음 → 중단
   - LINK의 URL이 비어 있음 → 중단
   - TITLE/CATEGORY 누락, 경계선 불일치 → 중단
   - 미지원 마크다운 잔존, 표 4열 이상 → 경고 후 진행

4. 오류 메시지에는 줄 번호와 해당 마커 원문을 같이 띄운다.
```

---

# 1. 🔗 링크 마커 신설

## 표기

```
[[LINK:https://blog.naver.com/baiyan_novembre/223xxxxxxx | 3편 깎아달라고 했다가 2.5% 더 주고 샀어]]
```

- **파이프 앞이 URL, 뒤가 표시할 텍스트.**
- 마커는 **단독 줄**에 둔다. 문장 중간에 넣지 않는다.
- 자동화가 네이버 텍스트 링크 서식으로 변환한다.

## 왜 마크다운 링크를 안 쓰나

`[텍스트](URL)` 문법은 대괄호와 소괄호를 쓰는데, 이 기호는 본문에 자연스럽게 등장한다.
`(2026년 8월 기준)` 처럼 괄호를 쓰는 문장 앞에 대괄호 표현이 오면 파서가 링크로 오탐할 수 있다.

`[[` 는 일반 글쓰기에서 나오지 않는 조합이고,
이미 `[[TITLE:]]` `[[CATEGORY:]]` `[[IMG:]]` 가 전부 이 규칙이다.
**링크만 다른 문법을 쓰면 "마크다운 기호는 안 쓰고 마커만 쓴다"는 원칙에 예외가 생긴다.**

→ 기존 금지 목록의 `링크 [텍스트](url)` 항목은 **그대로 유지**한다.

## 인자 순서는 IMG와 통일한다

| 마커 | 앞 | 뒤 |
|---|---|---|
| `[[IMG:파일명 \| 캡션]]` | 대상(파일) | 사람이 읽을 말 |
| `[[LINK:URL \| 텍스트]]` | 대상(주소) | 사람이 읽을 말 |

원칙은 **대상이 앞, 사람이 읽을 말이 뒤.**

## URL이 아직 없을 때

**본문에서 빼지 않는다.** 파이프 앞을 비운 채로 본문에 둔다.

```
[[LINK: | 3편 깎아달라고 했다가 2.5% 더 주고 샀어]]
```

작업 메모로 빼두면 발행 후에 붙여넣는 걸 잊는다.
본문에 있으면 눈에 보이고, 검증에도 걸린다.

## 머리말(▶ 1편:)은 링크에 넣지 않는다

`▶ 1편:` 같은 편수 머리말까지 파랗게 밑줄이 그어지면 줄이 지저분해진다.
**머리말은 검은 글씨로 두고, 제목 부분만 링크로 건다.**

편수 머리말은 **자동으로 인식해서 빼주고, `▶ 1편 : ` 꼴로 맞춰서 넣는다.**
초안에 어떻게 적혀 있든 발행되는 모양은 같으니 콜론 위치를 신경 쓸 필요 없다.

```
[[LINK:URL | ▶ 1편 아내는 평생 소원이라 했고, 나는 숫자를 댔어]]
[[LINK:URL | ▶1편: 2주를 차로만 돌았는데 남는 게 없었어]]
[[LINK:URL | 3편. 깎아달라고 했다가 2.5% 더 주고 샀어]]
```
```
발행 결과
▶ 1편 : 아내는 평생 소원이라 했고, 나는 숫자를 댔어
▶ 1편 : 2주를 차로만 돌았는데 남는 게 없었어
3편 : 깎아달라고 했다가 2.5% 더 주고 샀어
        ^^^^^^^^^^^^^^^^^^^^^^^^^^ 여기부터만 링크
```

인식되는 꼴은 `▶`(또는 `▷ ► >` / 없어도 됨) + 숫자 + `편` + `: . ：`(생략 가능) 이다.
**`▶`를 안 쓰면 결과에도 안 붙는다.** 시리즈 링크에는 붙여 쓰는 걸 권한다.

편수 머리말이 아닌 걸 빼고 싶으면 **파이프를 하나 더 써서 직접 나눈다.**
앞이 안 걸리는 부분, 뒤가 링크다.

```
[[LINK:URL | 참고 | 국세청 퇴직소득세 안내]]
        →  참고 국세청 퇴직소득세 안내
                ^^^^^^^^^^^^^^^^^ 여기만 링크
```

## 카드형이 아니라 텍스트 링크

네이버는 URL만 붙이면 카드형 미리보기가 된다.
시리즈 링크가 서너 개 쌓이면 글 끝이 무거워지므로 **텍스트 링크를 기본으로** 한다.

# 2. ✅ 발행 직전 검증

발행 버튼을 누르기 전에 md 파일을 한 번 훑고, 걸리면 알린다.

## 중단 — 발행을 진행하지 않는다

| 검사 | 이유 |
|---|---|
| `[[IMG:]]`의 파일이 폴더에 없음 | 이미지가 빠진 채로 발행됨 |
| `[[LINK:]]`의 URL이 비어 있음 | 링크가 죽은 채로 발행됨 |
| `[[TITLE:]]` 또는 `[[CATEGORY:]]` 누락 | 제목·분류 없이 올라감 |
| 경계선 두 줄이 정확히 일치하지 않음 | 작업 메모가 본문에 섞여 발행됨 |

**경계선은 글자 하나도 달라지면 안 된다.** 띄어쓰기·이모지 포함.

```
===== ✂️ 여기부터 복사 =====
===== ✂️ 여기까지 =====
```

## 경고 — 알리고 진행한다

| 검사 | 이유 |
|---|---|
| 본문에 `##` 헤딩 잔존 | 네이버에서 글자로 찍힘 (`#태그`는 제외) |
| 본문에 `- ` `* ` 목록 기호 잔존 | 기호가 그대로 노출됨 |
| 표가 4열 이상 | 모바일에서 잘림 |
| 코드블록 잔존 | 대응 서식 없음 |
| 본문에 `【` 잔존 | 구형 사진 마커를 안 지운 것 |

이쪽은 발행돼도 복구 가능한 수준이라 중단까지 갈 필요는 없다.

## 오류 메시지 형식

**어디가 문제인지 바로 찾을 수 있어야 한다.**

```
❌ 발행 중단 (2건)

  [줄 42] 이미지 파일 없음
     [[IMG:6-4.png | 잔금일 아침]]
     → 폴더에 6-4.png 가 없습니다

  [줄 118] 링크 URL 비어 있음
     [[LINK: | 5편 계약금 중도금은 있는데 잔금만 없었어]]

⚠️ 경고 (1건)

  [줄 77] 표가 4열입니다 — 모바일에서 잘릴 수 있습니다
```

"이미지 없음"만 뜨면 어느 마커인지 찾아야 한다.
**줄 번호와 마커 원문을 같이 띄운다.**

# 3. 📎 마커 요약

| 마커 | 구역 | 형식 |
|---|---|---|
| `[[TITLE: ]]` | A | 한 줄. 줄바꿈 금지 |
| `[[CATEGORY: ]]` | A | 한 줄 |
| `[[IMG:파일명 \| 캡션]]` | B | 단독 줄. 파일명은 목록에서 그대로 복사 |
| `[[LINK:URL \| 텍스트]]` | B | 단독 줄. URL 없으면 앞을 비움. `▶ 1편 : ` 머리말은 자동 정규화 + 링크 제외 |
| `[[LINK:URL \| 머리말 \| 텍스트]]` | B | 파이프를 하나 더 쓰면 앞부분을 링크에서 직접 뺀다 |

**본문(구역 B)에 허용되는 것**

발행될 문장 / 위 두 마커 / 이모지 소제목 / `---` 구분선 /
마크다운 표(3열 이하) / `**볼드**` / 해시태그 한 줄

**본문에 두지 않는 것**

`##` 헤딩 · `- ` 목록 · 코드블록 · 마크다운 링크 ·
