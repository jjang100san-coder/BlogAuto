> 파일명 `img1.png` ~ `img6.png`로 저장. 캡션에 전부 "AI로 만든 이미지야".

> 🚫 글자·숫자·통화 기호(¥ ₩ $)·은행 로고·유튜브 로고 없음. 그래프는 막대 높이로만.

## 공통 스타일 문구 — 모든 프롬프트 맨 앞

```
따뜻한 색감의 평면 일러스트(플랫 벡터 스타일). 굵은 외곽선 없이 면으로 표현.
색은 크림색 배경 + 연파랑 + 진남색 + 포인트 색 하나. 여백 넓게, 요소 2~3개만 크게.
사람은 뒷모습이나 실루엣만. 텍스트, 숫자, 통화 기호, 로고, 워터마크 없음. 16:9.
```

썸네일(img1)만 정사각형(1:1).

## img1.png — 썸네일 (높이가 다른 동전 탑 두 개)

```
[공통 스타일 문구] + 정사각형 + 포인트 색 금색.
나무 책상 위에 진남색 여권 한 권이 놓여 있고, 그 위에 무늬 없는 금색 동전 탑 두 개가 나란히 서 있다.
왼쪽 탑은 낮고 오른쪽 탑은 그보다 두 배쯤 높다. 동전 표면은 완전히 매끈하고 아무 무늬도 글자도 없다.
뒤쪽 창밖으로 눈 덮인 꼭대기를 가진 원뿔형 산 실루엣이 연파랑 하늘에 작게 보인다.
두 탑의 높이 차이가 한눈에 보이는 게 핵심. 요소는 여권, 동전 탑 둘, 창밖 산뿐.
```

## img2.png — 일본은행 금리 인상 (한 칸 올라간 계단)

```
[공통 스타일 문구] + 포인트 색 주황.
화면 가운데 연파랑 막대 다섯 개가 계단처럼 왼쪽에서 오른쪽으로 조금씩 높아진다.
맨 오른쪽 막대만 주황색이고 바로 앞 막대보다 한 칸 더 올라가 있다. 막대에 숫자나 눈금 없음.
막대 꼭대기 위에 작은 종이 초롱 하나가 걸려 있다.
배경은 크림색 여백, 아래쪽에 얇은 바닥선 하나.
```

## img3.png — 금리를 올렸는데 가치는 내려가는 역설 (에스컬레이터 두 대)

```
[공통 스타일 문구] + 포인트 색 파랑.
공항 같은 넓은 실내에 에스컬레이터 두 대가 나란히 있다.
왼쪽 에스컬레이터는 위로 올라가고, 그 위에 작은 주황색 화살표 표지(글자 없음)가 붙어 있다.
오른쪽 에스컬레이터는 아래로 내려가고, 그 위에 무늬 없는 금색 동전 몇 개가 실려 내려가고 있다.
두 에스컬레이터 사이에 캐리어를 든 사람의 뒷모습 하나가 서서 둘을 번갈아 보고 있다.
```

## img4.png — 같은 주에 네 개의 숫자 (스마트폰 네 대)

```
[공통 스타일 문구] + 포인트 색 겨자 노랑.
책상 위에 스마트폰 네 대가 가로로 나란히 세워져 있다.
각 화면에는 막대 하나씩만 그려져 있는데, 네 막대의 높이가 전부 조금씩 다르다. 화면에 글자·숫자·재생 버튼·로고 없음.
스마트폰 옆에 커피잔 하나와 펼친 수첩 하나. 수첩에도 글자 없이 선만.
네 막대 높이가 서로 다르다는 게 핵심.
```

## img5.png — 여행자가 보는 환율은 따로 있다 (세 동전 더미의 삼각형)

```
[공통 스타일 문구] + 포인트 색 초록.
크림색 바닥 위에 무늬 없는 동전 더미 세 개가 삼각형 꼭짓점 자리에 놓여 있다.
세 더미는 테두리 색만 다르다 — 하나는 파랑, 하나는 초록, 하나는 붉은 테두리. 동전 표면에 무늬·글자·기호 없음.
세 더미 사이를 가느다란 점선 화살표가 서로 잇고 있고, 초록 더미와 붉은 더미를 잇는 화살표만 굵고 진하다.
삼각형 안쪽에 작은 캐리어 하나.
```

## img6.png — 마무리 (나눠서 바꾸는 달력)

```
[공통 스타일 문구] + 포인트 색 금색.
벽에 걸린 숫자 없는 달력 한 장. 칸 중 세 곳에 무늬 없는 작은 금색 동전 더미가 하나씩 놓여 있다. 세 칸은 서로 떨어져 있다.
달력 아래 바닥에 반쯤 싼 캐리어가 열려 있고, 그 위에 진남색 여권 한 권.
창밖은 이른 저녁. 사람은 없다.
```
