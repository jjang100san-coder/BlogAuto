## 2. NomaDamas/k-skill — 한국 생활 스킬 131개 (★8.0k · MIT · 최근 커밋 2026-10-08)

설치: `npx -y skills add NomaDamas/k-skill --skill <이름> -g` 또는 Claude Code `/plugin marketplace add NomaDamas/k-skill`. 스킬 하나는 `SKILL.md`(짧은 안내) + `instruction.md`(실제 절차) + `scripts/`(파이썬 stdlib) 꼴. 상표·법률 면책문(`references/`)을 스킬마다 둔다.

### 2-1. 구조에서 미리 알아둘 것

- **프록시 의존**: 법령·KOSIS·ECOS·기상청·열린국회·천문연·뉴스 검색 등 「키 없이 된다」는 스킬은 운영자 서버 `k-skill-proxy.nomadamas.org`를 거친다(AGPL). 운영자가 키를 들고 대신 호출해 주는 구조라 **그 서버가 멈추면 같이 멈춘다**. 직접 키로 부르는 `--direct` 경로도 있어서, 우리는 `_문서\datago_check_2026-10-16.md`에 적힌 승인 키로 직접 호출하는 쪽이 맞다.
- **CLI 의존**: 안내문이 `npx -y @nomadamas/k-skill@0 exec <스킬> scripts/x.py` 꼴인데, 스크립트 자체는 `python3 scripts/x.py`로 바로 돈다. 옮길 때는 npx 없이 쓴다.
- **스크립트는 깨끗함**: `naver-blog-research` 4개 파일(744줄)을 읽은 결과 urllib·re만 쓰고, 파일 쓰기는 `--output` 폴더뿐.
