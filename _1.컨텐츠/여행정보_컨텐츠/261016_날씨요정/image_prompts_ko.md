- 도구: Higgsfield `gpt_image_2_5` · quality high · 1k · 3:2 (장당 1.5크레딧, 5장 7.5크레딧)
- 1번(캐릭터 기준)을 먼저 만들고, 2~5번은 1번 결과(job b85170d8-…)를 참고 이미지(`image_references`)로 넣어 얼굴을 맞췄다.
- 그림 안 글자는 모두 `base data\make_cards.py` 가 PIL 로 얹었다(저울 라벨 2개, 나고야 탑승권·예언 줄). AI 그림 자체에는 글자 없음.
- 빛: 썸네일 맑은 낮 / 저울 흐린 날 실내 / 나고야 눈 오는 겨울 아침 / 기준 그림·도장 단색 배경 — 노을·밤 없음.

## 1. 캐릭터 기준 그림 → `images\ai_characters.png` (본문에 안 씀, 참고용)

```
부드러운 파스텔 톤의 3D 그림책풍 캐릭터 일러스트, 밝은 낮의 자연광, 깨끗하고 귀여운 느낌, 3:2 가로 구도. 화면 어디에도 읽을 수 있는 글자·숫자·간판·로고가 없다. 실제 사람은 등장하지 않는다.

연한 하늘색 단색 배경 위에 작은 캐릭터 둘이 나란히 서서 서로를 곁눈질로 노려본다. 왼쪽은 날씨요정: 머리가 작은 해 모양(둥근 노란 얼굴 둘레에 짧고 둥근 햇살 꼭지들), 등에 투명한 하늘색 잠자리 날개 한 쌍, 따뜻한 노랑과 하늘색 옷, 한 손에 선글라스를 들고 턱을 치켜든 의기양양한 표정. 오른쪽은 날씨악마: 몸이 작고 통통한 보랏빛 잿빛 먹구름, 머리 위에 짧고 뭉툭한 귀여운 뿔 두 개, 한 손에 접힌 우산을 지팡이처럼 짚고 장난스럽게 씩 웃는 표정, 몸 아래로 빗방울 몇 개가 톡톡 떨어진다. 무섭지 않고 장난꾸러기 같은 얼굴. 빨강·검정은 쓰지 않는다. 두 캐릭터는 같은 크기, 전신이 다 보이고, 그림자는 바닥에 살짝.
```

## 2. 썸네일 → `images\ai_thumb.png` (대표 1:1 = `ai_thumb_square.png`)

```
부드러운 파스텔 톤의 3D 그림책풍 일러스트, 맑은 낮의 자연광, 3:2 가로 구도, 주인공은 화면 한가운데. 화면 어디에도 읽을 수 있는 글자·숫자·간판·로고가 없다. 사람은 뒷모습만 보이고 얼굴은 보이지 않는다. 어린이는 등장하지 않는다. 참고 이미지의 두 캐릭터(해 머리에 날개 달고 선글라스 든 노랑·하늘색 요정, 뿔 달린 보라·잿빛 먹구름에 접힌 우산 든 악마)를 얼굴·색·모양 그대로 쓴다.

공항 출국장 안, 큰 출발 전광판 앞. 전광판은 글자 없이 흐릿한 색 띠만 줄지어 있다. 화면 가운데에 하늘색 캐리어를 끈 여행자 한 명의 뒷모습(어깨 위부터 허리까지 크게). 여행자의 왼쪽 어깨 위에는 작은 날씨요정이 서 있고, 오른쪽 어깨 위에는 작은 날씨악마가 서 있다. 둘은 여행자 머리 뒤로 서로를 노려보며 신경전을 벌인다. 전광판 옆 커다란 유리창 밖 하늘은 정확히 반으로 갈린다: 요정 쪽(왼쪽)은 파란 하늘에 해가 빛나고, 악마 쪽(오른쪽)은 잿빛 비구름에 빗줄기가 유리에 흐른다. 바닥은 밝은 대리석, 멀리 다른 여행객은 작고 흐릿하게. 느낌은 웃기고 장난스럽다. 주인공·두 캐릭터·반반 하늘이 정사각형으로 잘라도 다 들어가게 가운데 모아 둔다.
```

## 3. 재는 법(저울) → `images\ai_scale.png` → 라벨 얹은 `ai_scale_label.png`

```
부드러운 파스텔 톤의 3D 그림책풍 일러스트, 흐린 날 창가의 부드러운 실내 빛, 3:2 가로 구도. 화면 어디에도 읽을 수 있는 글자·숫자·간판·로고가 없다. 실제 사람은 등장하지 않는다. 참고 이미지의 두 캐릭터(해 머리에 날개 달고 선글라스 든 노랑·하늘색 요정, 뿔 달린 보라·잿빛 먹구름에 접힌 우산 든 악마)를 얼굴·색·모양 그대로 쓴다.

나무 책상 위에 놋쇠 양팔 저울 하나. 왼쪽 접시에는 낡은 탁상 달력이 여러 권 차곡차곡 쌓여 있고(달력에는 글자·숫자 없이 빈 격자 무늬만), 오른쪽 접시에는 여권 한 권과 탑승권 한 장이 놓여 있다(표지·탑승권에 글자 없음). 저울은 거의 수평이다. 날씨요정은 여권 쪽 접시 끝에 매달려 위로 끌어올리려 날갯짓하고, 날씨악마는 같은 접시의 반대편 줄에 매달려 아래로 당기며 씩 웃는다. 두 캐릭터는 저울보다 작다. 뒷배경 창밖은 구름 낀 낮 하늘. 차분하고 재미있는 분위기.
```

## 4. 나고야 예언 → `images\ai_nagoya_raw.png` → 글자 얹은 `ai_nagoya.png`

```
부드러운 파스텔 톤의 3D 그림책풍 일러스트, 눈 내리는 겨울 아침의 하얀 자연광, 3:2 가로 구도. 화면 어디에도 읽을 수 있는 글자·숫자·간판·로고가 없다. 실제 사람은 등장하지 않는다. 참고 이미지의 두 캐릭터(해 머리에 날개 달고 선글라스 든 노랑·하늘색 요정, 뿔 달린 보라·잿빛 먹구름에 접힌 우산 든 악마)를 얼굴·색·모양 그대로 쓴다.

창가 나무 탁자 위, 가운데에 글자 없는 빈 탑승권 한 장이 놓여 있다. 탑승권 왼쪽에는 날씨요정이, 오른쪽에는 날씨악마가 서서 탑승권 위로 손을 맞잡고 내기 악수를 한다. 요정은 자신만만하게 선글라스를 쓰고 있고, 악마는 등 뒤로 접힌 우산을 숨기며 장난스럽게 웃는다. 탁자 위에는 작은 모래시계와 따뜻한 차 한 잔. 창밖에는 눈발이 날리고 흐릿하게 눈 덮인 지붕들이 보인다. 밤·노을이 아닌 낮.
```
