## 3. 테스트 클립 한 편 — 체크리스트

## 4. 안 될 때 — 멈추지 말고 예전 방식으로

| 증상 | 원인 | 이렇게 |
|---|---|---|
| `pron_book.py check` 에 「소리 검사 건너뜀 — g2pkiwi·kiwipiepy 필요」 | 패키지 없음 | `pip install g2pkiwi kiwipiepy` 뒤 다시. 안 깔리면 장부·꼴 검사만으로 진행하고 표에 적는다 |
| g2pkiwi 가 `Cannot open required files for skipbigram model` | kiwi 모델 종류 | `pron_book.py` 가 자동으로 기본 모델로 바꾼다. 그래도 나면 `pip install -U kiwipiepy kiwipiepy_model` |
| 첫 실행 때 nltk 가 cmudict 를 내려받는다 | 영어 낱말 처리용 | 한 번뿐. 막히면 `NLTK_ALLOW_PROXIED_URLOPEN=1` 환경변수(스크립트가 이미 켠다) |
| qa_clip ⑦ 에서 줄이 ±1 LUFS 밖 | 빌드 전 옛 `_build` 가 남음 · narr_proc 를 안 거친 파일 | 빌드를 다시. 그래도 밖이면 그 줄 mp3 가 거의 무음(−70 아래)인지 본다 |
| 완성본 TP > −1 dBTP | 효과음(휙·딩)과 내레이션이 겹침 | `tactics.SFX_VOL` 을 0.05 줄이거나 그 장면 sfx 를 뺀다. 표에 적어 두면 다음에 기본값을 바꾼다 |
| `stt.py which` 가 cli 인데 whisper-cli 없음 | 경로 | `stt.WH`·`stt.MD` 경로를 실제 위치로. 예전 `narr_pick.py` 상단에 있던 경로와 같다 |
| `narr_words.py` 가 「faster-whisper 가 있어야」 | 모델 없음 | `python clipkit\stt.py pull`(Hugging Face, 1.5GB). 안 받을 거면 5b 를 건너뛴다 — 말 자막은 예전 비례 배분 |
| `face_boxes` 가 얼굴을 못 찾음 | 옆얼굴·작음 | `--th 0.15` 로 한 번 더. 그래도 없으면 좌표는 손으로(예전) — 검출은 후보일 뿐 |
| `scene_cuts` 장면이 너무 잘게/안 나뉨 | 문턱 | 산행·이동 영상 `--th 35~40`, 실내 고정 `--th 20`. `--min 2` 로 짧은 장면 합침 |
| `trim_idle` 가 커서 깜빡임까지 남김 | 움직임 문턱 | `--motion 0.04~0.06`. 첫 실행 때 GitHub 에서 실행 파일을 받으니 인터넷 필요 |
| `depth_motion` 가 import·인자 오류 | 클라우드에서 실행 시험을 못 한 유일한 스크립트 | `depthflow --help` · `python -c "from depthflow.scene import DepthScene; help(DepthScene.main)"` 과 대조해 `make()` 의 `scene.main(...)` 인자를 맞춘다. 30분 넘게 걸리면 이번 시험에선 뺀다 |
| 뭐든 20분 넘게 막힘 | — | 그 도구만 ✕로 적고 예전 방식으로 클립을 끝낸다. **클립 완성이 먼저, 도구 시험은 그다음** |

## 6. 하지 않는 것

- 도구가 잘 돈다고 **검사 순서를 줄이지 않는다**(7-0 「예외 없음」). 소리 검사가 0건이어도 받아쓰기는 한다.
- `face_boxes` 결과를 보고 **눈 검사를 생략하지 않는다**. 못 찾은 얼굴이 한 장이라도 나오면 그 글은 사진 전부를 눈으로.
- `depth_motion` 으로 **다녀온 곳에 없던 장면을 만들지 않는다**. 내 사진에 움직임만(클립 지침 5장 진정성).
- `scene_cuts`·`trim_idle` 를 **남의 영상·화면**에 쓰지 않는다(마스터 6-7).
- 오픈소스 TTS 로 Kevin 을 **대체하지 않는다**(6-1 목소리 대장). 클라우드 시험의 여성 목소리는 대역이었다.
- 시험하느라 **발행 속도 규칙(하루 3편)을 넘기지 않는다.** 시험 클립도 한 편으로 센다.
