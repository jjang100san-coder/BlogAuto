- 「골라서 소개한다」는 기준이 카테고리 자체로 신뢰가 된다
- 「숙소」는 이미 상위 유입어(2026.7 유입 데이터)

🚫 **기존 발행 글을 이 카테고리로 옮기지 않는다** (예: 경주 1박2일 글 속 리버틴호텔). 대량 수정은 누락 트리거. 필요하면 링크만 건다.

## 2. 첫 글 — 대구 숙소 (감악산 가기 전날)

### 확정된 맥락
- 거창 감악산 꽃별여행(10/3 방문 예정이었음) **전날 대구 쪽 숙소에서 묵었다**
- 감악산 근처는 너무 시골이라 펜션을 잡으려다 "숙소 컨디션이 그런데 굳이?" 싶어서 **대구로 잡았다**
- 묵어보니 너무 좋아서 별도 글로 쓰기로 함
- 📸 **사진은 들어가자마자가 아니라, 묵고 나서 다음 날 허겁지겁 정리하고 찍었다**

### 이 맥락을 글에 쓰는 법
- **"다음 날 허겁지겁 찍었다"는 도입부·후킹 소재로 쓴다.** "들어가자마자 찍었어야 했는데, 자고 나서야 이건 써야겠다 싶었어" — 광고 글에서 안 나오는 문장이다. 제목 뒤쪽 후킹 후보
- 사진이 정리 후 상태라는 걸 숨기지 않는다. 오히려 솔직함이 신뢰가 된다
- "감악산 근처 펜션 대신 대구를 택한 이유"는 숙소 글 도입부 한 단락, 또는 감악산 후기와의 연결고리로 쓸 수 있다

### 여행 스타일 (동선·문장 톤에 반영)
- **체력이 좋은 편이 아니라 일찍 움직이지 않는다. 느슨한 아침과 여유로운 휴식이 테마** (사용자 명시)
- → 숙소 글에서 체크아웃 시간, 아침 여유, 쉬기 좋은 요소(침구·욕실·조용함)가 중요한 포인트가 될 가능성이 높다

### 아직 모르는 것 — 첫 질문에 한 번에 묻기 (마스터: 두 번 묻지 말 것)
1. 숙소 이름, 대구 어느 동네, 묵은 날짜
2. 예약처(야놀자·여기어때·직접 등), **1박 가격**, 방 타입
3. 체크인·체크아웃 시간, 주차 가능 여부
4. **"너무 좋았다"의 구체적 이유 2~3개** (침구·욕실·뷰·조용함·조식 등) ← 글의 뼈대
5. 아쉬웠던 점 하나
6. 다음 날 감악산 셔틀 주차장(거창 남상면 승강기단지길 94)까지 몇 시 출발, 얼마나 걸렸는지
7. 사진 zip

카테고리 이름도 이때 같이 확정받는다.

## 3. 숙소 글 전용 규칙

### 제목
- 앞: **[지역] [숙소명] 후기** + 필요하면 「숙소」「가격」「주차」 등 실무 검색어
- 뒤: 후킹 한마디 (첫 글은 「다음 날 허겁지겁 찍었다」 계열 유력)
- 숙소명 정확한 표기 확인 (간판·예약 화면 기준)
- 🚫 숙소명을 감악산 후기 제목에 넣지 않는다 — 키워드 카니발라이제이션

### 본문에 꼭 들어갈 정보 (독자가 검색하는 것)
| 항목 | 비고 |
|---|---|
| 위치·주차 | 동네 이름까지 |
| 가격 | **낸 금액 그대로 + 예약처 + 날짜.** 할인·쿠폰 썼으면 그것도 |
| 체크인·아웃 | |
| 방 타입 | |
| 좋았던 점 | 구체적으로. "깨끗하다"보다 "무엇이" 깨끗했는지 |
| 아쉬운 점 | 하나라도 있으면 쓴다. 신뢰도 |

### 사실·개인정보
- 직접 쓴 것만 쓴다. 안 써본 부대시설(수영장·조식 등)은 "있다고 안내돼 있다"로
- 🚫 예약 확인 화면 캡처 금지 (이름·번호·예약번호)
- 🔒 객실 호수, 동행 얼굴, 개인 소지품, 캐리어 태그 등 가린다
- 🔒 동행 정보는 최소한으로

### 사진
- 썸네일은 **방 전체가 보이는 사진** 우선. 욕실·어메니티 클로즈업은 본문용
- 정리 후 찍은 사진이므로 「다음 날 아침 정리하고 찍은 모습」이라고 캡션에 솔직하게 적어도 된다
