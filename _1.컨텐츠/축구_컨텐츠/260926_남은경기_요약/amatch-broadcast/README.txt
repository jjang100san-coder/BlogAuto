WHY IT IS A HUB
---------------
An earlier version was framed as "Korea vs Uruguay broadcast". That
collides with the upcoming Uruguay preview post - same front keywords,
my own posts competing. Reframed so the split is clean:

  this post ........ 축구 국가대표 A매치 중계 채널 일정
  Uruguay preview .. 한국 우루과이 선발 / 전망
  Uruguay review ... 한국 우루과이 결과 / 후기
  later matches .... each opponent's name

The hub takes the "A-match broadcast" queries. Single-match posts take
the opponent names. Do not reintroduce a specific match into the title
or the thumbnail.

The hub also lives longer: it keeps earning traffic until 10-06, while
single-match posts die at kickoff. Publish it first.
