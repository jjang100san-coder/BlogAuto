## 공통 스타일 문구 — 모든 프롬프트 맨 앞

```
따뜻한 색감의 평면 일러스트(플랫 벡터 스타일). 굵은 외곽선 없이 면으로 표현.
색은 크림색 배경 + 연파랑 + 진남색 + 포인트 색 하나. 여백 넓게, 요소 2~3개만 크게.
사람은 뒷모습이나 실루엣만. 텍스트, 숫자, 로고, 워터마크 없음. 16:9.
```

썸네일(img1)만 정사각형(1:1).

## img1.png — 썸네일 (9시 정각에 열리는 커튼)

```
[공통 스타일 문구] + 정사각형 + 포인트 색 진한 파랑.
진남색 무대 커튼이 가운데에서 막 양쪽으로 갈라지기 시작한 순간.
커튼 틈 사이로 비행기 객실 좌석 줄이 보이는데, 좌석들이 연파랑으로 환하게 빛나고 있다.
커튼 위쪽 벽에 둥근 벽시계 하나. 숫자판 없이 바늘만 있고, 짧은 바늘은 9시 방향, 긴 바늘은 정확히 12시 방향.
요소는 커튼, 틈 사이 좌석, 벽시계 셋뿐. 커튼이 열리는 틈이 화면 중앙에 크게 오도록.
```

## img2.png — 빈 목록 세 가지 (사정이 다른 세 개의 문)

```
[공통 스타일 문구] + 포인트 색 회청.
크림색 벽에 똑같이 생긴 진남색 문 세 개가 나란히 있다.
왼쪽 문은 굳게 닫혀 있고 손잡이에 작은 자물쇠가 걸려 있다.
가운데 문은 닫혀 있지만 문 아래 틈으로 따뜻한 노란 빛이 새어 나온다.
오른쪽 문은 활짝 열려 있는데 안쪽 방이 텅 비어 있다.
세 문이 멀리서 보면 비슷해 보이지만 가까이 보면 사정이 다르다는 느낌. 문에 글자나 번호 없음.
```

## img3.png — 11분 만에 다 찬 좌석 (모래시계와 아홉 좌석)

```
[공통 스타일 문구] + 포인트 색 주황.
비행기 좌석 아홉 개가 가로로 한 줄 늘어서 있다. 모든 좌석 위에 작은 여행가방이 하나씩 놓여 있어 빈자리가 없다.
좌석 줄 오른쪽 끝 바닥에 모래시계 하나. 모래가 거의 다 아래로 떨어진 상태.
좌석 줄 왼쪽 끝에 뒤늦게 도착한 사람 하나가 캐리어를 끌고 서서 꽉 찬 줄을 바라보는 뒷모습.
좌석 번호·글자 없음.
```

## img4.png — 며칠 뒤 다시 켜진 칸 (마무리)

```
[공통 스타일 문구] + 포인트 색 연두.
책상 위에 숫자 없는 격자판 한 장이 놓여 있다. 칸 대부분은 회색으로 꺼져 있는데, 그중 두세 칸에만 작은 연두색 불빛이 다시 켜져 있다.
격자판 옆에 연필 한 자루와 김이 나는 찻잔 하나.
창밖은 맑은 오전. 의자 등받이 너머로 앉아 있는 사람의 뒷머리만 살짝 보인다.
```
