# 5-1 내 블로그 성과 + NAVER API HUB 이관 (2026-09-22)

## 왜 5-X 인가

1~4 탭은 전부 **바깥 데이터**다. 뉴스·도서관·공공데이터·관광공사.
내 블로그가 실제로 어땠는지는 앱 어디에도 없었고, 그래서 흐름이 한쪽으로만 흘렀다.

```
1-1 판정 🟢  →  글 작성  →  (끝)
```

5-1 이 이 고리를 닫는다.

```
1-1 판정 🟢 → RSS 로 발행 확인 → 블로그 검색으로 순위 확인 → 판정 기준 보정
```

검색량 충분·경쟁 낮음으로 판정했는데 순위가 계속 안 나오면 **판정 공식이 이 블로그에 안 맞는다**는 뜻이다.
그걸 알아야 2·3·4 탭이 뽑는 키워드도 믿을 수 있다.

## blogdata.py

| 기능 | 내용 |
|---|---|
| `fetch_rss` / `parse_rss` | `rss.blog.naver.com/<아이디>.xml`. **인증 불필요**, 최근 50개 |
| `merge_posts` | RSS 는 50개뿐 → 받을 때마다 합쳐 쌓는다. 오래 쓸수록 이력이 길어진다 |
| `title_parts` / `title_audit` | 제목을 `앞(검색어) \| 뒤(사람용)` 로 가르고 규칙과 대조 |
| `keyword_guess` | 제목 앞부분 1순위, 태그 2순위로 노릴 검색어 후보 |
| `find_rank` / `rank_note` | 블로그 검색 결과에서 내 글 위치. 주소 형태가 달라 **글 번호(logNo)** 로 대조 |
| `add_rank` / `rank_trend` | 날짜별 순위 이력. 같은 날 재조회는 덮어쓴다 |
| `summary` / `summary_text` | 분류별·월별 발행, 평균 간격 |

자체검사 9개 통과. 저장 위치 `%LOCALAPPDATA%\ContentTrendRadar\blog\`.

제목 점검이 실제로 걸러낸 예: 앞부분 60칸짜리 제목, 전체 94칸짜리 제목, 앞부분 영어, 존댓말 어미.

## 5-1 탭

- `글 불러오기` — 아이디만 넣으면 된다. 주소를 통째로 붙여도 아이디만 뽑는다. 누를 때마다 누적된다.
- 표: 발행일 · 분류 · 제목 · 태그 수 · 제목 점검 · 순위. 점검에 걸리면 주황, 10위 안이면 초록.
- 분류 필터, `제목 점검에 걸린 글만` 필터.
- `이 글 순위 확인` / `보이는 글 전부` — 블로그 검색 100위까지 훑어 내 글을 찾는다. 날짜별로 쌓인다.
- `키워드 결정 탭으로 보내기` — 1-1 의 판정 대기 통로로 간다.

**RSS 에 없는 것**: 조회수·유입검색어·체류시간. 크리에이터 어드바이저 영역이고 공개 API 가 없다.
그건 1-1 `통계 유입어 붙여넣기` 로 손수 넣는다.

## NAVER API HUB 이관

네이버가 2026-07-31 개발자센터에서 검색 API 신규 발급을 끊었다. 그래서 등록 화면에 항목이 없었던 것이다.

| | 옛날 | 지금 |
|---|---|---|
| 주소 | openapi.naver.com | naverapihub.apigw.ntruss.com |
| 뉴스 | /v1/search/news.json | /search/v1/news |
| 블로그 | /v1/search/blog.json | /search/v1/blog |
| 트렌드 | /v1/datalab/search | /search-trend/v1/search |
| 헤더 | X-Naver-Client-Id | X-NCP-APIGW-API-KEY-ID |

발급 경로: 콘솔 → All Services → **Application Services → NAVER API HUB** → Application 등록.
키 하나로 고른 API 를 다 쓴다. 기존 키 보유자는 2027-06-30 까지 옛 방식 유지.

앱 반영:
- `naver_api` 를 HUB 뉴스 경로로 교체. `naver_blog_search`·`naver_search_trend` 신규.
- ⚙ 설정 첫 항목이 `NAVER API HUB`, 칸 이름은 `API Key ID` / `API Key`.
- `HUB 키 저장` — 전에는 환경변수로만 넣을 수 있어 매번 다시 넣어야 했다.
- `연결 확인` — 블로그 검색을 한 번 불러 결과를 옆에 표시.

## 아직 못 한 것

- **순위 확인은 실제 호출로 검증하지 못했다.** HUB 키가 앱에 아직 안 들어갔다. 단위 검사(`find_rank`·`add_rank`)만 통과.
- 검색어트렌드 함수는 만들었지만 쓰는 화면이 없다. 4-1 계절지수와 대조하는 용도로 붙일 자리가 있다.
- RSS 는 50개 한계. 그 이전 글은 계속 받아 쌓거나 다른 경로가 필요하다.
