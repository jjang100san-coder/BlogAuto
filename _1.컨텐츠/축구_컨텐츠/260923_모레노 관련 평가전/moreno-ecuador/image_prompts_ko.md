# 모레노 감독 글 — 이미지 프롬프트 (한글)

정보 카드 다섯 장은 만들어뒀어. 이 글은 **경기 사진이 한 장도 없는 글**이야. 아직 안 치른 경기 얘기니까 당연한데, 그만큼 카드만 연달아 나오면 딱딱해져. 분위기 이미지 두세 장이 있으면 훨씬 읽혀.

넣어도 되고 안 넣어도 발행에는 문제없어.

---

## 0. 먼저 지킬 것

🚨 **모레노 감독 얼굴을 절대 만들지 마.** 실존 인물이고, 이 글의 주인공이라 더 위험해. 감독을 암시하려면 **뒷모습, 손, 실루엣, 초점 날아간 형체**로만. 얼굴이 조금이라도 알아보이면 다시 뽑아.

**선수 얼굴도 마찬가지야.** 손흥민, 이강인 전부 실존 인물이야.

**대표팀 유니폼과 협회 엠블럼을 만들지 마.** 붉은 유니폼에 숫자나 마크가 박히면 못 써. "무지 운동복", "브랜드 마크 없는 축구화"라고 명시해.

**기자회견 사진이나 훈련 사진을 참조 이미지로 넣지 마.** 전부 언론사 저작물이야.

**한글 글자를 이미지 안에 넣지 마.** 어떤 AI든 한글은 깨져. 화이트보드에도 글자 대신 선과 도형만.

## 1. 공통 스타일 (세 장 모두 끝에 붙일 것)

지금까지 축구 글 톤이 이래. 카타르전 짙은 남색 / 마드리드 더비 적갈색 / 사우디전 해질녘 초록. **이번은 짙은 남보라로 간다.** 카드 배경과 같은 계열이야.

```
편집 사진 스타일, 차분한 실내조명, 짙은 남보라와 검정 위주에 차가운 흰빛 포인트,
새벽이나 늦은 밤 분위기, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

영문 툴이면 이걸로.

```
editorial photography, calm indoor lighting, deep indigo and black palette with cool
white accents, late-night mood, shallow depth of field, subtle film grain,
no text anywhere, 16:9
```

**빼달라고 할 것 (네거티브)**

```
글자, 한글, 숫자, 워터마크, 로고, 협회 엠블럼, 팀 유니폼, 사람 얼굴, 유명인,
뭉개진 손가락
```

## 2. 프롬프트 세 장

### ① 도형만 그려진 전술 화이트보드 — 442 섹션에 넣을 것

이 글에서 제일 중요한 한 장이야. 분석관 출신 감독이라는 정체성이 그대로 드러나거든. **442 문단 아래, 03번 카드 바로 위**가 제자리야.

```
어두운 방 안에 세워진 전술용 화이트보드를 비스듬히 찍은 클로즈업,
보드 위에는 동그라미와 화살표만 손으로 그려져 있고 글자나 숫자는 하나도 없음,
동그라미가 가운데에 네 개 모여 있고 양옆으로 화살표가 뻗어 있음,
보드 아래 선반에 마커펜 두 자루가 놓여 있음,
사람은 프레임 안에 없고 옆에서 들어온 조명이 보드 표면에 길게 반사됨,
편집 사진 스타일, 차분한 실내조명, 짙은 남보라와 검정 위주에 차가운 흰빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

보드에 글자나 숫자가 생기면 다시 뽑아. **동그라미와 화살표만** 남아야 해. "글자 없음"을 앞쪽으로 옮겨서 돌리면 잘 먹혀.

### ② 빈 회의실 의자 하나 — 개별 면담 섹션에 넣을 것

"선수 한 명 한 명과 마주 앉았다"를 그림으로 옮긴 거야.

```
어두운 회의실에 의자 두 개가 마주 놓여 있는 사진,
가운데 작은 탁자 위에 물컵 하나와 접힌 종이 한 장이 놓여 있음,
종이에는 글자가 전혀 없는 빈 종이,
사람은 아무도 없고 창 쪽에서 들어온 차가운 빛이 바닥에 길게 떨어짐,
벽에는 아무 장식도 없음,
편집 사진 스타일, 차분한 실내조명, 짙은 남보라와 검정 위주에 차가운 흰빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

종이에 글자가 찍히면 다시 뽑아. 빈 종이여야 의미가 살아.

### ③ 새벽 훈련장 조명 — 마지막 섹션에 넣을 것

"시간이 없는 채로 첫 경기에 들어간다"는 톤이야. 세 장을 다 안 만들 거면 이건 빼도 돼.

```
해 뜨기 전 이른 새벽 축구 훈련장을 멀리서 찍은 사진,
잔디는 아직 푸르스름하고 조명탑 몇 개만 켜져 있음,
그라운드에 훈련용 콘 몇 개가 줄지어 놓여 있고 사람은 아무도 없음,
멀리 하늘이 아주 옅게 밝아오는 중, 공기가 차갑게 보임,
광고판이나 전광판은 프레임 밖,
편집 사진 스타일, 차분한 조명, 짙은 남보라와 검정 위주에 차가운 흰빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

⚠️ 이 글 카드가 전부 남보라라 ③번이 어두우면 글 전체가 가라앉아. **하늘이 옅게 밝아오는 부분을 꼭 넣어야** 마지막 섹션의 기대감과 맞아.

## 3. 참조 이미지는 넣지 않아도 돼

프롬프트만으로 충분해. 기자회견이나 훈련 사진을 참조로 넣으면 저작권 문제가 생기고, 무엇보다 **얼굴이 닮게 나올 위험이 커져.**

세 장 톤을 맞추고 싶으면 **①번을 먼저 뽑아서 마음에 드는 걸 고르고, 그 이미지를 ②③번의 스타일 참조로 재사용**하면 돼.

## 5. 썸네일은 그대로 둬

**01_moreno_profile.png 를 첫 사진 자리에 유지해.**

이름이 큰 글씨라 축소해도 읽혀. 화이트보드 사진은 근사하지만 손톱만 하게 줄이면 그냥 어두운 네모가 돼.

카드 문구도 건드리지 마. `취임 일성은 442 한마디였다`까지만 둔 이유가 있어. **제목이 후킹으로 감춘 답(그 이유)을 썸네일이 미리 주면 안 되거든.**

## 6. 급하면 이렇게

발행이 급하면 **카드 다섯 장으로 그냥 올려도 돼.** 본문 2,997자에 표 하나라 읽기에 무리는 없어.

**경기가 내일이라 타이밍이 이미지보다 중요해.** 분위기 이미지는 나중에 수정으로 끼워 넣어도 되고, 다만 발행분 수정은 하루 2~3개 안에서만.
