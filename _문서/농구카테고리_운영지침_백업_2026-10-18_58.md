# 2. 🔁 연재와 작업 순서

## 2-1. 순서와 예고

- 편 번호는 연재 순서다. **보류한 편도 번호는 비워 둔다**(5편 유기상 ⏸ 복귀 뒤 재개 → 4편 다음 발행은 6편). 카드 번호 「No.NN / 12」도 편 번호 그대로.
- 앞 편 끝의 「다음 편은 ○○」 예고대로 발행한다(마스터 12장). 예고를 바꾸려면 앞 편 문장도 같은 날 고친다.
- 도입부 링크 줄 = 이미 발행된 앞 편들. 미발행 편 링크는 넣지 않고, 발행 뒤 `add_link.py`로 기존 링크 줄 바로 아래에 더한다(마스터 2-3).

## 2-2. 조사는 전원 1차 먼저, 편마다 2차·3차 (2026.10.16 본인)

| 단계 | 언제 | 무엇 |
|---|---|---|
| 1차 | 남은 선수 **전원 먼저** | 프로필(KBL)·커리어·대표팀 경로·기존 기사, 유튜브 후보 → ⭐ 영상 두 판독(마스터 0-11) → `base data\분석노트_○○.md` |
| 2차 | 그 편을 쓰기 직전 | 시즌 경기별 기록·경기 후 인터뷰·원문 기사 → `base data\2차수집_○○.md` → `종합분석_○○.md`(경유표·10-8 표·16-3·소제목 틀·이미지 계획) → 초안 |
| 3차 | 발행 직전 | 초안 뒤 새로 치른 경기만 → 경기 표·카드 04·평균 문장·「다섯 경기」 같은 소제목 숫자를 **함께** 고친다 |

- 영상 추출은 순차(병렬 금지), `--no-fallback`, 한국 영상은 한국어 플래그 고정. 긴 라이브는 자막 → 필요한 구간만 whisper, 원본은 끝나면 지운다.

# 3. 🎯 제목

- 앞(구분선 앞) = 검색형: **「농구 ○○ 프로필」 + 같은 의도의 말 1~2개**(군대·연봉·키·조기 전역·형제 등). 큰 말(이름만)은 좁힌다. 선수 이름은 제목에 한 번(마스터 10-8 규칙 4).
- 뒤 = 발견형 문장, 그 선수만의 숫자·장면 하나(마스터 10-6 ②③). 예: 「병역 혜택 8명에 없는 금메달리스트가 후배에게 군대 가라고 놀렸어」.
- **발행 전에 바뀌는 숫자(개막 N경기 등)는 제목에 넣지 않는다** — 3차 때 어긋난다.
- 소제목에 앞 검색어가 각각 나와야 한다(🏀 「농구 ○○ 프로필」 · 🪖 「○○ 군대」 · 💰 「○○ 연봉」).
- 자기 잠식 확인: 앞 편이 이미 그 검색어 1위면(예: 3편이 「문유현 프로필」 1위) 경유표 16-3 칸에 적고 다른 앞말을 고른다.

| 함정 | 규칙 |
|---|---|

| 방송 속 화자 | 예능(아는 형님 등)은 남녀 대표가 섞여 말한다 → **이름표가 보이는 장면만 인용**. 이름표 없는 말은 얼굴·화면 질문 자막으로 화자를 확정한 뒤에도 🟡 |
| 인용 | 화면 자막 ✅, 아니면 자동 자막 + whisper가 **일치하는 부분만**(마스터 0-11). 갈리는 낱말이 있으면 그 문장은 인용하지 않는다(예: 「저희도/저도」) |
| 숫자 | **KBL 공식 값**만(방송 그래픽 196.2cm·86kg 같은 값은 안 씀). 복무 기간·인상률 %·합계 같은 계산값 금지(마스터 0-4). 전역일처럼 자료가 갈리면 「9월 말」처럼 둘 다 맞는 범위로 |

| 판정·불화 | 퇴장·판정은 기사 사실 + 본인 말까지, 맞았는지 평가하지 않는다. 출연자 한 명의 불화 전언(「마줄스의 남자」 류)은 쓰지 않는다 |
| 경기 장면 | 화면으로 확인 못 한 장면은 기록 칸까지만(「앤드원」 단정 금지). 3편과 같은 장면은 3편과 같은 문장으로 |
| 부상·체력 | 부상은 한 줄 이하, 「지쳤다」 단정 금지 — 출전 분·로테이션 먼저 |
| 가족·배경 | 가족은 한 줄 이하(배우자·가족 인터뷰 제외). 혼혈·국적 같은 배경은 **본인이 한 말만**(에디 다니엘) |
| 영상 시각 | 글·카드엔 「N분쯤」, 분:초는 작업 메모에만 |

## 6-0. 🏀 농구 카드는 「코트 카드」 양식 (2026.10.18 본인 확정) — **농구 전용 분야 규칙**

> 계기: 축구 B 양식(2026.10.17) 뒤 「농구도 농구만의 결, 축구와 색 조합·결을 다르게」(본인). 시안 1~3차 `_1.컨텐츠\농구_컨텐츠\_카드양식_시안_2026-10-17\`. **축구 카드 문법(팀 색 대각 면·노란 띠·각진 모서리)은 가져다 쓰지 않는다.**

## 6-1. 🧭 전술판 (`CourtBoard`)

- 위에서 본 하프코트 패널 둘을 위아래로(①·② 장면), 아래에 범례·번호 설명 3줄·알약.
- **선 약속은 농구 작전판 관례 — 실선 = 사람 움직임, 점선 = 패스, 지그재그 = 드리블, 끝 가로 막대 = 스크린.** 공격 = 번호 원(오렌지), 수비 = X. ⚠ 축구 전술판(점선 = 사람, 실선 = 공)과 **반대**라 섞어 쓰지 않는다.
- 선은 흰색 + 먹 테두리(오렌지 페인트존 위에서도 보이게). 빈 자리는 흰 점선 면.
- 일반 원리 그림은 부제·출처에 「개념도 · 실제 경기 장면 아님」. **실제 경기 장면을 그릴 땐** 근거 영상·기록으로 선수 위치표(코트 미터 좌표)를 먼저 쓰고, 근거가 한 곳뿐이거나 내가 채운 위치가 있으면 **만든 뒤 무엇이 근거고 무엇이 채운 것인지 적어 본인 확인을 받는다** — 확인 전엔 발행본에 넣지 않는다(축구 6-2 ⑤와 같은 원칙).
- 렌더 뒤 확대해서 글씨 가림·선이 원을 지나는 곳 0건.

## 6-2. 썸네일과 AI 삽화

- **썸네일 = AI 장면 1번**(마스터 5-4 그대로), 세 질문 ①요약+궁금증 ②제목 연상 ③본문에 있음 셋 다 ○, 경유표에 적는다. 얼굴·숫자를 못 쓰니 ②는 「그 선수만의 사물·순간」으로(군화+농구화+메달, 부대 정문 등). 카드는 2번째부터.
- AI 삽화(마스터 5-5): Higgsfield `gpt_image_2_5` · xhigh · 2k · 3:2. 선수가 나오면 처음부터 **「짧은 검은 머리의 동아시아계 · 뒷모습」**, 농구화는 **「민무늬, 유명 모델 닮지 않게」**(10/16 재생성 사유). 얼굴·로고·글자·계급장·부대 마크·실제 경기장 재현 금지. 캡션 `(AI 생성 이미지, 특정 인물 아님)` / 장면이면 `실제 경기 장면 아님`.
- 삽화 색·빛은 편마다 돌린다(카드는 고정색이지만 삽화는 아니다). 한 편 세 장의 빛은 겹치지 않게(맑은 낮·흐린 날·실내 조명), 노을 쏠림 금지.
- 영상 프레임·중계 캡처·선수 사진은 한 장도 쓰지 않는다(마스터 6-7).
