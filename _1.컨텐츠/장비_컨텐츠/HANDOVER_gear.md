# 1. 🧭 시리즈를 관통하는 방향

> **「크면 장땡」「초보니까 넉넉하게」로 샀다가 돌아온 기록 → 이제는 조사하고 산다 → 새로 사기 전에 고쳐 쓸 수 있는지부터 본다**

| 단계 | 글 | 메시지 |
|---|---|---|
| 실수 | 등산화 1편 / 배낭 글 | 중등산화를 10년 신었다 / 40L 취소하고 36L, 결국 20L |
| 조사 | 등산화 2·3편 / 스틱 / 아이젠 | 남의 후기보다 내 기록이 기준 / 충분히 조사하고 산다 |
| 수리 | 델타 창갈이 | 버리지 않고 고친다 (댓글이 알려줌) |
| 역할 분담 | 델타 + 새 아이젠 겨울 산행 | 밴티지는 사계절, 델타는 겨울 |

💡 배낭 글의 「36L은 큰 산용으로 남겨뒀다」와 델타 수리가 같은 구조다. **버리지 않고 역할을 나눈다.**

💡 이 칸이 쌓이면 **아웃도어 체험단 포트폴리오**가 된다. 체험단 심사자는 코스 글보다 장비 후기가 쌓여 있는지를 본다.

## A. 델타 창갈이

**계기** — 등산화 1편에 어르신 독자들이 「밑창·토캡은 공식 홈페이지·센터에 연락하면 유상으로 갈아준다」는 댓글을 달아줌. 본문에서 **댓글로 알게 됐다고 출처를 밝힌다.**

**캠프라인 공식 A/S (2026.09.25 홈페이지 확인)**

| 항목 | 내용 |
|---|---|
| 창·토캡 떨어짐 | 일반 접착 **무상** / 창갈이 필요하면 유상 |
| 창갈이 비용 | 전문등산화·릿지화 60,000원 / 그 외 50,000원 (유상수리 기준일 2022.7.1) |
| 제한 | 창갈이 최대 2회 / 고어텍스 파손·가죽 훼손·원단 찢김은 수리 불가 |
| 방수 | 고어텍스 등산화는 창갈이 후 **방수 기능 보장 불가** |
| 접수 | 051-301-3657 (평일 09~17시), 카카오톡 상담, 부산 사상구 낙동대로 1398 |
| 출처 | campline.co.kr/as/price0 , /as/precautions0 |

**전화로 확인할 것 (아직 안 함)**
1. 토캡 **세로 갈라짐**이 무상 접착인지, 창갈이 대상인지
2. 구형 블랙스톰 델타가 가격표상 어느 분류인지 → 5만 원/6만 원
3. 소요 기간 — 아이젠 글(11월 중순)·겨울 산행 일정과 맞는지
4. 10년 된 고어텍스 상태 판정 가능 여부, 창갈이 후 방수
5. 구형 모델 부품 수급

🚨 **4번이 이 글의 전제다.** 방수가 안 남으면 「델타 = 겨울 전용」이 성립하지 않는다. 전화 결과에 따라 D의 각도를 바꿔야 한다.

**촬영 계획**
- 보내기 전: 갈라진 토캡 접사, 밑창, 옆면 — **받은 뒤와 같은 구도로**
- 포장·발송 (운송장 번호 가림)
- 받은 뒤: 같은 구도 비교 컷, 비용 영수증 (개인정보 가림)

**도입 재료** — 2026.09.27 용마산→아차산 능선을 토캡 갈라진 델타로 다녀옴. 「능선이라 운동화로는 발 아플 것 같아서」 선택, 「다행히 아직까지는 제 역할을 한다」(본인). → **갈라진 채로도 능선을 다녀왔다 → 그래서 버리지 않고 고친다.** 산행 후 갈라짐이 더 벌어졌는지 사진으로 남길 것.

**발행 후** — 등산화 1편 끝에 한 줄 + 링크 (댓글로 알려준 분께 감사 포함). 발행분 수정은 하루 2~3개 안에서.

## B·C. 스틱·아이젠 — 조사 1차 결과

**방향 (본인 결정)** — 둘 다 새로 사야 한다. **「같은 실수를 안 하려고 충분히 조사한 뒤 샀다」**로 쓴다. 배낭·등산화보다 활용도는 낮지만 있으면 좋은 장비.

**두 편으로 나누는 이유** — 검색하는 사람(무릎·내리막 vs 겨울산·체인젠)과 시즌이 다르다. 스틱은 사계절, 아이젠은 11월 중순 발행.

**스틱 조사 (찾아본 내용 — 본문엔 「찾아보니」로 출처 구분)**

| 기준 | 내용 |
|---|---|
| 길이 | 스틱을 쥐고 섰을 때 팔꿈치 90도. 한 가이드는 키×0.67 제시. 오르막 5~10cm 짧게, 내리막 5~10cm 길게 |
| 구조 | 3단 텔레스코픽 = 튼튼·조절 폭 넓음·부피 큼 / 접이식 = 가볍고 작게 접힘·내구성과 조절 폭 낮음 |
| 소재 | 카본 = 가볍지만 바위에 부딪히면 금 가고 부러질 수 있음 / 알루미늄 = 무겁지만 휘어도 안 부러짐 |
| 잠금 | 레버식이 대세. 금속 레버가 플라스틱보다 튼튼 |

# 5. 🚨 이 시리즈에서 난 사고 — 반드시 읽을 것

| 사고 | 원래 | 정정 | 교훈 |
|---|---|---|---|
| 델타 사용 기간 | 15년 | **10년 (2016 구매)** | 모델 등록 2014.10이라 15년 불가능. 구매 이력으로 확정 |
| 밴티지 컷 | 경등산화 = 로우컷 | **미드컷** | 「경등산화」는 무게·용도 분류. **상세페이지 측면 사진에서 복사뼈를 덮는지 본다** |
| 밴티지 방수 | 고어텍스 라벨 있다 | **방수 표기 없음** | 택 실물 확인이 화면 판독보다 우선 |
| 배낭 모델 | 푸트라 32 (주문 제목) | **푸트라 프로 36** | 상세 옵션에서 36 선택. 겉면 `FUTURA PRO 36` 확인 |
| 도시락통 | 2개 | **3개** | 청계산 현장 사진이 우선 |
| 배낭 깊이 차이 | 사진 판독 10cm | **본인 실측 약 5cm** | 🚫 「10cm 차이」로 되돌리지 말 것 |
| 델타 파손 표현 | 토 떨어짐 / 밑창 | **토캡 세로 갈라짐** | 사용자가 「토 떨어진」이라고 말해도 본문은 확정 표현으로 |

## 쓰지 않는 것

- **추정치를 사실처럼** — 확인 안 된 건 문장째 뺀다
- **써보지 않은 제품 평가** — 데카트론 40L은 취소해서 안 써봤다. 「커 보여서 취소」까지만
- **집 저울 무게** — 측정 불가. 「가볍더라」는 체감으로만. 상세페이지 무게는 출처를 밝혀서
- **제품 비판** — 36L이 나쁜 배낭이라서가 아니다. 장비 글 도입부에 **「불평 아님」 선언**. 사진에 모델명이 찍히므로 특히 주의
- **36L 사용 횟수를 흠으로** — 「낭비했다」로 몰지 않는다
- **배낭 25만 vs 등산화 20만 예산 비교** — 본인이 원하지 않음
- **기억 안 나는 것** — 십몇 L 배낭의 모델명·시기
- **남에게 들은 정보는 출처를** — 「댓글로 알게 됐다」「찾아보니」

- **예고했으면 반드시 쓴다** (마스터 §12). 바로 다음 글이라는 뜻은 아니다 — 2편 예고 「270 오면 첫 산행 다녀와서 쓸게」 때문에 배낭 글을 먼저 냈다
- **미발행 글은 링크하지 않는다.** URL을 아직 안 옮긴 발행 글은 파이프 앞을 비워 둔다
- **마무리 질문** — 「제대로 산 게 맞을까? 조언 있으면 댓글로」 틀은 공통. **반말로**, **질문 내용은 글마다 다르게** (배낭: 몇 리터 메고 다녀? / 스틱: 길이 이렇게 잡은 게 맞을까?)
- **비유는 여행·읽기·생활에서만.** 직업 비유 금지. 등산 글에서 등산 비유 금지
- 소제목 = 이모지 + 고유명사 넣은 평서문 / 볼드 섹션당 1~2개 / 문단 2~4문장 / 2,000자 이상 / 반말

## 사진·파일

- **컨택트시트로 전량 판독한 뒤 캡션** (라벨은 이미지 위, EXIF 회전 적용). 업로드 순서 = 파일명 순서라고 가정하지 말 것
- 파일명 지어내지 않는다. 채팅에 붙여넣은 사진은 이름이 바뀐다 → **원본 파일을 zip으로** 받는다
- 같은 사진 한 글에 두 번 금지, 거의 같은 컷 두 장 금지
- 인물은 본인 뒷모습만, 타인은 식별 불가만
- 원본 jpg 유지, **webp 변환 금지** (EXIF 유실)
- 화면 캡처 하단의 **Windows 정품 인증 문구**는 잘라낸다
- **zip 안 파일·폴더 이름은 영문·숫자만** — 한글 이름은 윈도우에서 깨진다
- 채팅 전송 한도 **30MB** — 원본 사진까지 넣으면 넘는다. 초안 + 새로 만든 이미지만 보내고, 원본은 본인 폴더에서 합친다
