## 2. 읽기 [추론 — 확신도 표시]

1. **이긴 방식이 정반대다 (높음 — 팀 기록).** 수원은 공을 쥐고(60%) 일찍(1분) 끝냈다. 화성은 공을 내주고(44%) 늦게(65분·95분) 끝냈다. 화성 27경기 중 20경기가 점유 50% 미만이라는 재료종합 2장과 같은 그림 — 안산전은 「두리볼」 표본 그대로다.
2. **화성의 강점 = 버티는 힘 + 상대 진영에서 뺏기 + 후반 교체 카드 (중간~높음).**
   - **두 골 모두 안산 진영에서 공을 뺏은 데서 나왔다** — 카운터프레싱(재료종합 2장, 해설 셋이 꼽은 최대 장점)이 실제 득점이 된 경기. 둘 다 **교체 선수**(최예훈·일류첸코)가 뺏었다.
   - 전반은 밀렸다: 경기신문 「김인성·말론에 고전」, 중부일보 「수세」. 안산 연응빈 헤더가 골대를 맞혔다.
   - 5월 R10 홈 안산전도 2-0 — 두 경기 모두 점유 43~44%, 첫 골 후반·둘째 골 추가시간·무실점. **같은 공식이 두 번 나왔다.**
   - 안산 유효슈팅(다음 8)·화성 선방(다음 6)이 서로 맞지 않는다 → **K리그 공식 기록 대조 전엔 본문에 「유효 8」 쓰지 않는다.** 많이 맞고도 0실점, 김승건 선방이 컸다는 방향만. (김승건 무실점 9경기 — 재료종합 1-1, 채널 집계와 기록 일치)
   - 결승골은 교체 투입 일류첸코(66'→95'). 1차전에서도 화성 교체 임병훈 골이 VAR로 취소됐다(재료종합 1-3). 화성 41골 중 26골이 후반 [계산].
   - 리드 뒤 75분 이후 파울 5개(문자중계 [계산]) — 시간을 쓰는 운영.
3. **화성의 약점 = 상대에게 유효슈팅을 많이 준다 + 스스로 만드는 슈팅이 적다 (중간).**
   - 안산에 슈팅 9개를 주고 화성은 7개(하나는 PK). 직전 수원FC전 슈팅 2·유효 0 — 차두리 「전방 속도가 없어 단순한 볼이 나갈 수 없었다」, 선수 기용·교체가 「너무 도전적」이었다(풋볼리스트 10/9). 수원FC는 미들블록으로 화성 전개를 측면으로 몰고 일류첸코·플라나를 전담 마크했다.
   - 그 경기 실점: 중앙 패스 미스 → 역습 → **화성 왼쪽 뒷공간**(풋볼리스트 10/9, 기호일보 「왼쪽 측면 공략」·「롱볼 위주」). → 수원 오른쪽(이건희·강성진 쪽)과 맞붙는 자리.
   - → 수원이 안산전처럼 **유효슈팅 10개**를 만들면, 김승건 한 명에게 기대는 버티기가 언제까지 되느냐가 질문.
4. **10/18의 충돌 지점 = 65~75분 (중간 — 두 경기 기록이 같은 시간대를 가리킴).**
   - 수원: 65분 3명 교체 → 65~75분 슈팅 0(문자중계 [계산])·67분 실점. 이정효 「후반 20분 정도 교체 이후의 경기력은 많이 아쉽다」.
   - 화성: 같은 시간대(65분 PK 골, 66분 일류첸코 투입)에 승부를 걸었다. 「후반 동점·역전골이 많다」[06].
   - → **수원이 약해지는 시간과 화성이 강해지는 시간이 겹친다.** 프리뷰의 핵심 관전 포인트 후보. (2편 「단점 셋째 — 약속은 시간이 지나면 흔들린다」와 직결)
5. **수원 안산전 첫 골 공식이 화성에도 통하나 (낮음 — 영상 확인 필요).**
   - 안산전: 앞 네 명이 넓게 서자 안산 **뒤 셋** 간격이 벌어짐 → 김민우 롱패스 → 루이스(사용자 확인 도해).
   - 화성은 수비 때 **5-4-1**(뒤 다섯) — 폭을 다섯 명이 나눠 막는다. 넓게 서는 것만으로 틈이 생길지는 1차전 영상(수원 63% 점유에도 전반 위협 적음 [05])으로 확인.
   - 1차전 동점골은 센터백 고종현이 직접 올라가 수비를 끌어낸 장면[05] — 「끌어내기」가 5-4-1을 연 방식.
6. **세트피스 (중간).** 화성: 1차전 플라나 코너 → 장민준 골, 안산전 플라나 PK. 수원: 안산전 코너 약속 골(루이스). 양쪽 다 세트피스로 한 골씩 나온 상대다.
   - ⚠ 1차전 헤더 골의 장민준은 공식 타임라인상 R28에서 경고 8장째 → **10/18 경고누적 출장정지 가능성**(대회요강 제39조, 연맹 공시·기사 대기). 빠지면 화성 세트피스 높이가 줄어든다. 일류첸코는 경고 3장이라 결장 없음(`base data\05_미확인항목_기사확인_2026-10-12.md`).

## 3. 프리뷰 축 제안

- 「안산을 이긴 두 방식 — 공을 쥐고 일찍(수원) vs 공을 내주고 늦게(화성)」 → 10/18 질문은 **수원이 일찍 넣느냐, 화성이 65분 이후까지 버티느냐.**
- 내 장면(10-6 ②): 안산전 교체 뒤 실점을 직접 보고 적은 관찰 + 직접 그린 실점 도해 → 「그 시간대가 화성의 시간」.
- 도해 후보: ① 안산전 두 경기 점유·유효슈팅 대비 카드 ② 65~75분 타임라인(수원 교체·실점 / 화성 PK·교체) ③ 수원 앞 넷 vs 안산 뒤 셋 / 화성 뒤 다섯 비교 도해(영상 확인 뒤, 컨펌 필요 — 축구 6-2 ⑤).
