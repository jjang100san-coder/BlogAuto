## 3. 실험 설계

### 고정할 것 (하나라도 바뀌면 비교가 안 된다)

| 항목 | 정하는 법 |
|---|---|
| 노선·날짜 | 실제로 갈 가능성이 있는 것. 예: 1월 게로 여행의 인천–나고야 |
| 편명·출발 시각 | 목록에서 한 편을 골라 끝까지 그 편만 |
| 인원·좌석 등급 | 성인 1, 일반석 |
| 통화·언어 | 원화, 한국어 |
| 판매처 | 스카이스캐너 목록의 **같은 판매처** 가격만 비교 (최저가 판매처가 바뀌면 그건 다른 값) |

### 바꿀 조건 네 가지

| 조건 | 어떻게 |
|---|---|
| A. 평소 브라우저 | 같은 편을 5번 이상 반복 검색한 상태 |
| B. 시크릿모드 | 새 시크릿 창에서 처음부터 |
| C. 쿠키 삭제 | 평소 브라우저에서 사이트 쿠키·캐시 삭제 뒤 |
| D. 다른 기기·통신망 | 휴대폰 LTE/5G (와이파이 끄고) |

### 재는 순서

1. A → B → C → D를 **10분 안에** 연달아 찍는다. 화면에 시계(작업표시줄 또는 휴대폰 상단)가 같이 보이게.
2. 이것을 **사흘, 같은 시각대에** 반복한다. 하루 중 아침·저녁 두 번이면 더 좋다.
3. 대조군: 항공사 공식 사이트에서 같은 편을 매번 한 번.
4. 매 회차를 표 한 줄로 적는다 — 날짜, 시각, 조건, 판매처, 표시 가격.

사흘을 하는 이유: "검색을 많이 해서 오른 것"과 "출발일이 가까워져 오른 것"을 나눠 보기 위해서다. 네 조건이 같이 오르면 검색 횟수 탓이 아니다.

## 4. 주장 순서

1. 항공권은 자꾸 검색하면 오른다, 시크릿모드로 보면 싸다 — 많이 듣는 말이다. 맞는지 재 봤다.
2. 같은 편을 네 조건으로 10분 안에 찍었다. (결과 표 1)
3. 사흘 반복했다. 가격이 움직인 날은 네 조건이 같이 움직였는지, 한 조건만 달랐는지. (결과 표 2)
4. 항공사 공식 사이트 값과 비교.
5. 그래서 내 다음 예매는 이렇게 한다 — 실험에서 나온 만큼만.

## 8. 사실 규칙 · 하지 말 것

- 🚫 가격이 달랐어도 **원인을 단정하지 않는다.** 환율, 남은 좌석, 판매처 교체, 시간 경과일 수 있다. "이 조건에서 이 값이 찍혔다"까지만.
- 🚫 "시크릿모드는 효과 없다 / 있다"로 일반화하지 않는다. "내가 잰 사흘, 이 노선에서는"으로 한정.
- 🚫 숫자는 캡처에 찍힌 값만. 차액·인상률을 계산해서 만들지 않는다. 필요하면 두 값을 나란히 적는다.
- 🚫 항공사·여행사가 "가격을 조작한다"는 식의 문장 금지. 확인할 수 없다.
- 🚫 VPN으로 다른 나라 가격을 보는 실험은 넣지 않는다. 약관 문제가 걸릴 수 있고 이 글의 질문이 아니다.
- 🚫 판매처가 다른 두 가격을 같은 줄에서 비교하지 않는다.
- 직업 비유 금지. 도구는 브라우저 기본 기능만.
- 실험을 하지 않은 조건은 쓰지 않는다. 사흘을 못 채웠으면 "이틀"이라고 쓴다.
