# 여행 회고록 시리즈 — 제작 방법론

> **공통 규칙은 `블로그_마스터지침.md`를 따른다.**
> 초안 형식·마커·검증·개인정보·볼드·썸네일·유입 구조는 전부 마스터에 있다.
> 이 문서는 **회고록에만 해당하는 것**만 담는다. 충돌하면 마스터가 우선한다.
>
> 기준: 2026.9.8 / 근거: 미국 체류기 1~15편 제작 경험

---

## 0. 이 형식이 뭘 하는 건가

**사진 폴더 하나에서 한 편의 에세이를 뽑아내는 방식**이다.

1. **EXIF가 기억보다 정확하다** — 시각·좌표로 그날을 복원한 뒤에 쓴다
2. **편마다 축이 하나** — 장소가 아니라 그날의 전환점 하나를 잡는다
3. **모르는 건 안 쓴다** — 그럴듯하게 채우면 회고록이 아니라 창작이 된다

### 적용이 되는 조건

| 조건 | 이유 |
|---|---|
| 여행이 **여러 회차** | 편 간 대비가 생긴다. 단발 여행은 안 붙는다 |
| 사진에 **EXIF 생존** | 동선 복원의 전제 |
| **1년 이상 지난** 여행 | "지금 보니 다르게 보인다"가 성립한다 |
| 검색 유입이 목적이 **아님** | 정보 글과 목적·문체·구조가 전부 다르다 |

**안 되는 경우** — 최근 여행 / 3~4일 단발 / 검색 유입이 목표인 콘텐츠

## 1. 워크플로

```
① 폴더 목록 확보        → 전체 지도
② 편 순서 결정          → 시간순 뼈대
③ 해당 편 ZIP 업로드    → EXIF/GPS 추출
④ 사진 실제로 보기      → 컨택트시트
⑤ 사용자에게 질문       → "순간"을 받아온다
⑥ 축 결정              → 편당 하나
⑦ 초안 작성            → 마스터 지침 형식
⑧ 확인·정정 루프        → 보통 2~3회
```

⚠️ **③④를 건너뛰면 안 된다.** 폴더명만 보고 쓰면 "어디 갔다"로 끝나는 일지가 나온다.
미국 1편은 폴더명만으로 짰다면 "물범 보고 버거 먹고 다리 봤다"였다.
실제로 글을 만든 건 **14:29라는 시각**과 **내비 화면 사진**이었다.

## 2. EXIF 추출 — 이 형식의 엔진

```python
from PIL import Image
from PIL.ExifTags import TAGS, GPSTAGS
import glob, os

def conv(v):
    try: return float(v[0]) + float(v[1])/60 + float(v[2])/3600
    except: return None

for f in glob.glob('**/*.jpg', recursive=True):
    ex = Image.open(f)._getexif() or {}
    t = {TAGS.get(k, k): v for k, v in ex.items()}
    g = t.get('GPSInfo')
    if g:
        gg = {GPSTAGS.get(k, k): v for k, v in g.items()}
        la, lo = conv(gg.get('GPSLatitude')), conv(gg.get('GPSLongitude'))
        if gg.get('GPSLatitudeRef') == 'S': la = -la
        if gg.get('GPSLongitudeRef') == 'W': lo = -lo
```

### 알아둘 것

- **`DateTimeOriginal`은 대개 비어 있다.** 시각은 **파일명**에서 읽는다 (`YYYYMMDD_HHMMSS`)
- 좌표의 이동 순서가 시각 순서를 **교차검증**해준다. 어긋나면 파일명을 의심한다
- 좌표가 없는 파일은 **출처가 다르다.** 대개 남이 찍어 보내준 사진
- 파일명이 epoch 밀리초(`1560157649353-3.jpg`)면 메신저 전송분 — 전송 시각을 역산할 수 있다

### 구간 평균 속도 — 어디서 멈췄는지 알아낸다

```
구간 거리 ÷ 걸린 시간 = 평균 속도
```

주행 속도(80~100km/h)면 **논스톱 통과**, 절반 이하로 떨어지면 **그 구간에 정차**.
미국 3편에서 주유소 위치를 이걸로 좁혔다. (90km/h 통과 / 49km/h 정차 흔적)

### 동선표는 만들되 본문에는 안 넣는다

| 시각 | 좌표 | 위치 |
|---|---|---|

작업 메모에만 둔다. 회고록은 문장이 중심이고, 표가 들어가면 정보 글이 된다.

## 3. 축 잡기 — 이 형식의 핵심

### 3-1. 장소가 아니라 순간이 단위

> ❌ "데스밸리 갔음" → 글이 안 됨
> ⭕ "기름이 얼마 안 남아서 계기판만 봤음" → 한 편이 됨

같은 장소에서 여러 편이 나와도 된다. 오히려 그게 좋다.

### 3-2. 축은 대개 '전환' 또는 '결정'이다

미국 1~15편의 축:

| 편 | 축 |
|---|---|
| 1 | 무서워서 **스스로** 돌아섰다 |
| 2 | **배 시간**이 정해서 돌아왔다 |
| 3 | 돌아가는 게 **내가 정하는 일이 아닐 뻔**했다 |
| 4 | 처음으로 **"누가 있었나"**의 이야기 |
| 5 | **아무 일도 없었던** 하루 |
| 6 | 사람은 안 남고 **길이 남았다** |
| 7 | **사진을 보내주는** 사람들이 생겼다 |
| 8 | 같은 사막이 **다른 곳**이 됐다 |
| 9 | 정보가 없어 **맡겼는데 그게 정보가 됐다** |
| 10 | 사람은 바뀌는데 **한 명만 그대로** |
| 11 | 아무것도 안 한 날인데 **그 장소가 사라졌다** |
| 12 | 처음으로 **사람이 목적지**였다 |
| 13 | **원을 통째로 옮길 수 있다**는 걸 알았다 |
| 14 | 마지막인 줄 알았는데 **마지막이 아니었다** |
| 15 | 맡기던 사람이 **데리고 다니는 사람이 됐다** |

1~3편이 전부 "어떻게 돌아왔나"이고 4편에서 축이 바뀐다. **이 배치를 미리 설계한다.**

### 3-3. 필수 구조

```
구체적 사실 (그때 있었던 일)
    ↓
지금 보니 다르게 보이는 지점
    ↓
그 차이가 만든 생각
```

**첫 칸이 비면 나머지가 안 선다.**
사진 한 장 올리고 "그때는 몰랐다, 지금은 안다"만 늘어놓는 게 가장 흔한 실패다.

### 3-4. 편 간 대비를 설계한다 — 숫자가 있으면 최고

| 대비 | 효과 |
|---|---|
| 6편 받은 사진 **0장** ↔ 7편 **129장** (일주일 차) | 가장 선명 |
| 2편 섬 체류 2h43m ↔ 5편 3h09m, 사진 117장 ↔ 25장 | 같은 조건, 다른 결과 |
| 3편 주유소 사진 **0장** ↔ 8편 **2장** | 뭘 배웠는지가 사진에 남음 |
| 본인 촬영 36 → 6 → 3 → **2장** | 운전자로 굳어지는 과정 |

→ 초안 작업 메모의 **연결 메모**에 매번 기록한다. 나중 편에서 회수한다.

### 3-5. 기억의 빈틈도 소재다

- 곡명이 기억 안 남 → **넣지 않는 것**이 낫다 (1편)
- 47장 중 주유소 사진 **0장** → 없는 사진이 더 많은 말을 한다 (3편)
- 지금 검색하면 그 장소 사진이 기억과 안 맞음 → 그대로 쓴다 (3편)

## 4. 사용자에게 뭘 물을 것인가

EXIF로 "어디 있었나"는 나오지만 **"뭐가 있었나"는 안 나온다.**

**좋은 질문**
- 왜 **거기서 멈췄어?** (동선의 끝점에는 이유가 있다)
- 왜 **그때 출발했어?** (첫 사진 시각이 이상하면)
- 그날 **있었던 일** 하나 — 풍경 말고
- **공백 구간**에 뭐 했어? (사진이 끊긴 자리)
- 돌아오는 길은 어땠어? (대부분 여기가 마무리가 된다)

**나쁜 질문** — "어땠어?" / "무슨 생각 했어?" / 한 번에 여러 개

**한 번에 3~4개까지.** "기억 안 나"도 답이다. (3-5 참조)

## 5. 🚨 사실 검증 — 실제로 틀렸던 것들

미국 시리즈에서 **그럴듯했지만 틀린 판단이 여섯 번** 나왔다.

| # | 틀린 판단 | 실제 |
|---|---|---|
| 1 | 8주 공백 = 심리적 공백 | **한국에 있던 기간** |
| 2 | 폴더명 `with`로 본 혼자→동행 곡선 | **폴더명이 동행을 다 담지 않음** (2회) |
| 3 | 사진 속 물체 = 상어 지느러미 | 확대하니 **판독 불가.** 현장 증언이 우선 |
| 4 | 폴더명 날짜 = 실제 일정 | **하루 일찍 출발**, **날짜 오기** (각 1회) |
| 5 | 뮤직비디오 촬영 곡 | **사용자 기억이 먼저 틀림.** 확인 표시가 막아줌 |
| 6 | 현장에서 들은 것처럼 쓴 **지질·생물 상식** | 사용자가 말한 적 없음. 내가 채워 넣음 |

### 6번이 가장 위험하다

1~5는 **틀린 사실**이라 확인하면 잡힌다.
6은 **맞는 사실**이다. 옐로스톤 온천 색이 온도별 미생물 때문인 건 사실이다.
그래서 검증에 안 걸린다.

문제는 그걸 **"그때 안내판에서 봤다"는 식으로 화자 경험에 붙였다는 것.**
회고록에서 이건 사실 오류가 아니라 **인물 조작**이다.

```
❌ 색이 나는 이유가 온도 때문이라고 했어
⭕ 왜 그런 색이 나는지는 그때 몰랐어
```

→ **일반 상식을 회고록 본문에 넣지 않는다.**
   설명을 넣고 싶어지면 그 자리에 "그때는 몰랐다"를 쓴다.

### 그 외

- 폴더명·EXIF·검색 결과는 **단서일 뿐 결론이 아니다**
- 사진은 **확대해서** 본다. 작게 보면 삼각형이던 게 확대하면 둥근 머리다
- **현장 증언 > 사진 판독.** 사용자가 그 자리에 있었다
- **사용자 기억도 틀린다.** 확인 표시는 사용자에게도 이득이다

## 6. 회고록 고유의 형식 판단

> 아래를 뺀 나머지(마커·검증·개인정보·문단·표)는 **마스터 지침**을 따른다.

### 6-1. 제목 — 장면형, 지명은 문장 안에

정보형은 지명을 맨 앞에 박는다(`오사카 3박4일 경비`).
회고록이 그러면 정보 글로 오해받아 들어온 사람이 실망한다.

```
❌ 데스밸리 당일치기 후기 | 기름이 떨어질 뻔했다
❌ 기름이 얼마 안 남았을 때              ← 어디인지 없어 임팩트 약함
⭕ 데스밸리에서 기름이 얼마 안 남았어      ← 지명이 곧 후킹
```

**지명이 긴장을 만들거나(데스밸리) 인지도가 높을 때만**(옐로스톤·요세미티) 넣는다.
인지도가 낮으면(채널 아일랜드) 넣어도 효과가 없으니 장면만 남긴다.

**숫자 제목은 전체의 3분의 1까지.** 반을 넘으면 통계 보고서처럼 읽힌다.
회고록의 숫자는 금액이 아니라 **서사가 된 숫자**다.

```
섬에 갔는데 사진이 스물다섯 장뿐이야
요세미티에서 백스물아홉 장을 받았어
넷이 갔는데 한 명만 그대로였어
```

**자가 검증** — "이 제목만 보고도 답을 알 수 있나?" 알 수 있으면 다시 쓴다.

### 6-2. 소제목 — 장면 문장을 유지한 채 고유명사만 끼운다

마스터 1-2는 `고유명사 + 결론 평서문`을 요구한다.
회고록은 소제목이 장면 문장이라 지명이 잘 안 들어간다. **문장 형태를 지키고 이름만 넣는다.**

```
❌ 🦭 물범이 누워 있었어
⭕ 🦭 피에드라스 블랑카스에 물범이 누워 있었어

❌ ♨️ 땅에서 김이 올라왔어
⭕ ♨️ 옐로스톤은 땅에서 김이 올라왔어
```

명사 나열(`♨️ 그랜드 프리즈매틱 스프링`)로 바꾸면 정보 글이 된다.

⚠️ **결말의 반전이 지명에 걸려 있으면 넣지 않는다.**
11편은 마지막에 "웨이페어러스 채플이라는 데였는데 지금은 없어"로 이름이 나오므로
소제목은 `⛪ 유리로 된 교회가 있었어`로 두고 해시태그에만 넣었다.

**마무리 섹션은 순수 평서문으로 둔다.** 검색어가 없는 자리다.

### 6-3. 예고를 걸지 않는다

"다음 편은 ○○이야"는 **의무가 되고, 의무가 붙으면 안 써진다.**
각 편이 독립적으로 끝나야 한다.

**예외 하나** — 마지막 편이 확정돼 있으면 1편에만 한 줄.

```
이 길은 마지막에 한 번 더 나와.
그건 나중에 쓸게.
```

다음 편이 아니라 **마지막 편**을 가리키고 시점을 안 박으므로 의무가 안 생긴다.
**1편에만.** 중간 편에서 반복하면 그때부터 사슬이 된다.

### 6-4. 링크는 편당 1~2개

회고록은 **편 간 대비가 핵심**이라 앞 편을 계속 참조한다.
그때마다 링크를 걸면 각주투성이가 된다.

| 건다 | 안 건다 |
|---|---|
| 그 편을 안 읽으면 이해가 안 되는 참조 | 문장만으로 이해되는 참조 |
| (15편 → 9편) | ("두 달 전에도 여기 왔었어") |

마무리 근처에 몰아둔다. 시간순 연재라 **앞 편은 이미 발행돼 있다. 뒤 편은 절대 링크하지 않는다.**
연재물이므로 `▶ N편` 머리말을 쓴다.

### 6-5. 가시성 — 회고록이 구조적으로 제일 약하다

표도 리스트도 없이 문장만 있으니 **눈에 걸리는 게 없다.**
실제로 미국 1~15편 초안에는 본문 볼드가 **한 개도 없었다.**

마스터 4-1의 자가 검증(소제목+볼드만 읽기)을 **반드시** 돌린다.
미국 1편 통과 예시:

```
구글 지도를 찍다가 정했어
  그날 아침에 정해서 그날 나간 거야
빅스비 브리지에서 멈췄어
  이 길을 어두울 때 혼자 운전할 자신이 없었거든
마무리
  무서웠거든 / 설레서 나갔다가, 무서워서 돌아오는
```

### 6-6. 썸네일 — 시간순이 함정이다

이 형식은 시간순이라 **첫 사진이 출발 게이트·주차장·안내판**이 되기 쉽다.
축소하면 아무것도 안 보인다.

→ **첫 사진만은 시간순을 깨고 그날 가장 강한 컷을 올린다.**

## 7. 정보형과의 차이 — 다른 나라 콘텐츠 설계 시

| | 정보형 | 회고록형 |
|---|---|---|
| 목적 | 검색 유입 | 블로그 색깔·이웃 교류 |
| 제목 | `[키워드] 경비 \| 금액+후킹` | `[장면] \| [시리즈명]` |
| 순서 | 논리순 | 시간순 |
| 편수 | 확정 | 열어둠 |
| 예고 | 다음 편 명시 | 안 함 |
| 표·리스트 | 적극 사용 | 최소화 |
| 사진 | 풍경·사물 | 사람·순간 |
| 발행 | 연속 | 막힐 때 하나씩 |

### 회고록이 유입에서 하는 역할

- 검색 유입은 **못 만든다.** 상위 글은 전부 경비·숙소·렌터카
- 대신 **피드·홈판**(유입의 절반 이상)에 기여한다. 단 휘발성이라 꾸준한 발행이 전제
- **Travel 카테고리 깊이**를 채운다 → 체험단 심사 지표
- ⚠️ **회고록이 정보형을 밀어내면 안 된다.** 검색이 장기 안정성의 핵심

### 하이브리드

한 여행에서 양쪽을 다 뽑을 수 있다. 같은 상위(Travel) 아래 두면 브릿지 글로 연결된다.
회고록을 별도 상위로 빼면 그 연결이 끊긴다.

**카테고리는 톤이 아니라 "독자의 다음 클릭"으로 나눈다.**
예고를 안 거는 연재는 **카테고리가 유일한 동선**이다.

## 8. 발행 속도 — 상한이 올랐지만 회고록은 예외가 있다

**2026.9.15 실측으로 상한이 하루 2개 → 3~4개로 올랐다.**
9월 초부터 하루 3개 이상 발행했는데 유입이 오히려 늘고 체류시간도 유지됐다.
피할 것은 하루 10개 이상 몰아 올리기와 복붙성 글 양산뿐이다.

안전장치는 **주간 평균 사용 시간 2분 30초.** 그 밑으로 내려가면 그때 줄인다.

### ⚠️ 그런데 회고록은 발행 간격이 별개 문제다

상한이 올랐다고 회고록을 몰아 올리면 안 된다. **유입이 아니라 블로그의 인상 때문이다.**

- 회고록은 **초안이 빠르게 쌓인다.** 한 세션에서 여러 편이 나온다
- 연속으로 올리면 **블로그가 과거 얘기로 가득 차 보인다**
- 회고록은 검색 유입을 못 만든다 → 정보형 글이 밀려나면 장기 성장이 죽는다

**규칙**

| | |
|---|---|
| 전체 발행량 | 하루 3~4개 (마스터 15장) |
| **회고록 비중** | 그중 **하루 1편까지** |
| 배치 | 시즌 콘텐츠(정보형) 사이사이에 하나씩 |

> **초안을 미리 만드는 것과 빨리 발행하는 것은 다른 얘기다.**
> 초안은 쌓아두고, 발행은 천천히.

---

### 💡 회고록과 시의성 키워드는 궁합이 나쁘다

시의성 전략(이벤트 2~5일 전 발행)은 정보형 글의 방식이다.
회고록은 시점이 없어서 **언제 올려도 같다.**

→ 그래서 회고록은 **시의성 콘텐츠의 빈칸을 메우는 용도**로 쓴다.
   이벤트가 없는 주, 쓸 소재가 없는 주에 하나씩 꺼낸다.
   마스터 지침의 "콘텐츠 막힐 때 하나씩"이 정확히 이 뜻이다.

## 9. 세션 관리

편이 여러 개면 한 세션에 다 못 한다. 파일 세 종류를 유지한다.

| 파일 | 역할 |
|---|---|
| `*_handover.md` | 시리즈 전체 상태. 확정 사실, 진행 현황, 남은 확인 |
| `*_scene_bank.md` | **미배치 소재** + 구조 메모 + **폐기된 가설** |
| `*_NN_*_draft.md` | 편별 초안 |

**보관함이 특히 중요하다.** 대화 중에 "아 그러고 보니" 하고 나오는 소재가 계속 생긴다.
나오는 즉시 넣고, **왜 좋은 소재인지**와 **서술 주의**까지 같이 적는다.

**폐기된 가설을 반드시 기록한다.** 새 세션의 나는 같은 함정에 다시 빠진다.
