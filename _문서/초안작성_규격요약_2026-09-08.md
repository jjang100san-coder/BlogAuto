# 초안 작성 규격 (한 장 요약)

> 새 채팅방에 이 파일 하나만 올리면 된다.
> 배경 설명은 `초안작성_프롬프트_추가지침_2026-09-07.md` 에 있다.
> 충돌하면 **긴 문서가 우선**한다.
>
> 기준: 2026.9.8

---

## 1. 파일 구조

```
[[TITLE: 제목 한 줄]]
[[CATEGORY: 분류]]

===== ✂️ 여기부터 복사 =====

(발행될 본문)

===== ✂️ 여기까지 =====

(작업 메모 — 발행 안 됨)
```

경계선 두 줄은 **글자 하나도 바꾸지 않는다.** 띄어쓰기·이모지 포함.
경계선 밖의 내용은 발행되지 않으니, 확인 대기 사항·편집 지시문은 전부 아래쪽에 둔다.

---

## 2. 마커

| 마커 | 형식 |
|---|---|
| `[[TITLE: 제목]]` | 한 줄. 줄바꿈 금지 |
| `[[CATEGORY: 분류]]` | 한 줄 |
| `[[IMG:파일명 \| 캡션]]` | 단독 줄. 파일명은 실제 목록에서 그대로 복사 |
| `[[LINK:URL \| 텍스트]]` | 단독 줄. URL 없으면 파이프 앞을 비움 |
| `[[LINK:URL \| 머리말 \| 텍스트]]` | 앞부분을 링크에서 빼고 싶을 때 |

원칙은 **대상이 앞, 사람이 읽을 말이 뒤.**
마커는 문장 중간에 넣지 않는다. 항상 단독 줄.

### 시리즈 링크 머리말

`▶ 1편` 같은 편수 머리말은 **자동으로 `▶ 1편 : ` 꼴로 맞춰지고 링크에서 빠진다.**
초안에 어떻게 적든 결과는 같으니 콜론 위치를 신경 쓰지 않는다.

```
[[LINK:URL | ▶ 1편 아내는 평생 소원이라 했고, 나는 숫자를 댔어]]
→  ▶ 1편 : 아내는 평생 소원이라 했고, 나는 숫자를 댔어
           └────────── 여기부터만 링크 ──────────┘
```

`▶` 는 원문에 있을 때만 붙는다. 시리즈 링크에는 붙여 쓴다.
편수가 아닌 머리말은 파이프를 하나 더 써서 직접 나눈다 — `[[LINK:URL | 참고 | 국세청 안내]]`

### URL이 아직 없을 때

작업 메모로 빼지 말고 **파이프 앞을 비운 채 본문에 둔다.** 발행 전에 걸린다.

```
[[LINK: | 5편 계약금 중도금은 있는데 잔금만 없었어]]
```

**미발행 글은 링크하지 않는다.**

---

## 3. 본문에 쓸 수 있는 것

발행될 문장 / 위 마커 / 이모지 소제목 / `---` 구분선 /
마크다운 표(**3열 이하**) / `**볼드**` / 해시태그 한 줄

**쓰지 않는 것**

`##` 헤딩 · `- ` `* ` 목록 기호 · 코드블록 · 마크다운 링크 `[텍스트](URL)` · `【 】`

표의 셀 정렬과 남는 빈 열은 **자동 처리**되니 신경 쓰지 않는다.

---

## 4. 발행 전 검증

**중단** — 고치기 전엔 발행하지 않는다

- `[[IMG:]]`의 파일이 폴더에 없음
- `[[LINK:]]`의 URL이 비어 있음
- `[[TITLE:]]` / `[[CATEGORY:]]` 누락
- 경계선 두 줄 불일치

**경고** — 알리고 진행

- `##` · `- ` · 코드블록 · `【` 잔존
- 표가 4열 이상 (모바일에서 잘림)

오류는 **줄 번호와 마커 원문을 같이** 띄운다.

---

## 5. 사진

`[[IMG:]]`의 파일명은 **절대 지어내지 않는다.** 실제 폴더 목록에서 그대로 복사한다.
캡션은 사진에 실제로 보이는 것과 맞아야 한다.
개인정보(단지명·동호수·계좌·주민번호)가 찍힌 이미지는 올리지 않는다.
