# 한국 에콰도르 검증 글 — 이미지 프롬프트 (한글)

정보 카드 다섯 장은 만들어뒀어. 이 글은 **경기 사진을 한 장도 못 쓰는 글**이야. 중계 화면·현장 사진이 전부 언론사 저작물이거든. 그래서 카드만 연달아 나오는데, 분위기 이미지 두세 장 끼우면 훨씬 읽혀.

넣어도 되고 안 넣어도 발행에는 문제없어. **결과 검색 피크가 48시간이라 타이밍이 이미지보다 중요해.**

---

## 0. 먼저 지킬 것

🚨 **선수와 감독 얼굴을 절대 만들지 마.** 손흥민, 김민재, 이재성, 모레노 전부 실존 인물이야. 사람을 암시하려면 **뒷모습, 손, 발, 실루엣, 초점 날아간 형체**로만.

**대표팀 유니폼과 협회 엠블럼을 만들지 마.** 붉은 유니폼에 숫자나 마크가 박히면 못 써. "무지 운동복", "브랜드 마크 없는 축구화"라고 명시해.

**경기 사진이나 현장 사진을 참조 이미지로 넣지 마.** 전부 언론사 저작물이야.

**한글 글자를 이미지 안에 넣지 마.** 어떤 AI든 한글은 깨져. 전광판에도 글자 대신 빛 번짐만.

---

## 1. 공통 스타일 (세 장 모두 끝에 붙일 것)

시리즈 색 순서가 이래. 카타르전 남색 / 마드리드 더비 적갈색 / 사우디전 해질녘 초록 / 모레노 예측 남보라 / 이민성호 청록 앰버. **이번은 짙은 차콜에 코랄 포인트로 간다.** 카드 배경과 같은 계열이야.

⚠️ 특히 **모레노 예측 글(남보라)과 확실히 달라야 해.** 같은 주제의 짝 글이라 색까지 비슷하면 피드에서 같은 글로 보여.

```
편집 사진 스타일, 밤 경기장 조명, 짙은 차콜과 검정 위주에 따뜻한 주황빛 포인트,
경기가 끝난 직후의 고요한 분위기, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

영문 툴이면 이걸로.

```
editorial photography, night stadium lighting, deep charcoal and black palette with
warm coral accents, quiet after-the-match mood, shallow depth of field,
subtle film grain, no text anywhere, 16:9
```

**빼달라고 할 것 (네거티브)**

```
글자, 한글, 숫자, 워터마크, 로고, 협회 엠블럼, 팀 유니폼, 사람 얼굴, 유명인,
관중석 얼굴, 뭉개진 손가락
```

## 2. 프롬프트 세 장

### ① 채점표가 그려진 노트 — 채점 섹션에 넣을 것

이 글의 성격이 그대로 드러나는 한 장이야. 예측을 적어놓고 하나씩 표시하는 그림이거든. **`📋 경기 전에 쓴 예측` 섹션의 02번 카드 바로 위**가 제자리야.

```
어두운 책상 위에 펼쳐진 줄노트를 비스듬히 위에서 찍은 클로즈업,
종이에는 글자가 하나도 없고 짧은 가로줄 여섯 개만 손으로 그어져 있음,
그 옆에 체크 표시와 물음표 모양만 몇 개 표시되어 있음,
볼펜 한 자루가 노트 위에 비스듬히 놓여 있고 사람 손은 프레임 밖,
옆에서 들어온 스탠드 불빛이 종이 한쪽만 밝게 비춤,
편집 사진 스타일, 짙은 차콜과 검정 위주에 따뜻한 주황빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

⚠️ 종이에 글자나 숫자가 생기면 다시 뽑아. **가로줄과 체크 표시만** 남아야 해. "글자 없음"을 프롬프트 앞쪽으로 옮겨서 돌리면 잘 먹혀.

### ② 잔디에 남은 스터드 자국 — 연계 섹션에 넣을 것

"여러 명이 한 장면 안에서 각자 다른 일을 했다"를 그림으로 옮긴 거야. 발자국이 여러 갈래로 갈라지는 그림이라 연계 이야기랑 맞아. **`🤝 중원 연계` 섹션 첫 문단 아래.**

```
밤 경기장 잔디를 아주 가까이에서 찍은 사진,
젖은 잔디 위에 축구화 스터드 자국이 여러 갈래로 어지럽게 찍혀 있음,
자국들이 한 지점에서 서로 다른 방향으로 갈라져 나감,
사람은 프레임 안에 없고 멀리 조명탑 불빛이 흐리게 번짐,
잔디에 맺힌 물기가 빛을 받아 반짝임,
편집 사진 스타일, 밤 경기장 조명, 짙은 차콜과 검정 위주에 따뜻한 주황빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

### ③ 불 꺼져가는 빈 경기장 — 마지막 섹션에 넣을 것

"한 경기 끝났고 다음이 남았다"는 톤이야. 세 장을 다 안 만들 거면 이건 빼도 돼. **`🔜 채점 못 한 항목` 섹션 첫 문단 아래.**

```
경기가 끝난 뒤 텅 빈 축구장을 스탠드 위쪽에서 멀리 찍은 사진,
조명탑 절반만 켜져 있고 나머지는 꺼져 있음,
관중석은 비어 있고 좌석 색은 어둡게 가라앉아 있음,
그라운드 한쪽에 접힌 골대 그물과 코너 깃발만 보임, 사람은 아무도 없음,
전광판은 불이 꺼져 있고 광고판은 프레임 밖,
편집 사진 스타일, 짙은 차콜과 검정 위주에 따뜻한 주황빛 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

⚠️ 전광판에 숫자가 뜨면 다시 뽑아. **3-0이 찍히면 못 써** — 스코어를 이미지로 만들면 틀린 정보가 박힐 위험이 있고, 전광판 디자인이 실제 경기장과 닮으면 그것도 문제야.

## 3. 참조 이미지는 넣지 않아도 돼

프롬프트만으로 충분해. 경기 사진이나 현장 사진을 참조로 넣으면 저작권 문제가 생기고, 무엇보다 **얼굴이 닮게 나올 위험이 커져.**

세 장 톤을 맞추고 싶으면 **②번을 먼저 뽑아서 마음에 드는 걸 고르고, 그 이미지를 ①③번의 스타일 참조로 재사용**하면 돼.

## 4. 넣을 자리와 파일명

```

07_studs.png           →  중원 연계 섹션 첫 문단 아래

```

마커는 이렇게. 각각 단독 줄로.

```
[[IMG:06_notebook.png | 적어둔 걸 하나씩 지워봤다]]
[[IMG:07_studs.png | 한 장면에 여러 갈래가 겹쳤다]]
[[IMG:08_empty_stadium.png | 한 경기가 끝났고 세 경기가 남았다]]
```

다 만들면 보내줘. 초안에 넣고 순서까지 맞춰서 압축해줄게. 파일명은 위 이름 그대로 저장해줘 — 다르면 마커랑 어긋나.

## 5. 썸네일은 그대로 둬

**01_result_card.png 를 첫 사진 자리에 유지해.**

`대한민국 3 - 0 에콰도르`가 큰 글씨라 축소해도 읽혀. 빈 경기장 사진은 근사하지만 손톱만 하게 줄이면 그냥 어두운 네모가 돼.

카드 문구도 건드리지 마. `세 골 모두 후반에 나왔다`까지만 둔 이유가 있어. **제목이 후킹으로 감춘 답(이재성과 김민재가 뭘 바꿨는지)을 썸네일이 미리 주면 안 되거든.**

## 6. 급하면 이렇게

발행이 급하면 **카드 다섯 장으로 그냥 올려도 돼.** 본문 3,100자대에 표 하나, 카드 다섯 장이라 읽기에 무리 없어.

**결과 검색은 48시간이 피크야.** 분위기 이미지는 나중에 수정으로 끼워 넣어도 되고, 다만 발행분 수정은 하루 2~3개 안에서.
