# 키워드 레이더에 Claude (Anthropic) 공급자 추가 (2026-09-22)

⚙ 설정 · 인증키 · AI 의 공급자 목록에 **Claude (Anthropic)** 이 생겼다. Groq 자리에 그대로 갈아 끼우면 된다.
1-7 글 방향, 1-1 AI 추천, 2-2 독서, 3-2 산행, 4-2 세계여행 — AI 를 쓰는 모든 탭이 같은 공급자를 쓴다.

## 쓰는 법

1. `console.anthropic.com/settings/keys` 에서 키를 만든다 (`sk-ant-` 로 시작).
2. ⚙ 탭에서 공급자를 `Claude (Anthropic)` 으로 바꾼다. 모델 칸에 `claude-opus-5` 가 자동으로 채워진다.
3. 키를 넣고 `[연결 확인·모델 조회]` → `[AI 설정 저장]`.

환경변수 `ANTHROPIC_API_KEY` 도 읽는다. 환경변수가 있으면 그쪽이 우선이다.

## 왜 SDK 를 안 쓰고 urllib 로 붙였나

이 앱은 **표준 라이브러리만 쓰고 단일 exe 로 빌드**한다. 나머지 여섯 공급자도 전부 `urllib` 직접 호출이다.
`anthropic` SDK 를 넣으면 `httpx` 등 의존성이 따라와 exe 가 커지고, 한 공급자만 다른 방식이 되어 섞인다.
**정식 Python SDK 로 바꾸고 싶으면 말해 달라.** 그때는 다른 공급자까지 함께 옮기는 편이 낫다.

## 구현에서 조심한 것

Messages API 는 OpenAI 호환 형식이 아니다. 형태가 다르고, 최신 모델은 옛 파라미터를 **400 으로 거절**한다.

| 항목 | 내용 |
|---|---|
| 주소 | `POST https://api.anthropic.com/v1/messages` |
| 헤더 | `x-api-key` (Bearer 아님) · `anthropic-version: 2023-06-01` |
| 본문 | `model` · `max_tokens` · `system` (top-level) · `messages` |
| **`temperature` 금지** | Opus 5 이후 모델은 400. 다른 공급자 경로는 0.2 를 보내지만 여기선 안 보낸다 |
| **`thinking` 생략** | Opus 5 는 생략이 곧 adaptive. `budget_tokens` 는 400 |
| 응답 | `content[]` 중 `type=='text'` 만 이어 붙인다 (`thinking` 블록이 섞여 온다) |
| 토큰 | `usage.input_tokens` / `output_tokens` (`prompt_tokens` 아님) |
| 거절 | HTTP 200 에 `stop_reason=='refusal'`. 예외로 바꿔 사용자에게 알린다 |
| 폴백 | `claude-opus-5` · `claude-fable-5*` 에만 `fallbacks:"default"` + 베타 헤더. 안 받아주면 빼고 한 번 재시도 |
| 모델 목록 | `GET /v1/models?limit=100` → `data[].id`. 막히면 예비 목록을 준다 |

JSON 강제는 안 쓴다. 기존 프롬프트가 전부 "JSON 객체 하나만" 으로 끝나고 `parse_json_block` 이 코드블록을 벗겨낸다.
