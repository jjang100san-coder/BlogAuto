## C. 키워드 레이더 + 지도 연동안 (초안 — 논의용)

### 가능 여부: **된다.**

레이더 화면은 tkinter라 지도를 창 안에 그대로 넣기는 어렵다. 대신 지금도 쓰는 방식대로 간다. **레이더가 지도 HTML을 만들어 브라우저로 연다**(이미 `webbrowser` 로 여는 기능이 8곳 있다). 네이버 지도 JS는 `localhost` 에서 띄우면 된다.

### 흐름

```
[레이더 새 창: 🏠 아파트 지도]
 1. 시군구 고르기 (예: 수원 영통·장안·팔달·권선)  + 기간 (최근 3·6·12개월)
 2. 수집 (하루 저장)
    실거래 매매·전월세 → 단지별로 묶기
    K-apt 기본정보 → 세대수·준공연도·주소
    주민등록 인구(동) → 동별 인구·증감
    (선택) 공시가격, 토지이용규제(토허·규제지역)
 3. 주소 → 좌표 (브이월드 또는 네이버 Geocoding, 한 번 바꾼 좌표는 저장)
 4. 지도 HTML 생성 → 브라우저로 열기
```

### 지도에 보일 것

| 표시 | 내용 |
|---|---|
| 마커 색 | 고를 수 있게 — ① 최근 3개월 거래가 변화 ② **전세가율** ③ 거래량 ④ 준공연도 |
| 마커 크기 | 세대수 |
| 마커 누르면 | 단지명 · 세대수 · 준공 · 최근 매매 3건(면적·층·가격·날짜) · 전세 최근가 · 전세가율 · 평형별 평균 · 국토부 실거래 링크 |
| 동 경계 색 | 동별 인구 증감(최근 12개월) |
| 경계선 | 규제지역(영통·장안·팔달) vs 비규제(권선) |
| 옆 표 | 단지 순위(거래량·상승률·전세가율) + [표 복사] → 글에 바로 |

### 블로그로 쓰는 법 (예)

- **[수원] 이사 가기 전에 뜯어본 수원 4개 구** — 구별 거래량·평균가·전세가율·인구 증감 비교 표. 직접 만든 카드로.
- **[내집마련] 우리 동네 전세가율 지도** — 전세가율 높은 단지와 낮은 단지의 차이.
- **[매달] 수원 실거래 리포트** — 매달 같은 표를 갱신하는 시리즈(검색형 + 단골용).
- ⚠️ 지도 화면 캡처를 블로그에 그대로 쓸 수 있는지는 네이버·브이월드 약관을 확인한 뒤에 정한다. 표·카드는 직접 만든 것이라 문제없다.

### 정해야 할 것 (논의)

1. **지도 바탕**: 네이버(NCP, 결제수단 등록 필요) vs 카카오(이미 맛집탐방 REST 키가 있다. JS 키는 같은 앱에서 바로 발급) vs 브이월드(무료, 정부). 질문 그대로 **네이버로 갈지**, 우선 무료인 카카오나 브이월드로 만들고 바꿀지.
2. **레이더 몇 번 탭으로 넣을지** — 새 번호(예: 7-1 부동산) vs 기존 탭에 창으로.
3. **첫 범위** — 수원 4개 구만 먼저 → 화성(지금 사는 곳)·하남 추가.
4. **갱신 주기** — 실거래는 신고 기한(계약 후 30일) 때문에 최근 한 달이 계속 채워진다. 하루 1회 저장이면 충분.
