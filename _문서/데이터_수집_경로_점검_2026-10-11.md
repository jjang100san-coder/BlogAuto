## 3. API가 없어서 손으로 가는 것 (바꾸지 않음)
- 블로그 통계(유입 검색어·홈판 비율) — 네이버 비공개. **붙여넣기**(searchad.extract_keywords)로. 나침반의 빠진 고리.
- 대한항공·아시아나 좌석 — 로그인 API·화면, 차단 규칙 그대로.
- KB 시세·매물 수·NEXCO 요금·KEP/HEP 요금 — 파일/화면 확인.
- 축구(K리그 기록)·풋살·심박 — 공식 API 없음. 워치 캡처·K리그 공식 기록 화면.
- 일본 기상청 — 스크랩 유지(공식 API 없음).

## 4. 순서 제안
1. 기상청 ASOS 일자료 + 단기예보 (지금 신청 → 257·336·337이 한 번에 산다)
2. 천문연 출몰·특일 (연휴 날짜 근거·야간 산행)
3. 인천공항 승객예고 (1월 출국 전)
4. 수출입은행 환율 (하나은행 스크랩이 끊길 때의 보험)
5. 오피넷 (자동차 오래 타기 글을 시작할 때)
각각 레이더 ⚙ 설정에 키 칸을 하나씩 늘리고(1.850~), 수집 모듈은 `radar/collect/`에 둔다. 매일 저장이 필요한 건 예보 하나뿐이라 아침 보고 작업(07:11)에 붙이면 된다.
