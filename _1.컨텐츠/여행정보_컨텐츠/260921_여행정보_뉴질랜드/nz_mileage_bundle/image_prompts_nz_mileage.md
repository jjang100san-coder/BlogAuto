## 공통 스타일 문구 — 모든 프롬프트 맨 앞에 붙인다

```
따뜻한 색감의 평면 일러스트(플랫 벡터 스타일). 굵은 외곽선 없이 면으로 표현.
색은 크림색 배경 + 연파랑 + 진남색 + 포인트 색 하나. 여백 넓게, 요소 2~3개만 크게.
사람은 뒷모습이나 실루엣만. 텍스트, 숫자, 로고, 워터마크 없음. 16:9.
```

## img1.png — 썸네일 (같은 좌석, 다른 값)

```
[공통 스타일 문구] + 정사각형 + 포인트 색 청록.
크림색 배경 한가운데에 비행기 좌석 한 개가 측면으로 크게 놓여 있다. 단순한 면으로만 그린 좌석.
좌석 등받이에 가느다란 끈으로 종이 태그 두 개가 나란히 매달려 있는데,
왼쪽 태그는 작고 연한 청록색, 오른쪽 태그는 그보다 두 배쯤 크고 진한 주황색이다.
두 태그 모두 아무 글자도 없이 색면만. 크기 차이가 한눈에 보이는 게 핵심.
좌석 아래쪽에 작은 종이비행기 한 대. 오른쪽 위 여백에 잎이 갈라진 식물 잎 한 장을 작게.
```

## img2.png — 하루 한 편뿐인 노선

```
[공통 스타일 문구] + 포인트 색 겨자 노랑.
밤 공항 터미널 내부. 탑승구가 가로로 네다섯 개 늘어서 있는데 맨 왼쪽 하나만 불이 환하게 켜져 있고
나머지는 전부 어둡게 잠겨 있다. 불 켜진 게이트 앞에만 사람 두엇의 뒷모습 실루엣.
통창 너머 활주로는 짙은 남색, 유도등 불빛이 점점이. 게이트 번호나 안내판 글자는 없다.
```

## img3.png — 달력에서 몇 덩어리만 값이 다른 구간

```
[공통 스타일 문구] + 포인트 색 주황.
숫자 없는 달력 격자 한 장이 화면 가운데 크게 놓여 있다.
대부분의 칸은 연한 민트색인데, 세 군데만 칸이 서너 개씩 묶여 진한 주황색으로 칠해져 있다.
주황 덩어리 위에는 각각 작은 전나무 한 그루, 폭죽 모양 하나, 둥근 보름달 하나가 아주 작게 얹혀 있다.
격자 옆에 연필 한 자루. 숫자와 요일 글자는 절대 넣지 않는다.
```

## img4.png — 한 줄은 비고 한 줄은 찬 좌석 배열

```
[공통 스타일 문구] + 포인트 색 연두.
위에서 내려다본 비행기 객실 좌석 배열도. 가로로 긴 좌석 줄이 위아래 두 줄 있다.
위쪽 줄은 좌석 대부분이 비어 연두색 윤곽선만 남아 있고, 두어 개만 채워져 있다.
아래쪽 줄은 반대로 좌석 대부분이 진회색으로 꽉 채워져 있고 한두 개만 비어 있다.
두 줄의 대비가 한눈에 읽히도록 단순하게. 좌석 번호나 글자는 없다.
```

## img5.png — 커튼이 쳐진 앞쪽 객실

```
[공통 스타일 문구] + 포인트 색 회청.
비행기 객실 통로를 정면에서 본 구도. 통로 끝에 두꺼운 커튼이 완전히 쳐져 있어 앞쪽이 막혀 있다.
커튼 앞쪽 통로는 텅 비어 있고 바닥 유도등만 희미하게 이어진다.
커튼 옆 벽에 작고 둥근 표지판 하나가 걸려 있는데 아무 글자도 그림도 없는 단색 원이다.
사람은 없다. 조용하고 닫힌 느낌.
```
