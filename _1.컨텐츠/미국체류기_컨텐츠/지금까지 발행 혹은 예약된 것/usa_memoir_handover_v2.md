## 1. 기본 정보

**소재**: 2019~2020년 미국 출장 체류. 거주지 **Goleta, CA 93117** (홀리스터 빌리지 3층).
산타바바라 서쪽. 1번 국도변이고, 이 위치가 1년 전체의 이동 반경을 설명한다.

**체류 구조 — 연속된 1년이 아니다**

| | 기간 | 성격 |
|---|---|---|
| 1차 | 2019년 5월 ~ 10월 | 원래 6개월 |
| 귀국 | 2019년 10월 | 제주도·집들이·이태원 할로윈 폴더가 이 시기 |
| 2차 | 2019년 11월 ~ 2020년 4월 | 6개월 추가. 코로나로 조기 종료 |

🚨 6개월이 더 붙은 **배경 사유는 문서에도 본문에도 남기지 않는다.** 회사 영역.
비자 문제도 아니었으므로 "연장"이라는 말도 쓰지 않는다.
쓸 수 있는 범위는 "원래 6개월이었는데 6개월이 더 붙었다"까지.

**차량**: 렌터카. 한 달에 한 번꼴로 차를 바꿔 탔음.
→ 회사 지원 조건은 쓰지 않고 "굳이 바꿔 탔다"는 선택만 쓸 것.
→ 「한 달에 한 번 차를 바꿨다」로 별도 한 편 가능.

| 공학 유추 | 편마다 1개 | **없음** |

### 카테고리 결정 근거

Moments가 아니라 Travel 하위인 이유:
- 예고를 안 걸므로 **카테고리가 유일한 동선**이다. 무관한 글이 섞이면 정주행이 끊긴다
- 그랜드캐년 브릿지 글로 미국 서부 시리즈와 이어야 하는데, 같은 상위여야 이동이 자연스럽다
- 체험단 심사에서 Travel 카테고리 깊이가 지표가 된다
- Moments에 20편이 들어가면 Moments가 죽는다

편수가 15~20편을 넘으면 상위 승격 재검토.

## 3. 구조

### 시간순 뼈대 + 편당 장면 하나

장소가 아니라 **순간**이 단위. 같은 장소에서 여러 편이 나와도 무방.

> ❌ "데스밸리 갔음" → 글이 안 됨
> ⭕ "기름이 얼마 안 남아서 계기판만 봤음" → 한 편이 됨

### 제목

날짜를 넣지 않는다. 본문 첫 줄에 넣는다.
형식: `[장면] | 미국 체류기`

### 확정된 처음과 끝

```
2019.5.11  캘리포니아 1번 국도   ← 1편. 혼자
2019.5.25  샌디에이고            ← 4편. 첫 동행
2019.10    귀국
2019.12~1  가장 활발했던 시기
2020.1/27~3/21  8주 공백        ← 🔴 진짜 공백
2020.3.21  1번 국도 드라이브     ← 마지막 편. 다시 혼자, 같은 길
2020.4.16  "기타 사진들"         ← 이름 붙일 시간 없이 귀국
```

시작과 끝이 같은 길이다. 의도한 게 아니라 실제로 그렇게 됐다는 점이 이 시리즈의 핵심.

### 🔴 2020년 2월 8주 공백

코로나 부상기. 동양인 대상 사건 보도가 강해지던 시점.
**나갈 수 있는데 안 나간 8주.** 5월의 혼자(아직 아무도 못 만나서)와 종류가 다르다.

서술 범위:

| | |
|---|---|
| ⭕ | 그때 내가 뭘 보고 어떻게 느꼈는지 (1인칭 사실) |
| ⭕ | 나가지 않기로 한 선택과 그 8주 |
| ❌ | 미국 사회·인종 문제에 대한 일반화나 평가 |
| ❌ | 뉴스 인용, 통계, 사건명 나열 |

**당한 얘기가 아니라 안 나간 얘기**로 쓴다.

각 편의 축:

1~3편은 전부 "어떻게 돌아왔나"이고, 4편에서 축이 바뀐다.

### 4편의 결정적 자료

2019.05.02 03:59 작성한 동행 구인 글이 남아 있다.

> *아직 업무적으로 영어적으로 공부 중에 있어서,*
> *혼자 어딜 가야겠다는 용기가 안 나네요.*
> *(한국에서는 잘 다녔습니다만..)*

## 5. 작업 방법 — 반드시 이 순서

### 5-1. 폴더 ZIP → EXIF부터

1편은 폴더명만으로 짰으면 "물범 보고 버거 먹고 다리 봤다"로 끝났을 것이다.
실제로 글을 만든 건 **14:29라는 시각**과 **내비 화면**이었다.

```python
# GPS + 파일명 시각 추출
from PIL import Image
from PIL.ExifTags import TAGS, GPSTAGS
```

- `DateTimeOriginal`은 비어 있는 경우가 많음 → **파일명이 시각**(`YYYYMMDD_HHMMSS`)
- GPS는 살아 있음 → 좌표 순서가 시각 순서를 교차검증해준다
- 구간 평균 속도를 계산하면 **어디서 멈췄는지**가 나온다 (3편 주유소 추정에 사용)

### 5-2. 사진을 실제로 볼 것

컨택트시트로 묶어서 본다. 확대 없이 판단하면 틀린다.
→ 2편에서 수면 위 물체를 "지느러미"로 단정했다가 정정한 사례 있음.

### 5-3. 사용자 확인 전에는 단정 금지

**이번 세션에서 그럴듯했지만 틀린 가설이 셋 나왔다.**

1. 9~11월 8주 공백 = 심리적 공백 → **실제로는 한국 체류**
2. 폴더명 with 표기로 본 혼자→동행 곡선 → **폴더명이 동행을 다 담지 않음**
3. 사진 속 물체 = 상어 지느러미 → **확대하니 판독 불가, 현장 증언이 우선**

→ 단서는 단서일 뿐이다. `[확인 필요]`를 반드시 표기한다.

## 6. 발행 전 확인

### 회사 관련 (제일 엄격)
- [ ] "출장으로 미국에 있었다"는 사실 외 전부 제외
- [ ] 회사명·로고·명함·사업장·제품·도면·동료
- [ ] 렌터카 지원 조건, 계약 형태, 상대 업체, 체류 연장 사유
- [ ] `'19.6.23~27 샌프란시스코 출장` 폴더는 업무 → 사진 섞임 주의

### 동행자
- 인터넷 카페에서 만난 사람들 → 연락 끊긴 경우가 많다
- **흰색 패딩 착용자는 지금도 연락하는 사이** → 동의를 구할 수 있음
- 동의 없으면 얼굴 사용 금지 (뒷모습·원경·실루엣만)
- 이름·닉네임·직업·거주지 미노출
- ⚠️ 공유받은 사진은 **촬영자 동의도 별도로 필요**
- ⚠️ 지금도 연락하는 사람은 **이 글을 볼 수 있다**

### 개인정보 일반
- [ ] 차량 번호판 → **검은 사각형** (모자이크·블러 금지, 복원 가능)
- [ ] 내비 화면의 목적지 주소
- [ ] 여권·비자·면허·보험증서
- [ ] EXIF는 제거하지 않음 — 현재 거주지가 아니므로 사용자 판단으로 유지

### 사고·타인의 위기 장면
3편에 응급 헬기 장면이 있다. 이런 소재는:
- 결과를 단정하지 않고 **본 것만** 쓴다
- 구경거리로 만들지 않는다. 묘사를 늘리지 않는다
- 위치·날짜를 특정하지 않는다 (검색으로 사고를 되짚을 수 있다)

## 6-3. 🔗 발행 후 내부 링크 — 편당 1~2개만

1~15편은 **구형식**이라 `[[LINK:]]` 마커를 쓰지 않는다.
네이버 편집기에 붙여넣은 뒤 **텍스트 링크로 직접 삽입**한다.

16편부터는 마커를 쓰고, 연재물이므로 **`▶ N편` 머리말**을 붙인다.

```
[[LINK:https://blog.naver.com/… | ▶ 9편 무서워서 남한테 맡겼어]]
→  ▶ 9편 : 무서워서 남한테 맡겼어   (콜론 뒤부터만 링크)
```

URL이 없으면 파이프 앞을 비운 채 **본문에 둔다.** 작업 메모로 빼면 잊는다.

**시간순 연재라 앞 편은 이미 발행돼 있다.** 뒤 편은 절대 링크하지 않는다.

### 링크를 걸 자리 (그 편을 안 읽으면 이해가 안 되는 참조만)

| 편 | 링크 대상 | 본문 어디 |
|---|---|---|
| 4편 | — | (시리즈 첫 참조 지점) |
| 5편 | 2편 | "2주 전에도 배를 타고 섬에 갔었는데" |
| 6편 | 4편 | "일주일 전에도 처음 보는 사람들이랑 다녔었어" |
| 7편 | 6편 | "일주일 전에 조슈아트리에 다녀왔었어" |
| 8편 | 3편 | "한 달 반 전에 혼자 갔던 데야" |
| 9편 | 6편 | "한 달 반 전에도 투어를 한 번 갔었어" |
| 10편 | 4편 | "두 달 전에 처음 갔던 데야" |
| 12편 | 3편 | 마무리의 "남의 나라" 대목 |
| 13편 | 1편 | "5월 첫 주말에 나는 구글 지도를 열고" |
| 14편 | 1편 | "미국에 온 첫 주말에 간 데야" |

| 15편 | 4편 | "5월에 나는 카페에 글을 하나 썼어" |

⚠️ **링크를 안 거는 참조**: 문장만으로 이해되는 것.
"두 달 전에도 여기 왔었어", "그때는 무서웠어" 등은 그대로 둔다.
전부 링크하면 각주투성이가 되고, 회고록의 흐름이 끊긴다.

### 발행 순서 주의

허브 글이나 뒤 편을 참조하는 링크는 **그 편이 발행된 뒤에** 넣는다.
편이 다 쌓이면 시간순 목차 허브 글을 하나 만들어 전부 묶는다.

## 7. 글 형식

**마스터 지침을 따른다.** 아래는 이 시리즈에만 해당하는 것.

- 짧은 호흡 줄바꿈, 친근한 말투 (`~해 / ~야 / ~거든`)
- **표·리스트 최소화** — 회고록은 문장이 중심
- 열린 결말 + **질문으로 마무리** (편마다 다른 질문 — 중복 점검 필수)
- 제목에 날짜를 넣지 않는다. **본문 첫 줄**에 넣는다
- 제목 형식: `[장면] | 미국 체류기`
- **예고를 걸지 않는다.** 1편의 마지막 편 연결선 한 줄만 예외

⚠️ 1~15편은 구형식이라 `📷 **[사진 N]**` 번호 마커를 쓴다.
**16편부터는 마스터 5-4에 따라 번호를 붙이지 않는다.**

### ⚠️ 「사계」 → 「Why」 정정 (2026-08-31)

당초 「사계」의 뮤직비디오가 조슈아트리 부근에서 찍혔다고 적어두었으나 **혼동이었다.**
「사계」는 그 1년 중 가장 기억에 남은 곡이지만 촬영지와는 무관하다.

촬영지가 있는 곡은 **태연 「Why」(2016)**이고,
조소영 감독 연출로 **캘리포니아 산타바바라와 팜스프링스**에서 촬영됐다.

→ 산타바바라는 **거주지 고레타 바로 옆**, 팜스프링스는 조슈아트리로 가는 관문 도시.
   살던 동네와 가려던 사막 양쪽에서 찍힌 곡이라는 점이 조슈아트리 편의 재료가 된다.

📌 이 건은 **사용자 기억이 먼저 틀렸고 사용자가 스스로 정정한** 사례다.
   앞서 미검증으로 표시해둔 덕분에 잘못된 내용이 본문에 들어가지 않았다.
   `[확인 필요]` 표기를 계속 유지할 것.

## 10. 운영

- 콘텐츠 막힐 때 하나씩 발행. 몰아 올리지 않는다
- **전체 발행량 하루 3~4개** (2026.9.15 상한 수정). 단 **회고록은 그중 하루 1편까지**
- 시즌 콘텐츠 사이에 끼워 넣는다 (회고록만 올리면 블로그가 과거로 가득 찬다)
- 편이 쌓이면 시간순 목차 허브 글 하나

### 🚨 초안 수와 발행 속도는 다른 얘기다

현재 1~8편 초안이 완성돼 있다. **이걸 몰아 올리면 안 된다.**

전체 상한은 하루 3~4개로 올랐지만(2026.9.15 실증), **회고록은 그 안에서 1편까지**다.
이유는 유입이 아니라 **블로그의 인상**이다. 연속으로 올리면 과거 얘기로 가득 차 보인다.

- 회고록은 검색 유입을 못 만든다 → 정보형이 밀려나면 장기 성장이 죽는다
- 시즌 콘텐츠 사이사이에 하나씩 끼워 넣는다
- 시의성 전략(이벤트 2~5일 전 발행)은 정보형의 방식.
  **회고록은 시점이 없으니 시의성 콘텐츠의 빈칸을 메우는 용도**로 쓴다

### 회고록이 유입에서 하는 역할 (2026.8 데이터 기준)

- 검색 유입은 **못 만든다.** 상위 글은 전부 경비·숙소·렌터카 실무 정보
- 대신 **피드·홈판 노출**(유입의 53%)에 기여한다. 다만 이건 휘발성이라 꾸준한 발행이 전제
- **Travel 카테고리 깊이**를 채운다 → 체험단 심사 지표
- ⚠️ 따라서 회고록이 정보형 콘텐츠를 밀어내면 안 된다. 검색 유입이 장기 안정성의 핵심

### 지명 처리 — 2026.09 실측으로 강화됨

**소제목에는 고유명사를 넣는다.** 실측에서 제목에 없던 지명이 실제 검색어로 걸혔다.
장면 문장을 유지한 채 이름만 끼워 넣는다.

```
🦭 피에드라스 블랑카스에 물범이 누워 있었어
♨️ 옐로스톤은 땅에서 김이 올라왔어
🏜 브라이스 캐니언을 하나 더 넣었어
```

1~15편 소제목 **31곳을 이 방식으로 수정 완료** (2026.9.7).

본문 문장은 계속 묘사로 간다(`소금 평원`). ALT·해시태그에도 정식 명칭을 넣는다.
단 **결말 반전이 지명에 걸린 편(11편 웨이페어러스 채플)은 소제목에 넣지 않는다.**

### 📂 카테고리 주제 설정
네이버 카테고리별 주제 지정에서 **「세계여행」**으로 맞출 것.
내용과 안 맞으면 엉뚱한 독자에게 노출돼 이탈률이 오르고, 현재 강점인 체류시간을 깎는다.
