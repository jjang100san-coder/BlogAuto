# 1. 🍽️ 이름과 범위

**카테고리명: 「먹!자」**

「밥!집」을 먼저 떠올렸다가 바꿨다. **「밥」이 들어가면 밥에 한정된다.**
커피·디저트·빵집·술집·분식까지 다 담으려고 제한을 없앴다.

느낌표는 그대로 뒀다. 리듬이 생기고, 청유형 동사라 블로그명 「**걷고 읽고 떠나고**」와 결이 맞는다.
(카테고리명은 검색에 안 걸리므로 특수문자가 있어도 상관없다.)

## 🚨 범위 — 여행과 갈라놓는다

| 어디서 먹었나 | 어느 카테고리 |
|---|---|
| **여행 중에** 먹은 것 | **Travel** (해당 여행 글 안에 소제목으로) |
| **국내에서 식당에 가서** 먹은 것 | **먹!자** |

🚫 **여행지 식당을 단독 글로 빼지 말 것.** 여행 글이 얇아지고 내 글끼리 경쟁한다.
(마스터 13-2 「여행 중 식사 vs 먹!자」)

---

# 2. 🗂️ 주제 설정

**「맛집」으로 둔다.** 여행에서 떼어냈으니 주제도 떼어내야 한다.

⚠️ 카테고리 관리에서 주제 목록에 맛집이 있는지 **화면에서 확인**할 것.
내용과 주제가 어긋나면 엉뚱한 독자에게 노출돼 체류시간을 깎는다. (마스터 13-3 「먹!자 = 맛집」)

---

# 3. ✍️ 쓰는 태도 — 맛을 평가하지 않는다

**이 블로그는 맛 평론을 하지 않는다.** 그게 약점이 아니라 이 카테고리의 규격이다.

| 🚫 안 쓴다 | ⭕ 대신 쓴다 |
|---|---|
| 육즙이 어떻고 감칠맛이 | **뭘 시켰고 얼마였나** |
| 인생 맛집 / 강추 | 웨이팅 몇 분, 주차 되나, 몇 시에 갔나 |
| 별점·평점 | 그날 못 먹은 것, 품절, 실패한 주문 |
| 남에게 권하는 투 | **"내 경우엔 이랬다"** |

지금 블로그가 실제로 걸리는 건 `숙소` `경비` `1박` 같은 **실무어**다.
음식 글도 같은 재료로 간다. 맛 평가는 애초에 재료에 없다.

💡 **실패담이 강점이다.** 웨이팅하다 포기한 것, 품절이라 못 먹은 것, 주차 못 해서 돈 낸 것.
제목 뒷부분에 그대로 쓴다 — 못 먹은 것, 기다리다 포기한 것. 단 제목이 약속한 건 본문에 있어야 한다(마스터 10-3).

💸 협찬·제휴·쿠폰으로 간 곳이면 대가성 문구가 의무다 (마스터 7장 · 16-9).

# 4. 🎯 제목 — 지역명이 맨 앞

**동네 식당은 상호만으로 아무도 검색하지 않는다.**

```
[지역명] [상호] [업종/메뉴] [가격·실무어]  |  [후킹 한마디]
```

| ❌ | ⭕ |
|---|---|
| `오늘의 점심` | `OO동 OO국밥 가격 후기 | 9천원인데 공기밥이 두 공기야` |
| `분위기 좋은 카페` | `OO동 OO카페 메뉴 주차 | 주차장이 카페보다 좋았어` |

먹!자 글은 **검색형(마스터 10-7)**이 기본이다 — 앞은 「지역명 + 가게 이름 + 메뉴·주차·웨이팅 같은 함께 찾는 명사 2~3개」, 구분선 뒤에만 문장. `[후킹 한마디]`는 마스터 10-5·10-6을 따른다 — 질문형은 뒤집을 숫자가 있을 때만, 없으면 발견형 평서문. 실패담은 10-6의 「놓친 것 하나를 내 영수증으로」와 같은 결이다. **제목을 정하기 전에 점검표(마스터 10-8)** — `title_check.py --q "지역명 가게 이름"`으로 메뉴·주차·웨이팅 중 검색량이 있는 말을 고른다. 「○○ 맛집」은 큰 말이라 앞에 그대로 두지 않는다.

**검색 경로가 여러 갈래로 늘어난다** — 지역명 / 상호 / 메뉴 / 가격.
검색량은 작지만 **경쟁이 거의 없는 롱테일**이라 신생 블로그가 실제로 1등 하는 구간이다. (마스터 1-5)

⚠️ 카페는 `OO동 카페`가 경쟁이 세다. **상호 + 구체 실무어**(주차·콘센트·웨이팅)로 파고들 것.

## 소제목 재료 (마스터 1장 — 고유명사 + 결론 평서문)

```
🍜 OO국밥은 OO역 3번 출구에서 5분이야
💰 순대국밥이 9,000원이었어
🅿️ 주차는 건물 뒤에 네 자리뿐이야
⏰ 12시 20분에 갔더니 열두 명이 서 있었어
🚫 수육은 그날 품절이었어
```

**상호에 금액을 붙이면 소제목 하나가 검색 두 갈래를 잡는다.** (마스터 1-4 독립 소제목을 먹!자에 맞춘 확장)

# 5. 📷 사진

기본은 마스터 5·6장. 이 카테고리에서 특히 걸리는 것만.

| 항목 | 규칙 |
|---|---|
| **다른 손님** | 원거리·식별 불가만. 홀 전경은 사람 없을 때 (마스터 6-1) |
| **직원 얼굴·명찰** | 제외 |
| **영수증** | 금액 근거로 본문에 좋다. 🚫 **썸네일로는 금지** (축소하면 글씨가 뭉개짐) |
| **카드 영수증** | 카드번호·승인번호는 **검은 사각형**으로 가린다. 금액·시각은 가리지 않는다 (마스터 6-3 · 6-5) |
| **가족·동행** | 풍경·음식만 또는 뒷모습만 (마스터 6-1) |
| **QR 주문판** | 테이블 QR이 찍히면 빼거나 가린다 (마스터 6-2) |
| **AI 이미지** | 마스터 5-5 그대로. 5-6 삽화는 Travel 글만이라 먹!자에는 쓰지 않는다 |
| **썸네일** | 음식 클로즈업 한 접시. 상차림 전체는 축소하면 뭉개진다. 🚫 가격표·비교표·통계 카드를 첫 이미지로 쓰지 않는다 (마스터 5-4 썸네일, 2026.10.9) 세 질문(마스터 5-4, 10.15): 그 집 대표 메뉴 한 접시가 ①②③을 한 번에 채운다. 외관만·거리 풍경만은 무슨 집 글인지 몰라 ②✕ |

💡 **색 대비**가 관건이다. 국물·갈색 음식은 피드 흰 배경에서 묻힌다.
밝은 반찬이나 그릇 색이 같이 들어간 컷을 첫 사진으로.

지금 한식/양식/카페로 미리 갈라두면 빈 칸만 생긴다. (**분야 예외** — 마스터 13-2의 일반 기준은 3편, 먹!자 안의 세 번째 단계 분류는 10편. 2026.10.7 사용자 결정, 마스터 13-2에도 같은 표시)

# 7. 🔗 등산(Move > 등산)과 엮인다

이미 **「산은 공짜인데 뒤풀이가 17만 5천원」** 글이 있다. 사실상 이 카테고리의 원형이다.

- 산 다녀와서 먹으면 **등산 ↔ 먹!자**가 자동으로 링크로 묶인다 (마스터 12장 짝 글 링크)
- 등산 글 주 독자층은 **50-60+**, 실용 정보를 보러 온다
- **산 근처 밥집**은 그 독자층에 정확히 맞는다 (마스터 11장)

→ 「OO산 등산하고 먹은 곳」 조합은 두 카테고리가 같이 먹는 소재다.
