# 2027 추석 대한항공 마일리지 항공권 오픈 현황

> ⚠️ **본문 3~5장은 2026-09-20 05:40 KST 스냅샷이다. 같은 날 20:40에 2027-09-15가 열렸다 → 9장 업데이트 로그 참조.**

- **조회 시각**: 2026-09-20(일) 새벽 05:40 KST (9장에 20:40 재조회 추가)
- **조회 조건**: 성인 1명, 대한항공 자사 직항, 보너스 항공권(KEBONUSNEW)
- **조회 방법**: 로그인된 크롬 세션에서 대한항공 award API 인페이지 호출 (`mileage-seat-search`)
- **2027 추석 연휴**: 9/14(화) ~ 9/16(목) / 추석 당일 9/15(수)
  - 연차 9/13(월)·9/17(금) 사용 시 **9/11(토)~9/19(일) 9일 연휴**

## 1. 핵심 결론 3줄

1. **오픈 한계일은 하루에 한 칸씩 밀린다.** 09-20 새벽엔 2027-09-14까지, 같은 날 저녁엔 2027-09-15(추석 당일)까지 열렸다. 09-16 이후는 아직 미오픈.
2. **장거리 프레스티지석은 사실상 전멸.** 5개 노선 × 열린 전 날짜 중 좌석이 있는 건 **PRG→ICN 9/13 KE970의 단 1석**뿐이다.
3. **일반석은 노선별로 극명하게 갈린다.** 뉴욕·라스베이거스는 열린 날짜 전부 여유, 파리는 9/13부터만, 프라하는 운항일 자체가 적다.

## 7. 재조회 방법

```
프로젝트: C:\Users\user\Desktop\Blog\projects\mileage-seat-search
```

1. 크롬에서 koreanair.com 로그인
2. `npm run browser` → Playwright 확장에서 해당 탭 `Allow & select`
3. 인페이지 award API 호출 (`POST /api/ap/booking/avail/awardAvailability`)
   - 헤더 4종 필수: `ksessionId`, `timestamp`, `channel: pc`, `Content-Type`
   - 호출 간 2초 이상 간격

### 걸렸던 함정 메모

- 브리지의 `browser_run_code_unsafe`에 넘기는 코드는 **`async (page) => { ... }` 형태의 표현식**이어야 한다.
  `return await ...`로 시작하거나 top-level `await`를 쓰면 SyntaxError.
- 미오픈 날짜는 **에러가 아니라 빈 목록**이다. 대조군 노선으로 판정할 것.
- 프레스티지가 전부 매진으로 보이면 API 착시인지 먼저 의심할 것.
  → ICN-NRT 2027-02을 찍어 프레스티지 1~2석이 정상 표시되는 걸 확인했으므로 **이번 결과는 실제 매진**이다.

## 9. 업데이트 로그

### 2026-09-20(일) 20:40 KST — 2027-09-15(추석 당일) 오픈

같은 날 새벽 05:40에는 미오픈(항공편 0건)이었던 2027-09-15가 저녁 20:40에 열렸다.
대조군 ICN-NRT가 5편 정상 반환되어 **실제 오픈**임을 확인했다(오전엔 0건이었다).
2027-09-16은 여전히 `no-bound` = 미오픈.

#### 이 회차에서 새로 나온 사실 3가지

1. **오픈 주기는 359일이 아니라 359~360일이다.**
   새벽엔 +359일, 저녁엔 +360일. 하루 중 특정 시각에 한 칸 넘어간다.
   "D-361일 오픈"이라는 통념과도, 아침에 측정한 359일과도 다르다.
   → **노리는 날짜가 임박하면 아침에 한 번, 저녁에 한 번 찍어야 한다.**

2. **CDG → ICN 09-15는 오픈 당일인데 두 편 모두 일반석까지 매진이다.**
   09-10~09-14는 KE902 일반석이 계속 9석이었는데 09-15만 양편 전멸.
   2회 연속 조회에서 동일하게 재현됐다.
   다만 **오픈 당일 스냅샷이라 재고가 아직 다 안 실렸을 가능성**을 배제할 수 없다.
   → 09-21에 같은 구간을 다시 찍어 "진짜 매진"인지 "오픈 직후 미적재"인지 판정할 것. 이건 글의 핵심 소재가 될 수 있다.

3. **프라하 운항일은 홀수일 패턴이다.** 09-10·11·13·15 운항 / 09-12·14 미운항.
   09-15는 운항일이고 양방향 일반석 9석이 살아 있다.
   단 09-13 PRG→ICN에 있던 프레스티지 1석은 09-15에는 없다.

#### 프레스티지 집계 (누적)

열린 전 날짜(09-10 ~ 09-15) × 5개 노선 양방향 중 **프레스티지 좌석은 PRG→ICN 09-13 KE970의 1석이 전부**다.
09-15 추가분에서도 새 좌석은 없었다.
