## ① 코드표 — 두 글자(IATA)와 세 글자(ICAO)

### 누가 정하나
| | IATA 두 글자 (항공권·편명에 찍히는 것) | ICAO 세 글자 (관제·비행계획서에 쓰는 것) |
|---|---|---|
| 배정 | IATA. 근거는 Passenger Services Conference **결의 762**. 편명은 **결의 761** [공식, 01·08] | ICAO. 신청은 그 항공사를 관할하는 **국가**를 거쳐야만 받는다(Doc 8585 규칙 1.1) [공식(웨이백), 06] |
| 조건 | 정부 발급 운항증명(AOC), 정기편이면 스케줄 공표 증빙. 수수료 「The 2026 fee is USD 6,900 per code.」 [공식, 01] | 한 곳에 하나, 같은 지정자를 두 곳에 주지 않음(규칙 1.2·1.3) [공식, 06] |
| 형식 | 두 글자, 영문+영문 또는 영문+숫자(7C·5J·9C). 숫자+숫자는 없음. 허용 패턴 `[A-Z]{2,3}|[A-Z][0-9]|[0-9][A-Z]` [2차 공식, 09 FIXM] | 세 글자. 회사 이름이나 호출부호를 되도록 닮게(규칙 2.2 a). CZ·ZC·NN 조합, PAN·SOS 금지(2.4) |
| 무선 | — | 호출부호(telephony designator) + 편명으로 부른다. 예 「AEROFLOT 301」(규칙 3.1) |
| 문서 | IATA Airline Code Search 「official source for codes assigned by IATA」 [공식, 02] | Doc 8585 제217판(2026년 7월), 1·4·7·10월 분기 발행 [공식, 03] |

- **숫자를 섞는 이유**: 공식 문장 **미확인**. 다만 IATA 결의 매뉴얼 46판(2026) 개정 목록에 「Resolution 762 - Updated Section 2: Use of Three-letter designators (removing "two character" due to likely depletion)」 [공식, 07] — **IATA 스스로 두 글자 코드가 바닥날 것 같다고 적었다.** (3글자 IATA 코드를 언제·어떻게 쓰는지는 미확인. 같은 목록의 「01 June 2027」은 결의 743b 줄이라 762 발효일로 쓰면 틀림.)
- **같은 코드 두 회사**(controlled duplicate): 「two carriers have the same code but operate different types of non-overlapping services」, 별표(*)로 표시 [공식, 02]. 비정기 항공사는 별표 코드를 받고 「schedules cannot be published」 [공식, 01].
  - 실례 [공식, 02]: **7C = 제주항공 / 7C\* = Coyne Airways(영국)**, **RF = 에어로케이 / RF\* = Erofey(러시아)**.
- **코드 재배정**
  - ICAO 세 글자: 반납된 지정자는 「not be reassigned until a period of at least **60 days** has elapsed」(규칙 1.4) [공식, 06]. 국가 담당자가 60일 대기를 면제하는 칸도 있음 [공식, 04 FAQ 2.3].
  - IATA 두 글자: 대기 기간 **미확인**(「6개월」은 위키 단서뿐).
  - 실례 [공식 두 출처 대조]: **4V** — 국토부 항공정보포털에 플라이강원 4V/FGW 「운영중단」, IATA 조회 현재 4V = 「SKY UP NISTRU」 S.R.L.(몰도바). 날짜·중간 사용자는 미확인.
  - 실례 [시작만 공식]: **WE** — 2014-04-11 태국관광청 「THAI Smile … new airline code WE」 [14] → 현재 IATA WE = PARATA AIR INC. [02]. 파라타가 받은 시점·경위 미확인.
  - TW = 옛 TWA 코드: **관례·단서만**(IATA·국토부 원문 근거 없음).

## ② 숫자 규칙 — 공식과 관례를 나눠서

### ②-1 국제 규정
| 내용 | 등급 | 근거 |
|---|---|---|
| 편명 숫자는 **최대 4자리**(1~9999) | [2차 공식] | FIXM 4.3 「Up to four-digit commercial flight number」, maxInclusive 9999 [09]; OpenTravel 「1-4 numeric」 [17, 3차]. **SSIM 원문(유료)은 미확인** |
| 접미 문자(operational suffix) **영문 대문자 1자** | [공식(IATA 데이터 모델)] | IATA AIDM(출처 표기: SSIM Data Elements) 「A code assigned by the operating airline and appended to the flight number to distinguish multiple flights with the same flight number for operational purposes.」 / 「distinguish two flights having the same flight number and departing … on the same date」 [16]. 한 글자 `[A-Z]` [09] |
| 접미 문자 실제 쓰임: 회항으로 편명이 「다 쓰이면」 A를 붙이는 게 흔함 | [2차] | ACI 데이터 사전 「It is common to append an 'A' to the FlightId if the FlightId is "used up" for instance by a return from airborne.」 [18] |
| 관제용 항공기 식별부호는 **7자 이하** = ICAO 세 글자 + 편명(예 KLM511) | [2차 공식] | FAA AIP 비행계획서 Item 7 「must not exceed seven alphanumeric characters」 [10], FIXM `[A-Z0-9]{2,7}`(출처 Doc 4444) [09]. Doc 4444 원문 직접은 미확인. → 세 글자+네 자리 = 7자(예 JJA1101)로 딱 맞는다는 건 **산술(규정 문장 아님)** |
| ICAO 권고: 편명은 **되도록 짧게, 보통 세 자리까지**, 다른 항공사 편명과 헷갈리지 않게, **가능하면 0·5로 끝나지 않게** | [공식(웨이백)] | Doc 8585 규칙 3장 Note 2 a~c(호출부호 혼동 방지 절) [06]. 호주 항공항행청 문서도 같은 권고 [15] |

### ②-3 공식으로 확인되는 편명 관련 사실 (약관·공지)
- **공동운항 약관 조항** [공식]
  - 대한항공 국제여객운송약관(2025.6.30 발행) **제11조 공동운항편** 1항: 「타 운송인이 운항하는 항공편에 대한항공 코드를 부여하여 항공권을 판매할 수 있으며 … 이 경우 동 운송 구간에 대하여 대한항공 운송 약관이 적용되며 … 다만, 일부 사항은 … 제휴 운항사의 운송 규정이 적용될 수 있으며」. 3항: 남이 팔고 대한항공이 운항하면 「항공권을 판매한 운송인이 의무를 부담한다」. 국내여객운송약관 **제9조**도 같은 취지.
  - 아시아나 국제여객운송약관(제46차, 2025.01.15) **제2조 7항 가호**: 「…항공사 코드(OZ)로 항공권을 판매할 수 있으며, 여객이 동 서비스 예약 시 아시아나항공은 **실제 항공기를 운항하는 운송인을 여객에게 고지**한다.」 다호: 운항사 규정이 적용될 수 있는 9가지(탑승수속·마감, 도움 필요 여객·비동반 소아, 수하물, 생동물, 운송 거절, 산소, 비정상 운항, 탑승 거절 보상, 미국 활주로 대기). 영문판 Article 2.7 「airline designator code (OZ)」.
  - 제주항공 국제선 운송약관(2025.1.07 개정) **제2조 제7항**: 「타 운송인이 운항하는 구간에 제주항공 코드(7C)를 부여하여 … 여객이 실제 탑승하는 항공기를 운항하는 운송인을 고지한다.」(웹 원문에 「재량에 의해」가 두 번 겹친 오기 있음)
  - 진에어 국제여객운송약관(Rev.10, 2025.1.31): **공동운항 조항 없음**.
  - 「항공사 지정코드」「편명」 **정의 조항은 네 회사 모두 없음**.
  - → **운항사를 알려 줄 의무를 약관에 적은 곳은 아시아나·제주항공뿐**, 대한항공은 없음.
- **아시아나 편명이 사라진다** [공식]: 아시아나 공지(2026.09.14) 「2026년 12월 17일(출발일 기준)부터 운항하는 아시아나항공 항공편은 대한항공 편명으로 변경되어 대한항공이 운항합니다.」 공동운항편 이관 12/7~12/9. 대한항공 통합 FAQ 「기존 아시아나항공 편명(OZ)이 대한항공 편명(KE)으로 변경」 「편명 외에 다른 부분은 바뀌지 않습니다」. **새 KE 번호를 어떻게 매기는지는 미확인**(aeroroutes 「OZ272/271 → KE047/048」은 단서).

- 대한항공 운항편에는 남의 편명 23종(델타 7xxx 489줄, 일본항공 5xxx, 버진 5xxx, 아시아나 9xxx…), 아시아나 운항편에는 18종이 붙음.
- 내 표의 공동운항: **KE5749 → Operated by LJ0349**, KE5077 → LJ0265 등 5구간 모두 진에어. airport.kr 에서도 KE5749 = LJ349 [계산].

### ③-3 홀짝 — 인천 출발 실제 운항편 끝자리 (`결과3`, `결과6`)
| 편명 | 고유 편명 | 홀수 비율 | 짝수 편명 |
|---|---|---|---|
| 대한항공 KE | 134 | **100%** | 없음 |
| 제주 7C · 진에어 LJ · 트리니티 TW · 이스타 ZE · 에어서울 RS · 에어프레미아 YP · 파라타 WE | 64·44·40·30·15·13·8 | **100%** | 없음 |
| **아시아나 OZ** | 80 | **73%** | **일본행 1xx·미국행 2xx 전부 짝수**(OZ102 나리타, OZ202 LA…) |
| **에어부산 BX** | 9 | 22% | 인천→일본 BX1xx 전부 짝수 |

- 아시아나·에어부산(아시아나 계열)은 **「인천에서 나갈 때 홀수」가 아니라 「동쪽(일본·미국)으로 가면 짝수」로 보임** — 중국·유럽·동남아·시드니행은 홀수. **[관례(공식 문서 없음)]**, 이유 미확인.
- 외항사: 인천을 떠나 **자기 나라로 돌아가는** 중국 항공사(남방·동방·국제·산동·심천·샤먼)·피치·델타·유나이티드·에어캐나다는 **짝수 100%**. 하지만 베트남·비엣젯·캐세이·싱가포르·에바·중화·타이·세부퍼시픽·루프트한자는 돌아가는데도 **홀수 100%** → 「집에서 나갈 때 홀수」는 만국 공통이 아님.
- **내 전자항공권**: 한국 출발 22구간 **전부 홀수**, 한국 도착 21구간 **전부 짝수**(KE071→KE072, KE5749→KE5750, 운항사 LJ0349→LJ0350까지). 국내선 김포→제주 KE1241 홀 / 제주→김포 KE1326 짝.

### ③-4 한 비행기에 편명 몇 개 (`결과4`, `결과4b`)
- 한 주 3,910편 중 편명 1개 46.4% · 2개 26.0% · 3개 11.6% · 4개 6.2% · 5개 4.7% · 6개 3.3% · 7개 1.3% · **8개 0.5%(20편)**.

### ③-5 접미 문자 (`결과5`)
- 한 주 97줄에 접미 문자: **Y 94줄, A 3줄**(실제 운항편 기준 26줄).
- **Y**: 전날 밤 비행기가 자정을 넘겨 뜬 것. KE647Y(싱가포르)는 원본 btime 2026-10-08 23:47 → atime 10-09 00:04, 같은 날짜 목록에 그날 밤 23:35 KE647이 또 있음. SQ605는 매일 Y로만 찍힘. 화면 시각 00:05는 자리표시값. → AIDM 정의(「같은 날짜에 같은 편명 두 편을 구분」)가 실제로 쓰이는 장면. 단, **airport.kr 이 Y를 붙이는 기준 문서는 미확인**(관찰).
- **A**: ZH634A(선전)가 10/9 08:00, 정규 ZH634는 15:15 — 같은 날 같은 편명 2편. A가 붙은 사유(지연·추가편)는 미확인.

### ③-6 끝자리 0·5 (`결과8`)
- ICAO가 「가능하면 0·5로 끝나지 않게」 권고하지만 국적사 실제 편명의 0·5 끝자리 비율: KE 24% · TW 25% · RS 20% · 7C·ZE 17% · LJ 16% · YP 15% · WE 12% · BX 11% · **OZ 9%**. 홀수만 쓰면 끝자리 5가 우연히 나올 몫이 20%라, 대한항공은 권고를 따로 의식한 흔적이 없고 아시아나만 낮다(이유 미확인).

## ④ 읽는 사람에게 쓸모 있는 것

1. **진짜 운항사 확인법 — e-티켓의 Operated by** [공식]
   - 대한항공 공동운항 안내 그림3(e-티켓 확인증 견본): 편명 칸 「**KE5711 / Operated by JL0090** / JAPAN AIRLINES INTERNATIONAL COMPANY」, 그 아래 「…JAPAN AIRLINES 항공기로 운항하는 공동운항편입니다. … **운항 항공사의 터미널과 탑승수속 카운터를 이용**하시기 바랍니다」 (`원문\대한항공_공동운항확인_그림3_E티켓확인증_OperatedBy.jpg`).
   - Operated by 옆 번호는 **운항사 자기 편명을 네 자리로 0을 채워** 찍는다(JL0090, 내 표 LJ0349) — 이게 공항 전광판에 뜨는 「진짜 편명」(LJ349).
   - 항공편 검색 화면에도 편명 옆에 「일본항공 운항」 표시(그림1).
2. **마일리지 — 회사마다 정반대** [공식]
   - 대한항공: 「대한항공 편명 및 예약 등급 기준으로 마일리지가 적립됩니다」(공동운항 이용안내), 스카이패스 「대한항공 편명으로 판매된 공동운항편을 탑승한 경우에도 스카이패스 마일리지를 적립할 수 있습니다」 → **판매 편명 기준**.
   - 아시아나클럽: 「구매하신 운임 및 클래스를 기준으로 **실제 운항 항공사의 적립율**에 의해 적립」, 스타얼라이언스 운항편은 「운항 항공사 편명 및 운항 항공사 적립 기준」 → **운항사 기준**. 단 대한항공과의 공동운항만 「마케팅사 편명으로 마케팅사 회원계좌에 적립」.
   - 통합: 2026-12-17부터 통합 마일리지 제도, 전환비율 「탑승 마일리지 1:1, 제휴 마일리지 1:0.82」(아시아나 공지 2026.09.15).
3. **수하물 — 「운항사 따라」가 아니라 「협정 따라」** [공식]
   - 대한항공 무료 수하물 페이지: 「공동운항에 참여하는 항공사 간의 협정에 따라 **판매항공사 또는 운항항공사**의 위탁 수하물 규정이 적용됩니다」, 대한항공 규정 적용 17곳(델타·베트남·JAL·진에어·아시아나 등) / 운항사 규정 적용 17곳(가루다·에미레이트·중국동방 등). 「최종 안내는 … e-티켓 확인증에서」. (같은 회사 공동운항 이용안내 팝업은 「수하물 규정 … 운항사 규정을 따릅니다」로 단순화 — 결이 다름)
   - 아시아나: 「계약 또는 IATA Resolutions에 따라 … **운항 항공사의 수하물 규정이 반드시 적용되지는 않습니다**」 판매사 규정 적용(대한항공·ANA·싱가포르·유나이티드…) / 운항사 규정 적용(에바·에어부산·에어차이나·타이…).
   - IATA 결의 302 「Most Significant Carrier」는 두 회사 모두 언급 없음.
4. **터미널 — 운항사 따라** [공식]
   - 인천공항 출국절차·환승안내: 「공동운항편(코드셰어), 항공사 사정 등에 따라 실제 출입국 터미널이 달라질 수 있으니 … 전자항공권(E-Ticket) 또는 홈페이지 내 항공편 검색을 통해 터미널을 꼭 확인」(airport.kr 886·926). 「실제 운항 항공사 터미널 이용」 문구는 airport.kr 이 아니라 **아시아나 T2 이전 공지** 문구.
   - 실례 [계산, 261016 노트]: 한 주 KE 편명인데 T1에서 뜬 줄 196, OZ 편명인데 T1 302. OZ6783 = SQ605(T1), KE5679 = VN441(T1).
5. **라운지·체크인·기내 서비스도 운항사** [공식]: 대한항공 「공항 및 기내 서비스는 운항사 기준」「체크인 시 운항사 카운터」, 아시아나 「운항사의 라운지 입장 규정에 따릅니다」.
6. **12/17 이후 OZ 표**: 아시아나 편명이 KE로 바뀐다, 예약번호 6자리는 그대로(대한항공 통합 FAQ).
