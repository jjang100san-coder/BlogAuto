# 마드리드 더비 글 — 이미지 프롬프트 (한글)

정보 카드 다섯 장은 이미 만들어뒀어. 이 글은 카드가 전부 같은 남색이고 표도 하나 들어가서, **중간에 질감이 다른 이미지 두세 장**이 있으면 훨씬 읽기 편해져.

넣어도 되고 안 넣어도 발행에는 문제없어.

---

## 0. 먼저 지킬 것

**선수 얼굴을 절대 만들지 마.** 이강인도 시메오네도 실존 인물이야. 사람이 필요하면 **뒷모습이나 다리, 실루엣, 초점 날아간 형체**로만.

**구단 엠블럼과 유니폼을 만들지 마.** 아틀레티코의 붉고 흰 세로 줄무늬나 레알의 흰 유니폼처럼 **특정 팀으로 읽히는 조합**은 빼. "무지 유니폼", "브랜드 마크 없는 축구화"라고 명시하면 돼. 관중석 색은 그냥 붉은 계열이면 충분하고, 깃발이나 배너는 아예 넣지 마.

**중계 화면이나 기록 사이트 화면을 참조 이미지로 넣지 마.** 전부 제3자 저작물이야. 가져온 건 사실 정보뿐이고 그림은 새로 만드는 거야.

**한글 글자를 이미지 안에 넣지 마.** 어떤 AI든 한글은 깨져. 전광판이나 광고판도 글자 없이 가는 게 안전해.

---

## 1. 공통 스타일 (세 장 모두 끝에 붙일 것)

지난 아시안게임 글이 남색 위주였으니 이번엔 **붉은 계열로 한 톤 틀어주는 게 좋아.** 시리즈 안에서 색감이 겹치면 피드에서 같은 글처럼 보이거든.

```
편집 사진 스타일, 영화 같은 조명, 짙은 적갈색과 검정 위주에 따뜻한 조명 포인트,
야간 경기장 분위기, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

영문 툴이면 이걸로.

```
editorial photography, cinematic lighting, deep maroon and black palette with warm
light accents, night stadium atmosphere, shallow depth of field, subtle film grain,
no text anywhere, 16:9
```

**빼달라고 할 것 (네거티브)**

```
글자, 한글, 숫자, 워터마크, 로고, 팀 엠블럼, 줄무늬 유니폼, 깃발, 배너,
사람 얼굴, 유명인, 뭉개진 손가락
```

## 2. 프롬프트 세 장

### ① 피치에서 올려다본 붉은 스탠드 — 도입부에 넣을 것

경기장의 밀도를 한 장으로 보여주는 컷이야. 더비의 온도를 깔고 시작하는 역할.

```
야간 축구 경기장 피치 쪽에서 관중석을 올려다본 로우앵글 사진,
붉은 계열 좌석이 위로 가파르게 솟아 있고 관중은 전부 초점이 날아가 형체만 남음,
얼굴은 하나도 알아볼 수 없음, 깃발이나 현수막은 없고 좌석 색만 보임,
위쪽에서 조명탑 빛이 쏟아져 내려와 공기 중 먼지가 보임,
아래쪽에 초록 잔디 끝단이 살짝 걸침,
편집 사진 스타일, 영화 같은 조명, 짙은 적갈색과 검정 위주에 따뜻한 조명 포인트,
야간 경기장 분위기, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

관중석에 글자나 팀 로고 모양이 생기면 다시 뽑아. 좌석 색과 빛만 남아야 해.

### ② 잔디 위에 멈춰 선 공과 긴 그림자 — 템포 조절 섹션에 넣을 것

이 글에서 제일 중요한 한 장이야. "서두르지 않고 한 박자 멈춘다"를 그림으로 옮긴 거라 **두 번째 골 문단 아래**가 제자리야.

```
야간 축구 경기장 잔디 위에 축구공 하나가 멈춰 있는 사진,
공은 브랜드 마크나 무늬 없는 단색 흰 공, 살짝 흙이 묻어 있음,
조명 때문에 공 옆으로 사람 그림자 하나가 길게 늘어져 있지만 사람 자체는 프레임 밖,
잔디에 흰 라인이 한 줄 지나가고 배경은 어둡게 떨어짐,
편집 사진 스타일, 영화 같은 조명, 짙은 적갈색과 검정 위주에 따뜻한 조명 포인트,
야간 경기장 분위기, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

공에 브랜드 로고나 오각형 무늬 글자가 생기면 다시 뽑아. "단색 흰 공"을 앞쪽으로 옮겨서 돌리면 잘 먹혀.

### ③ 밤거리 술집 창문 너머 켜진 TV — 마지막 섹션에 넣을 것

"다음 경기를 기다린다"는 톤이야. 세 장을 다 안 만들 거면 이건 빼도 돼.

```
밤 유럽 도시의 좁은 거리, 작은 술집 유리창 너머로 켜진 텔레비전 화면이 보이는 사진,
화면에는 초록 잔디만 흐릿하게 비치고 점수판이나 글자는 없음,
창가에 사람 실루엣 두엇이 등을 보이고 앉아 있고 얼굴은 보이지 않음,
바깥은 비에 젖어 가로등 불빛이 바닥에 번짐, 간판에는 글자가 없음,
편집 사진 스타일, 영화 같은 조명, 짙은 적갈색과 검정 위주에 따뜻한 조명 포인트,
얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

간판이나 TV 화면에 글자가 생기면 실패야. "간판에 글자 없음"을 한 번 더 강조해서 다시 돌려.

## 3. 참조 이미지는 넣지 않아도 돼

프롬프트만으로 충분해. 오히려 실제 경기 사진을 참조로 넣으면 저작권 문제가 생기고 구도까지 끌려가.

세 장 톤을 맞추고 싶으면 **①번을 먼저 뽑아서 마음에 드는 걸 고르고, 그 이미지를 ②③번의 스타일 참조로 재사용**하면 돼.

## 4. 넣을 자리와 파일명

```
06_red_stand.png        →  도입부, 01번 카드 바로 아래
07_ball_on_line.png     →  두 번째 골 섹션, 02번 카드 바로 위
08_night_street_tv.png  →  마지막 섹션 첫 문단 아래
```

세 장 모두 초안에 이미 넣어뒀어. 아래 마커는 다시 넣을 일이 생겼을 때 쓰는 백업이야.

마커는 이렇게 넣으면 돼. 각각 단독 줄로.

```
[[IMG:06_red_stand.png | 더비는 시작 전부터 온도가 다르다]]
[[IMG:07_ball_on_line.png | 한 박자 멈추는 게 이날의 무기였다]]
[[IMG:08_night_street_tv.png | 11월에 한 번 더 보게 된다]]
```

업로드는 **파일 선택이나 드래그**로. 캡처 붙여넣기로 올리면 파일명이 바뀌어서 마커와 어긋나.

## 5. 썸네일은 그대로 둬

**01_score_atletico_real.png 를 첫 사진 자리에 유지해.**

`2 - 1` 숫자가 커서 축소해도 읽히거든. 붉은 스탠드 사진은 예쁘지만 손톱만 하게 줄이면 그냥 어두운 붉은 네모가 돼.

그리고 이 카드 문구를 `이강인의 첫 마드리드 더비 선발`로 바꿔둔 이유가 있어. **제목이 후킹으로 감춘 답(기점 역할)을 썸네일이 미리 주면 안 되거든.** 문구는 건드리지 말고 그대로 써줘.

## 6. 시리즈 색감 메모

지난 아시안게임 카타르전 글에 쓴 AI 이미지 세 장이 **짙은 남색 야간 경기장**이었어. 이번 세 장을 **붉은 계열**로 잡은 건 그것 때문이야. 두 글이 피드에 나란히 뜰 때 다른 글로 보여야 하니까.

다음에 축구 글을 또 쓰면 **주간 경기 톤(밝은 잔디, 파란 하늘)**으로 한 번 더 틀어주는 게 좋아.
