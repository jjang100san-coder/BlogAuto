## 2. 하나은행 상담 결과 (10/16)

### 확정된 숫자

| 항목 | 내용 |
|---|---|
| 담보평가액 | 7억 |
| 방공제 | 4,800만 원 |
| 한도 계산 | (7억 − 4,800만) × 70% = **4억 5,640만 원** |
| 금리 | 5년 고정 **5.62%** (가산·우대 모두 포함한 최종) |
| 금리 기준 | **실행일 기준 — 계속 변동** |
| 중도상환수수료 | **3년 0.78%** |
| 근저당 설정 비용 | 은행 부담 (고객 부담 없음) |
| 우대 조건 | 주거래등급, IRP 등 |
| 소득 산정 | **원천징수영수증만. 올해 급여 불가** |
| 생애최초 LTV | **70% 확인됨** ✅ |

### 여기서 읽어낸 것

**계산 순서가 유리한 쪽이다.**

| 방식 | 결과 |
|---|---|
| (7억 − 4,800만) × 70% ← 하나은행 | 4억 5,640만 |
| 7억 × 70% − 4,800만 | 4억 4,200만 |
| 방공제 없음(MCI 가입 시) | **4억 9,000만** |

→ 같은 방공제라도 **순서에 따라 1,440만 원**, MCI 여부에 따라 **3,360만 원**이 갈린다.

**소득 기준이 작년(2025년)이다.** 원천징수영수증만 받으므로 올해 연봉 인상·성과급은 DSR에 반영되지 않는다. 은행마다 다른 항목이다.

## 3. 검증된 제도 정보

### 3-1. 한도는 네 문턱 중 가장 낮은 것

| 문턱 | 기준 |
|---|---|
| 주택가격별 총액한도 | 15억 이하 6억 / 15~25억 4억 / 25억 초과 2억 |
| LTV | 규제지역 40%, **생애최초 70%** |
| DSR | 은행권 40% |
| 은행 자체 심사 | 은행마다 |

금융위도 저 상한은 **보장액이 아니라고** 명시. 우리 건은 총액한도(6억)에 안 걸리고 **LTV가 결정**했다. DSR 통과 여부는 아직 확인 안 됨(4장 참조).

### 3-2. 방공제 (소액임차보증금 최우선변제금)

경매 시 세입자가 은행보다 먼저 가져가는 금액이라 은행이 미리 차감. **집이 비어 있어도 적용.**

| 지역 | 금액 |
|---|---|
| 서울 | 5,500만 원 |
| **과밀억제권역·세종·용인·화성·김포** | **4,800만 원** |
| 광역시·안산·광주·파주·이천·평택 | 2,800만 원 |
| 그 밖 | 2,500만 원 |

### 3-3. MCI 가입 중단 현황 (2026년 6월 보도 기준)

MCI(모기지신용보험)에 가입하면 **방공제 없이** 한도가 나온다.

| 은행 | 상태 |
|---|---|
| NH농협 | 6/12부터 제한 |
| KB국민 | 6/26부터 |
| **하나** | **7/1부터 신규 중단** ← 우리 건에 방공제가 적용된 이유 |
| 신한 | 중단 보도 있음 |
| **우리** | **보도에 언급 없음 — 확인 필요** |

⚠️ 넉 달 지난 보도다. 현재 상태는 각 은행에 직접 확인.

### 3-4. 그 밖의 규제

- 수도권·규제지역 주담대 **만기 30년 이내** (DSR 우회 방지) → 만기가 짧으면 연간 원리금이 커져 DSR 한도가 또 줄어든다
- 스트레스 DSR **3단계**, 수도권·규제지역 스트레스 금리 하한 **3%**, DSR 산정에 **100% 반영**
- 수도권·규제지역 주담대 시 **6개월 이내 전입 의무**
- 토허구역 **2년 실거주 의무** (별도 규제, 위와 출처가 다름)
- 토허 실거주 유예 신청 기한 **2027.12.31까지 연장** (국토부 9/17 발표, 10/1 시행)

## 4. 남은 은행 3곳 — 반드시 물어볼 것

> **10/16 저녁 바뀜 — 신한 상담 뒤 본인 결정.** 남은 은행은 `신한은행_상담_전사_2026-10-16.md`의 「다음 은행 질문표」 10개로 간다. 한도는 나온다고 보고 **금리 비교 중심**으로 본다. 방공제·담보평가액·MCI는 묻지 않는다. 아래 원래 목록은 기록용으로 둔다.
> - 소득 질문은 신한에서 답이 나왔다: 올해 소득 연환산이 된다(하나는 안 됨).
> - 생애최초 LTV 70%는 신한도 같다.

우선순위 순.

### ⭐ 1순위 — 한도가 갈리는 항목

**MCI 가입이 되나요** → 되면 방공제 없이 7억 × 70% = 4억 9,000만.
**우리은행이 유일하게 가능성 있는 곳.**

**소득을 뭘로 보시나요** — 원천징수만인가요, 최근 급여명세서도 되나요.
→ 올해와 작년 중 어느 쪽 소득이 높은지에 따라 유불리가 갈린다. **이것부터 확인 필요.**

**이 한도가 DSR까지 통과한 숫자인가요** — LTV만 계산한 건지.

**배우자 소득 합산이 되나요** — 합산 시 한도 변화. 단 공동명의가 따라오고 서류가 두 배가 된다.

**방공제 계산 순서가 어떻게 되나요** — 차감 먼저인지 LTV 먼저인지.

**담보평가액이 얼마로 잡히나요** — 은행마다 다를 수 있다. 하나는 7억.

### 2순위 — 고정되는 조건

**중도상환수수료** 요율과 기간 (하나 3년 0.78%가 기준점)
**근저당 설정 비용** 부담 주체 (하나는 은행 부담)
**우대 조건**과 충족 가능 여부
**만기·상환 방식** 선택지

### 3순위 — 금리

금리는 **실행일에 다시 정해지므로 지금 비교 가치가 낮다.**
다만 **"우대 다 채운 최종 금리 + 받은 날짜"**를 같은 방식으로 적어두면 은행 간 간격은 보인다.

→ **가능하면 3곳을 같은 주에 돌 것.** 날짜가 벌어지면 시장금리가 움직여 비교가 흐려진다.

### 일정·의무

언제까지 신청해야 하나요 / 심사에서 실행까지 며칠 / 보완 시 지연
전입 의무 6개월 기산 시점 / 토허 2년 실거주와의 관계

### 6-2. 7편 초안 수정 사항

- [ ] **생애최초 LTV 70% → 확정 서술로** (하나은행 확인됨)
- [ ] 일정 섹션을 실제 일정으로 교체 (11월 초 제출 / 2~3주 / 금통위 두 번)
- [ ] **방공제 섹션 신설** — 제도 설명만, 우리 금액은 제외
- [ ] **MCI 섹션 신설** — 한도가 갈리는 지점인데 아무도 안 알려주는 항목
- [ ] 소득 산정 기준(원천징수 vs 급여명세서)이 은행마다 다르다는 내용 추가
- [ ] 서류 발급 타이밍 경고 추가

→ **방공제와 MCI가 7편에서 제일 값나가는 정보가 됐다.** "수도권은 6억까지"만 알고 가면 모르는 항목이고, 실제로 수천만 원이 갈린다.

### 6-3. 🚨 숫자 공개 원칙 (마스터지침 6-6)

**블로그에 쓰지 않는다**
7억 / 4,800만 / 4억 5,640만 / 4억 9,000만 / 5.62% / 소득 관련 일체

**이유**: 3편 제목에 `2.5%`가 이미 발행돼 있다. 여기에 담보평가액과 LTV가 더해지면 매매가가 역산되고, 단지명·계약 시기와 조합하면 실거래가 자료에서 거래 건이 특정된다.

**쓸 수 있는 것**: 제도 숫자만
지역별 방공제 금액 / LTV·DSR 비율 / 총액한도 구간 / 만기 30년 / 전입 6개월 / 토허 2년 / 중도상환수수료 요율 구조

**서술 방식**: "방공제 4,800만 원을 빼고 70%를 적용하더라" — 구조만, 우리 금액은 비율로도 쓰지 않는다.
