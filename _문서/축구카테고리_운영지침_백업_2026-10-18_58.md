# 4. 🚨 사실 — 축구 글에서 실제로 틀렸던 것

| **숫자는 기록에서** | 골·교체·경고·팀 기록은 **다음스포츠 경기 기록(KFA 원천)**. 영상 속 숫자(점유·패스·공중볼)는 「채널 집계」로만, 출처 미표기면 **방향만** 쓴다 |

| 설영우 | 언론 명단 | 카드 인수인계서가 예로 든 확정 표기 |
| 김명준 | 언론 명단 | 〃 |
| 김준홍 | 언론 명단 | 〃 (수원삼성 골키퍼) |

# 5. 🔬 자료 작업 흐름

## 5-1. 폴더 (마스터 15장 위치)

```
축구_컨텐츠\YYMMDD_주제\
  base data\            ← 원자료: 영상 폴더(seg\transcript.txt), _out_<ID>.txt, 00_발언종합.md, 관전 메모, _경기기록\

  <영문-slug>\           ← 초안 zip을 푼 것 (draft_….md, images\, cards.py)
```

## 5-2. 유튜브 → 발언종합

- 자막을 직접 받는다(`yt-dlp --write-auto-subs --sub-langs ko-orig`). ffprobe가 스마트 앱 컨트롤에 막혀 있어 videoscan 대신 이 방식(10/5~).
- **(2026.10.11) 해설·인터뷰 영상은 처음부터 whisper medium 받아쓰기도 같이 만든다 — 마스터 0-11.** 감독·선수 발언 인용은 자막과 whisper 두 판독이 같을 때 쓴다(위 「인용은 자막 대조」를 강화). 도구는 `_1.컨텐츠\_자동화\yt_extract.py <작업폴더> <영상ID...>`(자막 + whisper 한 번에, 마스터 0-11 4번). 폴더마다 `_추출.py` 를 복사하지 않는다.
- **한 편씩 순차로.** 병렬은 429. 실패하면 몇 분 쉬고 다시.
- 4시간 넘는 라이브는 끝나고도 자막이 8시간 넘게 안 붙는다 → **같은 채널 요약본**을 먼저 찾는다. 대기가 길면 사용자에게 알린다.
- 편수가 많으면(20편 이상) 주제별로 나눠 에이전트가 영상별 정리를 쓰고, 합쳐서 `00_발언종합.md` 하나로.
- 영상을 볼 때 "편수보다 **기간**" — 여러 해에 걸쳐 같은 현상이 나오면 패턴, 한 시점만이면 그때의 모습.

## 5-3. 종합분석 — 모르는 사람이 읽어도 논리가 보이게

- 맨 위에 **자료 기호표**(기록 R · 감독/선수 본인 · 해설 채널 A~) + **확신도 규칙**.
- 확신도: 기록·본인 발언과 해설이 같은 방향이거나 **독립된 해설 3곳 이상** 일치 → 높음 / 2곳 또는 본인 발언 하나 → 중간 / 1곳·판독 불확실 → 낮음 / 내 판단은 [추론]으로 표시하고 근거를 옆에. (**분야 예외** — 마스터 16-0의 🔁 「서로 다른 채널 2편 이상」보다 엄격하게 3곳. 해설 채널이 서로를 인용하는 일이 많아서다)
- 각 절은 **주장 → 근거 → 논리 → 확신도.** 해설끼리 엇갈리면 표로 나란히 놓고 판정한다.
- 마지막에 「확인이 덜 된 것」.

## 5-4. 예측 → 검증

- 프리뷰에 **관전 포인트(채점 기준)**를 적고, 후기에서 표로 채점한다: 맞음 / 반반 / 빗나감 / 판단 보류.
- 프리뷰 ↔ 후기 **양방향 링크**. 후기 발행 뒤 프리뷰 끝에 한 줄(`add_link.py`).
- 사용자의 경기 중 관찰은 `base data\00_관전메모_사용자.md`에 시각과 함께 적고, 해설·회견과 대조해 후기의 1차 관점으로 쓴다.

## 6-1. 이미지 톤 — 카드가 본문보다 먼저 말하지 않게

- **(분야 예외, 2026.10.9 본인 결정) 축구는 썸네일도 1080×1080 카드 그대로 간다.** 마스터 5-4 「썸네일은 궁금한 장면의 AI 이미지」는 축구에 적용하지 않는다 — 카드 이미지가 이 분야의 방향성으로 잡혔기 때문. 아래 결론 바 규칙이 썸네일 규칙이다. **(2026.10.11 보강) 카드 뒤에 팀·감독의 트레이드마크를 그린 AI 배경을 깔 수 있다 — 6-2.**
- **(2026.10.15 마스터 5-4 동기화) 카드여도 썸네일 세 질문을 적용한다.** 조회수 150편 비교에서 경기 **전** 프리뷰 카드(우루과이·베네수엘라·우즈베키스탄·베트남)는 상위, 같은 디자인의 결과 카드(결승 1-0, 사우디 2-0)·감독 프로필 카드는 하위였다. 결과·프로필 글은 답이 그림에 다 있어 ①✕ → 카드 대신 6-2 트레이드마크 AI 장면을 대표로 시험하고, 카드는 2번째 이미지로 내린다.
- **썸네일 결론 바에 제목이 감춘 답을 쓰지 않는다.** 제목이 질문형·발견형으로 답을 숨겼으면(마스터 10-5), 썸네일은 큰 숫자·이름까지만 — 답은 첫 문단에서 (카드 인수인계서 3장).
- 본문 카드의 결론 바 = **그 섹션 소제목의 결론과 같은 말** (카드만 봐도 섹션 결론이 잡히게).
- 예측 글과 검증 글은 일부러 다른 톤, 연재는 편마다 톤을 돌린다 (인수인계서 4-3, 마스터 5-4).
- AI 이미지는 마스터 5-5 그대로 — 얼굴·로고·읽히는 글자 금지, 남의 사진·영상 프레임을 참고 이미지로 넣지 않는다, 프롬프트는 한 장에 한 덩어리. 캡션 `(AI 생성 이미지, 실제 경기 장면 아님)`, 사람이 나오면 `특정 인물 아님`까지. (5-6 삽화는 Travel만 — 스포츠는 5-5 그대로)

## 6-2. 🎯 축구 이미지를 만들 때 — 방향 (2026.10.11 본인 지시)

> 계기: 수원 4-1 안산 리뷰 이미지. 네이버 검색 상위 글을 벤치마킹해 만든 썸네일·네임카드가 「깔끔해졌다」는 평가를 받았고, 같은 방향으로 굳힌다. 사례 폴더 `_1.컨텐츠\축구_컨텐츠\261011_수원안산리뷰\suwon-ansan\` (`cards.py`, `ai\image_prompts_ko.md`).

**① 먼저 벤치마킹한다.** 그 글의 주어(팀·감독·선수)로 **네이버 블로그 검색 화면 상위 8개**를 검색어 5~8개로 받아 썸네일을 한 장에 모아 본다(`261011_수원안산리뷰\base data\_벤치마크_썸네일2.py`). 🚫 검색 API 결과는 화면 순위와 달라 쓰지 않는다. 유입 수는 공개 자료가 없으니 「검색 화면 상위 = 유입이 많이 드는 자리」로 본다. 우리 글의 순위도 같이 적는다.

**② 썸네일 = 트레이드마크 AI 배경 + 큰 숫자 카드.** (2026.10.17 B 양식부터는 `vs_card()`·`namecard_b()`의 팀 색 면이 배경 몫을 한다 — AI 배경은 선택, 쓸 때는 팀 색 면 아래 흐리게)

| 할 것 | 하지 않을 것 |
|---|---|
| 배경은 그 팀·감독의 **트레이드마크를 그린 AI 장면** — 팀 색 깃발이 흐려진 관중석, 해트트릭이면 공 세 개, 감독의 손 신호처럼 **기사·본인 발언으로 확인된 버릇** | 🚫 엠블럼·유니폼 재현·선수 사진·중계 캡처(상위 글이 써도 우리는 안 쓴다) |
| 위쪽(또는 왼쪽)을 어둡게 눌러 **큰 숫자 하나 + 이름·사건 한 줄** | 🚫 국기나 다른 팀으로 오해되는 색 배열(세로 삼색 작은 깃발 = 프랑스 국기로 보여 버림, 10/11 사례) |
| **팀 색 띠**를 상단에(수원 = 청·백·적), 결론 바는 질문형(6-1 — 답은 숨긴다) | 🚫 팀 색을 데이터 표시에 섞기 — 의미색(주황·청록·초록·앰버·빨강)은 그대로 |
| 출처 줄에 `배경은 AI 생성 이미지(실제 경기 장면 아님)`, 손·몸이 나오면 `특정 인물 아님` | 🚫 얼굴·실존 인물 닮게(마스터 5-5) |

**③ 기본 세트는 4~6장.** 썸네일 → **네임카드**(그 경기·그 글의 주인공 한 명, 첫 줄 = 오늘 기록) → 기록·채점 카드 → **전술 도해도**.

**④ 가능하면 전술 도해도를 넣는다.** (2026.10.17부터 `TacticsBoard` — 6-0) 득점·실점 장면, 또는 그 글이 말하는 원리 하나를 세로 피치 두 장(인수인계서 6장)으로. 선수 배치표(자리 번호·이름·좌표)를 먼저 쓰고 그린다 — 선발 자리 번호는 다음스포츠 `formationPlace`(1 GK, 2 RB, 3 RCB, 4 LCB, 5 LB …). 렌더 후 확대해서 **글씨 가림·화살표가 원을 지나는 곳 0건**까지 고친다(클립 지침 4-4-1 세 원칙과 같다).

**⑤ 설명이 부족하면 제작자 컨펌을 받는다.** 도해의 근거(분석 영상·기사)가 장면의 위치·움직임을 다 설명하지 못하면 — 근거가 채널 한 곳의 해석뿐이거나, 확신도 중간 이하이거나, 선수 위치가 자료에 없어 내가 채운 부분이 있으면 — **그 도해는 만든 뒤 「무엇이 근거고 무엇이 내가 채운 것인지」를 적어 제작자(사용자)에게 확인을 요청한다.** 확인 전에는 발행본에 넣지 않는다. 작업 메모의 이미지 표에 「컨펌 대기 / 완료」 칸을 둔다.
