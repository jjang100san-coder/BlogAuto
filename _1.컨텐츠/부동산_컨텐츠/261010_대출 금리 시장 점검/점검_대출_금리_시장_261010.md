# 대출·금리·시장 분위기 점검 — 2026-10-10 기준 (12/18 수원 잔금 관점)

> 언론 보도와 공식 페이지로 확인한 내용이다. 은행별 한도·접수 여부는 매주 바뀌므로 **실제 신청 전 은행 창구 확인이 최종**이다. 개인 한도(소득·DSR)는 매매가·구·소득을 알아야 계산된다.

---

## 1. 대출 — 받을 수 있나

### 1-1. 지금 적용되는 규제 (수도권·규제지역)

| 항목 | 기준 | 비고 |
|---|---|---|
| 주담대 금액 상한(주택 구입) | 15억 이하 **6억** / 15~25억 4억 / 25억 초과 2억 | 2026.4.2 시행, 중도금대출 제외 |
| LTV 일반 | 규제지역 **40%** / 비규제 70% | |
| LTV 생애최초 | 수도권·규제지역 **70%** (그 외 80%) | **6개월 안 전입 의무** |
| DSR | 40%(은행) | 스트레스 DSR 가산금리 하한 **3%**(10·15 대책) — 변동형일수록 한도가 크게 줄어듦 |
| 다주택 | 수도권·규제지역 추가 구입 LTV 0% | 해당 없음 |

**수원은 구마다 다르다.** 영통·장안·팔달은 10·15 대책으로 조정대상·투기과열·토지거래허가(아파트, ~2026.12.31) 지역이다. **권선구는 빠졌다.** 같은 단지라도 동에 따라 팔달·권선으로 갈리는 곳이 있다.

### 1-2. 정책대출 — 은행 총량 규제와 따로 간다

| | 디딤돌(생애최초) | 보금자리론 |
|---|---|---|
| 금리 | 연 2.85~4.15% (소득·만기별, 부부 7천만 이하 30년 3.80%) | 10월 공시 연 4.90~5.30% 고정(아낌e 30년 5.10%), **규제지역 +0.2%p** |
| 한도 | 생애최초 2.4억 / **신혼 3.2억** | 3.6억(생애최초 4.2억) |
| 집값 | 평가액 5억 이하(신혼 6억 이하), 85㎡ 이하 | 시세 6억 이하 |
| 소득 | 생애최초 7천만 / **신혼 8.5천만** 이하 | 7천만 이하(신혼 8.5천만) |
| LTV | 수도권·규제지역 70% | 생애최초 80%(수도권 규제 반영 여부 확인) |
| 우대 | 우대 상한 0.5%p | 신혼 0.3%p(혼인 7년 이내, **결혼 예정 포함**) 등 |

- 5대 은행 가계대출 총량 집계는 **정책성 대출을 뺀 숫자**다. 은행 자체 주담대가 막혀도 정책대출 경로는 따로 있다.
- 결혼 예정이면 **신혼가구 요건**(디딤돌 3.2억·소득 8.5천만, 보금자리 신혼 우대)을 먼저 따져 볼 만하다. 결혼 예정 인정 기준(예식 예정일·혼인신고 시점)은 기관에 확인한다.
- 디딤돌은 2026.12.31까지 중도상환수수료 면제.

- 잔금일 근처 대출 실행일을 은행 일정에 맞춰 둔다. 매도인과 잔금일 조정 여지도 확인한다.

## 4. 내 상황에서 확인할 것 (체크리스트)

- [ ] 집 주소가 **어느 구**인지(영통·장안·팔달 = 규제지역, 권선 = 비규제) → LTV·보금자리 가산금리가 갈린다
- [ ] 매매가 · KB시세(감정가) → 디딤돌(평가액 5억, 신혼 6억 이하)·보금자리(6억 이하) 대상인지
- [ ] 부부 합산 소득(결혼 예정이면 합산 기준) → 7천만 / 8.5천만 경계
- [ ] **생애최초** 요건(세대 전원 전 기간 무주택) — 6개월 내 전입 의무
- [ ] 은행 2~3곳의 **12월 실행분** 접수 상태와 마감 시점, 사전 상담 예약
- [ ] 변동형 vs 고정형 스트레스 DSR 한도 차이 견적
- [ ] 정책대출 신청 → 승인까지 걸리는 기간(잔금 역산)
- [ ] 계약일이 2025.6.27 이전이면 디딤돌 옛 한도(생애최초 3억) 적용 — 해당 여부
