# 사우디전 후기 — 이미지 프롬프트 (한글)

정보 카드 다섯 장은 이미 만들어뒀어. 이 글은 카드가 전부 같은 초록이고 섹션이 여덟 개라 **중간에 질감이 다른 이미지 두세 장**이 있으면 훨씬 읽기 편해져.

넣어도 되고 안 넣어도 발행에는 문제없어.

---

## 0. 먼저 지킬 것

**선수 얼굴을 절대 만들지 마.** 배준호도 이영준도 실존 인물이야. 사람이 필요하면 **뒷모습이나 다리, 실루엣, 초점 날아간 형체**로만.

**대회 엠블럼과 대표팀 유니폼을 만들지 마.** 붉은 유니폼에 숫자가 박히는 순간 특정 대회·특정 팀으로 읽혀. "무지 운동복", "브랜드 마크 없는 축구화"라고 명시하면 돼. 전광판·광고판·깃발은 아예 빼.

**전술판이나 중계 화면을 참조 이미지로 넣지 마.** 전부 제3자 저작물이야. 가져온 건 사실 정보뿐이고 그림은 새로 만드는 거야.

**한글 글자를 이미지 안에 넣지 마.** 어떤 AI든 한글은 깨져. 등번호도 빼는 게 안전해.

## 1. 공통 스타일 (세 장 모두 끝에 붙일 것)

카타르전 글이 짙은 남색, 마드리드 더비 글이 적갈색이었어. **이번엔 해질녘 톤으로 한 번 더 틀자.** 세 글이 피드에 나란히 떠도 서로 다른 글로 보여야 하거든.

```
편집 사진 스타일, 해질녘 자연광, 초록과 황금빛 위주에 긴 그림자,
따뜻하고 낮게 깔린 빛, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

영문 툴이면 이걸로.

```
editorial photography, golden hour daylight, green and amber palette with long
shadows, warm low-angle light, shallow depth of field, subtle film grain,
no text anywhere, 16:9
```

**빼달라고 할 것 (네거티브)**

```
글자, 한글, 숫자, 등번호, 워터마크, 로고, 대회 엠블럼, 팀 유니폼, 깃발, 배너,
사람 얼굴, 유명인, 뭉개진 손가락
```

## 2. 프롬프트 세 장

### ① 해질녘 빈 경기장 — 도입부에 넣을 것

톤을 잡는 한 장이야. 앞선 두 글이 밤이었으니 이 글은 여기서부터 달라 보여야 해.

```
해질녘 축구 경기장을 관중석 낮은 각도에서 바라본 사진,
잔디에 깎은 결이 줄무늬로 남아 있고 흰 라인이 선명함,
해가 낮게 걸려 잔디 위로 긴 그림자가 비스듬히 누워 있음,
경기장은 비어 있고 사람은 아무도 없음, 광고판은 글자 없는 단색,
하늘은 주황에서 옅은 파랑으로 넘어가는 중,
편집 사진 스타일, 해질녘 자연광, 초록과 황금빛 위주에 긴 그림자,
따뜻하고 낮게 깔린 빛, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

광고판이나 전광판에 글자가 생기면 다시 뽑아. 잔디 결과 빛만 남으면 돼.

### ② 잔디를 가로지르는 긴 그림자 — 사우디가 막은 방식 섹션에 넣을 것

이 글에서 제일 중요한 한 장이야. "길이 막혔다"를 그림으로 옮긴 거라 **사우디 섹션의 03번 카드 바로 위**가 제자리야.

```
축구 경기장 잔디를 낮은 각도에서 클로즈업한 사진,
여러 개의 긴 그림자가 잔디를 비스듬히 가로질러 격자처럼 겹쳐 있음,
그림자를 만든 사람들은 전부 프레임 밖이라 보이지 않음,
잔디 사이로 흰 라인이 한 줄 지나가고 그 위로도 그림자가 걸침,
배경은 초점이 날아가 형체만 남음,
편집 사진 스타일, 해질녘 자연광, 초록과 황금빛 위주에 긴 그림자,
따뜻하고 낮게 깔린 빛, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

사람 다리가 프레임에 들어오면 다시 뽑아. **그림자만 남고 주인은 안 보여야** 의미가 살아.

### ③ 텅 빈 교체 대기석 — 마지막 섹션에 넣을 것

글의 결론이 "아직 안 뛴 선수가 남아 있다"니까, 이 한 장이 마지막 문단을 대신 말해줘.

```
축구장 옆 교체 대기석을 측면에서 찍은 사진,
등받이 있는 좌석이 한 줄로 길게 늘어서 있고 전부 비어 있음,
좌석 위에 접힌 수건 한 장과 물병 하나만 놓여 있음,
좌석과 지붕에는 글자나 마크가 전혀 없는 단색,
옆쪽에서 해질녘 빛이 들어와 좌석 사이에 그림자가 생김,
사람은 아무도 없음,
편집 사진 스타일, 해질녘 자연광, 초록과 황금빛 위주에 긴 그림자,
따뜻하고 낮게 깔린 빛, 얕은 심도, 미세한 필름 그레인,
이미지 안에 글자 없음, 가로 16:9
```

좌석이나 지붕에 스폰서 글자가 생기면 실패야. "글자 없는 단색"을 앞쪽으로 옮겨서 다시 돌려.

⚠️ 마드리드 더비 글에 **벤치 위 축구화** 사진을 썼으니, 이번 건 축구화를 빼고 **빈 좌석**이 주인공이 되게 했어. 축구화가 들어가면 그 글이랑 겹쳐 보여.

## 3. 참조 이미지는 넣지 않아도 돼

프롬프트만으로 충분해. 실제 경기 사진을 참조로 넣으면 저작권 문제가 생기고 구도까지 끌려가.

세 장 톤을 맞추고 싶으면 **①번을 먼저 뽑아서 마음에 드는 걸 고르고, 그 이미지를 ②③번의 스타일 참조로 재사용**하면 돼.

## 4. 넣을 자리와 파일명

```
06_golden_hour_pitch.png  →  도입부, 01번 카드 바로 아래
07_long_shadows.png       →  사우디 섹션, 03번 카드 바로 위
08_empty_bench.png        →  마지막 섹션 첫 문단 아래
```

마커는 이렇게. 각각 단독 줄로.

```
[[IMG:06_golden_hour_pitch.png | 이기고도 마음이 편하지 않은 날이 있다]]
[[IMG:07_long_shadows.png | 길이 하나 막히자 갈 곳이 없어졌다]]
[[IMG:08_empty_bench.png | 아직 이 자리에서 일어나보지 못한 선수가 있다]]
```

다 만들면 보내줘. 초안에 넣고 순서까지 맞춰서 다시 압축해줄게. 파일명은 위 이름 그대로 저장해줘 — 다르면 마커랑 어긋나.

## 5. 썸네일은 그대로 둬

**01_score_kor_ksa.png 를 첫 사진 자리에 유지해.**

`2 - 0` 숫자가 커서 축소해도 읽히거든. 해질녘 경기장 사진은 예쁘지만 손톱만 하게 줄이면 그냥 초록 네모가 돼.

카드 문구도 건드리지 마. `두 골 모두 헤딩으로 나왔다`로 둔 이유가 있어. **제목이 후킹으로 감춘 답(전술적 아쉬움)을 썸네일이 미리 주면 안 되거든.**

## 6. 시리즈 색감 정리

축구 글 세 편이 연달아 나가니까 톤을 계속 어긋나게 잡고 있어.

| 글 | 톤 |
|---|---|
| 카타르전 후기 | 짙은 남색 야간 경기장 |
| 이강인 마드리드 더비 | 적갈색 야간 경기장 |
| **이 글 (사우디전)** | **해질녘 초록·황금빛** |

다음 베트남전 글은 **실내나 도시 쪽**으로 한 번 더 틀면 좋아. 경기장 밖 풍경이나 이동 중인 장면 같은 걸로.
