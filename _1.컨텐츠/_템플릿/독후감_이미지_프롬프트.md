## 1. 지금까지의 결 — 27편에서 본 것

**표지가 빠진 썸네일은 한 장도 없다.** 표지는 「이 책을 읽었다」는 표시다(본인 10/16). 그래서 이 블로그 독후감의 썸네일은 **내가 찍은 표지 + 책 속 핵심을 한 장면으로 보여 주는 무대**를 합친 꼴이다.

| 꼴 | 어떻게 생겼나 | 예 |
|---|---|---|
| ㉠ 상징 무대 속 표지 | 책의 핵심 은유 하나를 무대로 짓고 표지를 그 안에 둔다 | 바깥은 여름(눈 오는 유리 볼 속 표지) · 서성이다(새벽 병원 복도 의자 위 표지) · 바벨(탑 아래 표지) · 소년이 온다(흰 꽃더미 속 표지) |
| ㉡ 인물이 표지를 든다 | 주인공을 닮은 AI 인물이 표지를 들거나 곁에 둔다 | 설득 · 질투라는 감옥 · 페넬로피아드 · 옐로페이스(가면 쓴 인물) |
| ㉢ 주제 정물 | 책의 생활 소재를 탁자·자연 위에 늘어놓고 표지를 가운데 | 저소비 생활 · 직관과 객관 · 존재의 세 가지 거짓말 · 조용한 회복(숲) · 다정한 것이 살아남는다 |
| ㉣ 명화풍 | 그림 양식 안에 표지 | 위버멘쉬·차라투스트라(별이 빛나는 밤 풍) |

- 비율: 4:5 세로 11편 · 그 밖의 세로 9편 · 1:1 6편 · 가로 1편. 세로가 대부분이었다.
- 표지는 늘 **정면에 가깝고 글씨가 읽힌다.** 썸네일 크기에서도 책 제목이 보여서 세 질문 ②(제목 연상)를 저절로 채운다.
- 최근 글(8월 말~10월)일수록 ㉠·㉡이 많고, 표지는 화면의 1/4~1/3 크기다.

**앞으로는 버릴 것 — 그때는 규칙이 없었거나 지금 규칙에 걸린다(발행 글은 고치지 않음, 2-8)**

## 2. 받는 것 — 자동 게시를 맡길 때

| 받는 것 | 쓰는 곳 |
|---|---|
| **책 표지 사진 1장**(본인이 직접 찍은 것) | 썸네일의 표지. Higgsfield 참고 이미지(`image_references`)로 넣는다 |
| **관련 독후감 2개** | 책 내용의 근거. 핵심 질문·장면·인물 설정을 뽑는다. 문장은 옮기지 않는다 |
| (있으면) 초안 md | 제목·소제목. 장면은 소제목 결론에 맞춘다(세 질문 ③) |

- 🚨 표지 사진은 **직접 찍은 것인지 묻고 나서** 쓴다(5-5 Book 예외, 0-1). 인터넷 표지 이미지·서점 사진을 넣으면 6-7 「AI 세탁」이 된다 → 그때는 표지 없이 단색 책으로 그리고 캡션에서 「합성」을 뺀다.
- 표지에 도서관 라벨의 학교·기관 이름처럼 지울 것이 있으면 생성 **전에** 원본에서 지운다(`base data\cover_clean.png`). 생성기는 참고 이미지를 거의 그대로 옮긴다(이방인, 10/16).
- 독후감 두 개가 서로 다른 말을 하면(줄거리·인물 이름·결말) 장면에 넣지 않는다. 둘 다 같은 것만 쓴다(0-1·0-4).

## 3. 장면 짜는 순서

1. **책의 질문 하나를 고른다.** 제목 파이프 뒤 문장(10-6)이 있으면 그것. 없으면 독후감 두 개가 공통으로 붙든 대목.
   예: 바깥은 여름 → 「유리 볼 안은 겨울, 바깥은 여름」 / 서성이다 → 「평가해도 될까 — 응급실 밖에서 서성이는 남편」
2. **그 질문을 사물·장소 하나로 바꾼다.** 주인공은 하나(5-6 「주인공 하나」). 표지는 그 무대 안에 놓이거나 인물이 든다.
3. **꼴을 고른다** — ㉠ 상징 무대가 기본. 인물이 핵심인 소설이면 ㉡. 실용서·에세이는 ㉢. ㉣ 명화풍은 같은 작가·사상 시리즈에서만.
4. **빛을 고른다.** 그 글에서 쓸 장면들의 빛을 먼저 적고 겹치지 않게 나눈다(맑은 낮 / 흐린 날 / 비 / 형광등 실내 / 아침, 밤·노을은 글당 1장 이하).
5. **본문 장면 1~2장**을 더 짠다. 이 장면에는 **표지를 넣지 않는다**(같은 합성 두 번 금지, 5-4). 소제목의 결론 하나씩.
6. 세 질문을 적는다 → 경유표 썸네일 칸.

**Book 썸네일의 세 질문**

| | ○ 이면 |
|---|---|
| ① 요약 + 궁금증 | 장면이 책의 질문 하나를 보여 주고, 답(결말·작가의 판정)은 숨긴다 |
| ② 제목 연상 | 1:1로 줄였을 때 **표지 제목 글씨가 읽힌다**(표지 = 앞 검색어). 책이 화면 폭의 4분의 1 정도면 120px 에서 제목이 사라진다 — 높이의 3분의 2로 키운다(이방인 v1, 10/16) |
| ③ 본문에 있음 | 그 무대·사물을 말하는 소제목이나 문단이 본문에 있다 |

## 4. 프롬프트 블록 — 이미지마다 이 블록 하나를 통째로 쓴다

> 5-5 한 덩어리 규칙대로 공통 조건을 블록마다 풀어 넣는다. 아래 `( )` 는 쓰는 법 표시다 — 실제 블록에는 단어를 채우고 괄호를 남기지 않는다.

### 4-1. 썸네일 (표지 합성 · 1:1)

도구: Higgsfield `gpt_image_2_5` · quality high · 1k · **1:1** · 참고 이미지 = 표지 사진(`image_references`)

```
실사풍 사진 스타일, (빛: 예 — 흐리고 부드러운 낮빛), 선명하고 대비가 뚜렷한 색감, 1:1 정사각 구도. 참고 이미지의 책을 그대로 사용한다. 표지의 그림·색·제목 글씨·배치를 바꾸거나 다시 그리지 않고, 책은 정면을 똑바로 보고 서 있으며 화면 가운데에서 크게, 화면 높이의 3분의 2를 차지한다. 작게 줄여도 표지 제목이 읽힐 만큼 표지 주변은 단순하고 대비가 크다. 표지 밖에는 읽을 수 있는 글자·숫자·간판·로고·말풍선이 없다. 다른 책 표지나 포스터를 지어내지 않는다. 사람이 나오면 성인이고, 실존 인물·작가·배우를 닮지 않은 평범한 얼굴이며, 어린이는 등장하지 않는다. 노을이나 황금빛 역광은 쓰지 않는다.

(장면: 책의 질문 하나를 보여 주는 무대 — 장소, 주인공 사물 또는 인물 하나, 책이 놓인 자리, 날씨·계절, 분위기. 세 문장 안팎.)
```

### 4-2. 본문 장면 (표지 없음 · 3:2)

도구: 같은 모델 · quality high · 1k · **3:2** · 참고 이미지 없음

```
실사풍 사진 스타일, (빛: 썸네일과 다른 것 — 예: 맑은 아침 햇빛), 차분한 색감, 3:2 가로 구도. 화면 어디에도 읽을 수 있는 글자·숫자·간판·로고가 없다. 책이 나오면 단색 표지이고 실제 책 표지 디자인을 재현하지 않는다. 사람이 나오면 성인이고, 실존 인물·작가·배우를 닮지 않은 평범한 얼굴이며, 어린이는 등장하지 않는다. 노을이나 황금빛 역광은 쓰지 않는다.

(장면: 그 소제목이 말하는 결론 하나 — 주인공 하나, 두세 문장.)
```

### 4-3. 실제로 채운 예 — 서성이다(이미 발행, 형식만 보기)

```
실사풍 사진 스타일, 흐린 날 오전의 형광등과 창빛이 섞인 실내, 선명하고 대비가 뚜렷한 색감, 1:1 정사각 구도. 참고 이미지의 책을 그대로 사용한다. 표지의 그림·색·제목 글씨·배치를 바꾸거나 다시 그리지 않고, 책은 정면을 똑바로 보고 서 있으며 화면 가운데에서 크게, 화면 높이의 3분의 2를 차지한다. 작게 줄여도 표지 제목이 읽힐 만큼 표지 주변은 단순하고 대비가 크다. 표지 밖에는 읽을 수 있는 글자·숫자·간판·로고·말풍선이 없다. 다른 책 표지나 포스터를 지어내지 않는다. 사람이 나오면 성인이고, 실존 인물·작가·배우를 닮지 않은 평범한 얼굴이며, 어린이는 등장하지 않는다. 노을이나 황금빛 역광은 쓰지 않는다.

병원 응급실 앞 긴 복도. 앞쪽 대기 의자 위에 참고 이미지의 책이 세워져 있다. 복도 안쪽에 외투를 입은 성인 남성 한 명이 등을 보인 채 서성이고, 얼굴은 보이지 않는다. 바닥은 형광등 빛을 반사하는 연한 회색 리놀륨이고, 창밖은 흐린 하늘이다.
```
캡션: `흐린 오전 병원 복도와 서성이다 (직접 찍은 책을 AI로 합성, 특정 인물 아님)` — 실제 발행본은 새벽(밤) 장면이었다. 위 예는 빛 규칙(10/13)을 적용해 다시 짠 꼴이다.

## 5. 만들고 나서

**순서:** 표지 사진 → `media_upload` → curl PUT(`-H "If-None-Match: *"`) → `media_confirm` → `generate_image`(썸네일, `medias:[{role:"image_references", value:<media_id>}]`) · 본문 장면은 `generate_image_batch` → `jobs_wait` → 초안 폴더에 `01_<장면>_thumbnail.png`, `02_<장면>.png` … 로 저장 → 한 장씩 Read 로 연다.

**검수 — 하나라도 어긋나면 다시 생성(장당 1회까지)**

| 볼 것 | 어긋나면 |
|---|---|
| 표지 제목 글씨가 원본과 같은가(글자 뭉개짐·다른 글자·지어낸 부제) | 다시 생성. 또 어긋나면 표지 사진을 직접 오려 붙인다(PIL 합성). 책을 크게 그리면 작은 글씨까지 원본대로 나온다(이방인 v2) |
| 1:1을 손톱만 하게 줄여도 표지 제목이 읽히나 | 책을 키우거나 배경을 단순하게 |
| 표지 밖 읽히는 글자·숫자·로고 | 다시 생성 |
| 어린이, 실존 인물을 닮은 얼굴 | 다시 생성 |
| 독후감 두 개와 어긋나는 설정(시대·옷·장소) | 프롬프트에 사실을 적고 다시 생성 |
| 장면 빛이 그 글의 다른 장면과 겹침 | 빛만 바꿔 다시 생성 |

**캡션**
- 썸네일: `(장면 묘사) (직접 찍은 책을 AI로 합성)` — 사람이 나오면 `, 특정 인물 아님` 을 붙인다.
- 본문: `(장면 묘사) (AI 생성 이미지)` — 사람이 나오면 `AI 생성 이미지, 특정 인물 아님`.
- 프롬프트는 초안 폴더 `image_prompts_ko.md` 에 남기고, 검수 결과를 그 아래 표로 적는다(앤카슨 글 형식).
- 비용: 장당 1.5크레딧(high·1k). 썸네일 1 + 본문 1~2 = 3~4.5크레딧.
