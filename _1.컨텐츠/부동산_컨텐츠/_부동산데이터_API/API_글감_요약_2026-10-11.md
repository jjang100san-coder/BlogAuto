## 3. 레이더 지도(C안)로 만드는 글 — 글이 아니라 「표·지도 한 장」이 재료

- 마커 색 = 전세가율 / 거래량 / 준공연도, 동 경계 = 인구 증감 → **「수원 집 고를 때 내가 본 네 가지 지도」** 1편(이사 뒤). 지도 이미지는 직접 만든 것이라 5-4 캡션 「직접 만든 지도」.
- 매달 1일 실거래 API 자동 조회 → 「내 단지 이번 달 거래 N건」 한 줄을 월간 유입어 리포트(156)처럼 붙일 수 있다. 다만 **시세 중계 글이 되면 공장형** — 내 집 숫자 한 줄까지만.

## 4. 안 쓰는 것
- 집값 전망·서울집값·목동 재건축·부산 아파트·경매 사이트(법원경매 31,800) — 내 일이 아니다.
- 강아지 분양·수원 맛집류는 부동산 검색어가 아니라 지역명 때문에 걸린 것(표의 분야 오류).
- 주식(잔금) 글은 308 하나만, DART는 점검 끝난 뒤.
